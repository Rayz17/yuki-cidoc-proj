# 湘乡岱子坪新石器时代遗址

湖南省博物馆

湘乡县在湖南省的中部。岱子坪遗址在湘乡县的西北角，离县城约四十公里，现属龙潭公社童家大队株树生产队。遗址所在地为低矮丘陵环绕的小盆地。湘江水系的龙石河由遗址的西部边缘流过（图一；图版贰，1)

1975年冬兴修水利，人工渠道切过遗址西部，文化遗产暴露。公社干部将这一情况告之湖南省博物馆。湖南省博物馆随即派傅

# 一 地层堆积与分期

发掘区东北部的四个探方（T7、T8、T11、T12)被近代水池破坏，仅在水池底下保留有厚10—20厘米的文化层。其它探方文化层厚1—2.75米不等。地势是由北向南、由东向西逐渐倾斜，文化层加厚。其最厚处为发掘区西南的T1和T13、T16、T17等几个探

![](images/e9aaa278cac615c5f282c7d90df66dd12833689f4f437d47f23ac2dca0bb1732.jpg)


方和探沟。

包括耕土层在内，可分为六个层次。以T1、T5、T9南壁剖面为例(图三)。

第1层耕土。黄褐色，松软、夹有粗砂，包含有新石器、唐宋以及近代遗物。厚0.15—0.3米。

第2层 黑灰色土。松软，出有新石器时代陶片。石器和唐宋时代的瓷片、瓦当、砖块。为唐宋时期的文化层。厚15—32厘米。

第3层 灰色粘土。出有新石器时代陶片和石器、兽骨等。为新石器时代文化层的上层。厚20—40厘米。

第4层 灰黄色土。土质较硬。地层中不见遗物，但出有多座墓葬。在T1—T9南剖面上。可见M7、M65和M24的墓坑。此层当为新石器时代墓葬层。厚40—55厘米。

第5层 灰褐色土。土质较细腻松软，夹红烧土渣，出有新石器时代陶片、石器等。厚20—45厘米。

第6层 黄色土。坚硬，夹红烧土渣，出较少的陶片、石器。出土物与第5层近似，同为新石器时代文化层下层。最厚处1米，从西向东逐渐减薄，至T9已无此层次。

T1、T5第6层以下为黄褐色生土。T9第5层直接叠压在黄褐色生土之上。

根据地层堆积情况，结合出土器物的发展演变特点，我们将岱子坪遗址新石器时代文化遗存初步划为三期。各探方的第5、第6层为第一期。各探方第4层所出墓葬为第二期。压在墓葬层之上的第3层为第三期。

# 三 第二期遗存

# （一）墓葬

共九十五座。出陶器四百另四件，石器二件，玉器一件。

墓葬开口在第四层中或第四层底部。除五座墓坑不明外，其余九十座均有清晰的墓坑。墓口距地表的深度最浅的(M24)为0.64米，最深的(M51)为1.5米。这期墓葬的特点是：均为长方形浅竖穴，坑很小。一般长在1米左右，宽为0.5左右，深度0.15—0.30米。坑底积满草木灰、炭渣，并夹杂大量烧烤并经砍碎的兽骨，不见人骨。从墓坑的大小和坑内堆积物推测，很可能为二次葬（图版贰，3）。

墓葬主要分布在T1、T2、T5、T6、T9、T10、T17内(图六)。计T1有九座，T2有十一座、T5有十六座。T6有十八座、T9有二十座、T10有七座、T17有五座。其余T4有一座、T12有一座、T15有一座、T16有一座，T13、T14各两座。

有七座墓无随葬器物，八十八座均有多少不等的随葬品，最多的十七件，最少的仅一件。多为陶质实用器，间有小型明器。随葬石器的墓仅有三座。主要陶器种类有豆、罐、壶、釜、杯、钵等。

# 五结语

俗子坪遗址共分为三期，第一期为第5、6两个文化层和墓葬M43、M62；第二期为第4层和在第4层中的九十五座墓葬。这些墓葬又可分为略有早、晚的前后两段。第三期为压在墓葬之上的第3层。其中尤以第一、二两期遗存内容最为丰富。

第二、第三期遗存，时代上虽有早晚之分，但文化性质、面貌却是很接近的，表明其时代应是紧相衔结的。在这两期的地层和墓葬中所出的一系列典型器物群，如长颈、捏流冲天、厚胎喇叭形杯。高直圈足盂、各种形式的豆、钵、罐、扁平足的釜形和盆形鼎、多种形式的壶、澄滤器，在长江中游地区龙山文化遗址里都是常见的。这一文化分布的北界直至河南西南部——南阳地区，东到鄂东，西到三峡。而岱子坪遗址则是目前所见这一文化的最南一处。关于长江中游龙山文化的名称，有叫为青龙泉三期文化、湖北龙山文化的，也有称之为季家湖文化或七里河文化的。关于名称的争论，可以暂置勿论，而其分布范围、文化内涵和特征，似乎各家见解均无甚差异。

岱子坪的第二期遗存，不难发现有甚多屈家岭文化母体的胎记。如：E型豆与澧县梦溪三元宫屈家岭晚期墓葬中的V式豆①，

I型壶与三元宫屈家岭晚期墓葬中的Ⅲ式壶②，D型I式壶、D型Ⅱ式壶与三元宫屈家岭晚期墓葬中的I式尊③，K型I式壶与三元宫屈家岭晚期墓葬中的I式瓶④均十分接近，可以看出其发展和承袭的关系，时代应相距不远。因此，似可认为岱子坪遗址第二期遗存属于长江中游龙山文化的较早阶段。

第三期遗存有较多的扁平起纵向棱脊的鼎足，有较细柄的豆，时代应稍晚。

长江中游地区的龙山文化分布范围广阔，各个遗址除有显而易见的共性以外，往往还反映出各自的地域特性。因此，可以划分出几个类型。笔者在《长江中游原始文化初论》⑤一文中试图着将其划分为青龙泉——下王岗、季家湖——桂花树、尧家林一舵上坪和岱子坪等四个类型。笔者是将岱子坪遗址作为一个类型的代表来处理的，原先认为其分布地域局限在湘中，最近华容车轱山遗址发掘表明，其分布范围实应包括洞庭湖东岸、湘江下游地区。长沙月亮山遗址⑦也应属此类型。

岱子坪遗址二、三期有它鲜明的个性，可以从以下几点同其它三个类型加以比较。

1. 埋葬习俗 青龙泉、七里河遗址龙山期的墓葬以仰身直肢葬为主，七里河还有合葬墓。季家湖遗址又发现有蹲式屈肢葬。而岱子坪遗址则全部为二次葬。从墓坑内遗留满坑灰烬炭渣和经过烧烤的动物骨骼看来，迁葬时应举行过祭祀。

2.典型器物 夹砂褐陶釜是岱子坪类型常见的器物之一。岱子坪墓葬中，无论前后段，几乎每墓必有，有多至一墓五件的。这种釜在长江中游龙山文化其它类型遗址中是极少见的。岱子坪遗址中所见鼎足，除扁平式外，特多圆锥形，上有窝洞和竖、斜划纹，这也是其它类型遗址难以见到的。岱子坪遗址出土的、颈特别细长，除反映时代较早的特点外，似应有地区特色。

3.纹饰 岱子坪遗址以绳纹为主的风格，不同于青龙泉一下王岗类型蓝纹多于

方格纹以及桂花树——季家湖类型篮纹、方格纹并重的风格。

岱子坪遗址第一期遗存与第二期遗存虽然属于两个发展阶段不同的文化，但也还是存在着不少联系。如第一期的B型Ⅱ式壶与第二期的C型I式壶之间，第一期的A型I式罐与第二期的A型Ⅱ式罐之间均可见承袭关系。特别是圆锥形，上有窝洞和刻划纹的鼎是从第一期一直延续到第三期。

自然，第一期与第二期之间的差别是主要的。第一期不见，不见方格纹，不见长江中游龙山文化习见的一整套典型器物。因此，可以断定，它是早于龙山期的一种原始文化。

岱子坪遗址和邻近地区，与其时代相同或相近的其它原始文化遗址比较，均有若干相似之处。

试将其与石峡文化比较。

石峡文化中最常见的是鼎、釜、三足盘、圈足盘、豆、壶、罐、盂、器盖等⑧。就岱子坪一期来说，二者之间相同因素是较多的。如石峡文化中的盘鼎、三足盘、多为浅盘形，盘壁中腰有一凸棱。这样的盘鼎，岱子坪遗址也有出土。石峡M79:8和M2:2两件三足盘的略似镶形的足，在岱子坪一期中也可见到，我们是将其作鼎足认识的。岱子坪一期常见的圆锥形、上有圆窝和刻划凹槽的鼎足，石峡也曾发现。石峡文化的圈足盘和豆多为子母口和向上折沿，岱子坪一期的豆，也具有相同风格。岱子坪一期所谓双层式豆座，其中T1(六):23(图四，1)。与石峡遗址M3:3陶豆的豆座很接近。石峡文化与岱子坪遗址诸多相同的因素，目前还不能简单地断定是谁影响了谁，但至少说明两者联系紧密。就时间来说，也是接近的。石峡三期墓葬M43所出木炭C14年代为公元前2480±150，岱子坪一期没有进行年代测定，但第二期M3内木炭经过C14测定，经树轮校正年代为2330BC±140(2K-1005)。第一期时代自然更早一些，其年代与石峡文化测定数字不会相差

多远。

试将其与良渚文化比较。

岱子坪一期所出贯耳壶、带盖四系簋、喇叭状高柄镂孔弦纹豆、折沿喇叭状柄豆、带盖扁腹壶等都有良渚文化早期的造型风格。一期墓葬中基本上全是磨光黑陶，也与良渚文化有相似之处。属良渚文化早期的钱山漾遗址下层的断代大体在BC3000—2500年之间，与岱子坪遗址第一期时代也大致相当。

试与屈家岭文化晚期比较。

岱子坪一期中的B型I式器盖、A型器盖、B型Ⅱ式壶、A型V式豆、A型V式豆，如果与梦溪三元宫遗址屈家岭晚期墓葬中出土的Ⅳ式器盖、I式器盖、Ⅱ式壶、XⅥ式豆、XⅢ式豆比照，可以发现其相似的程度是很大的⑨。当然，三元宫屈家岭文化晚期墓以灰陶为主，而岱子坪一期墓以黑陶为主，这是两者的不同。另外，岱子坪一期墓中出土的鼎、甑似与湘北地区屈家岭文化早期偏晚的墓葬中所出相近，而在屈家岭文化晚期墓中难以见到。是否岱子坪一期的绝对年代较屈家岭晚期略早？

目前材料还不够充分，尚不足以断定岱子坪遗址第一期遗存应归属于哪种文化，抑或能否单独命名，成为一种新的原始文化。为解决这一问题，还需沿着湘江、在湘中和湖南作更多的调查与发掘工作。

（上接34页）确。容庚先生推断一件虎饰和一件鸟饰的年代“约在西周前期”⑧，王海文同志把故宫博物院收藏的两件虎饰铸的时代定为“周代之物”，并推测“可能出自兄弟民族地区”⑨。我认为把这类铜铸定为西周器物是对的，其中花纹繁缛的较早，甚至可早至商末，花纹简单的较晚，可晚至西周末。这类铜铸均是单个出土，未见成组的，故可能是一种单独悬挂打击的乐器。

至于这类铜锷的产地，由于有了湖南资兴和浏阳县两件铜锷的出土，还有衡阳市博物馆收藏的那件锷⑩，虽然来自废品站，但

仍可推定它是在衡阳地区境内出土的。由此我们可以推测这类铜锛的产地应就在湖南境内的湘水流域或其邻近地区。这些铜锛以及上述铜锛、甬钟的铸造者应就是当地的土著民族，即古越族。

从上述铜饶、甬钟和镌的铸造水平看，说明湖南地区的青铜铸造业，自商代中期开始接受商人先进的铸造技术以来，一直在向前发展，到西周时代，仍铸造了大量青铜器，且有不少精美之作，反映了当时的青铜铸造技术仍有相当高度的水平。
