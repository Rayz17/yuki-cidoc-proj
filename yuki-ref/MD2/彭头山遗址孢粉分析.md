# （二）不同时期孢粉组合面貌

27个孢粉样品，除个别地层不含孢粉以外，其他地层均有孢粉，但孢粉含量仅耕土层、扰土层和彭头山文化层较丰富，其余地层孢粉含量均偏低。

为了更准确地反映不同文化层的孢粉组合面貌，在以下的论述中，根据表六三的地层对应关系，按照自上而下的地层顺序，即耕土层、扰土层、皂市下层文化层、彭头山文化层、铁锰结核层、灰褐色黏土层、灰黄色黏土层等7个大的地层单位，对孢粉进行综合统计（详见表六四）。各地层单位孢粉组合面貌分析如下。

# （1）耕土层孢粉组合面貌

耕土层共分析样品2个，编号分别为T43①和挡1。观察孢粉626粒，隶属24科28属①②③。孢粉组合中，被子植物占绝对优势，含量为  $70\%$  ；裸子植物、蕨类植物、藻类及其他类孢粉含量分别占  $15\%$  、  $3\%$  、  $11\%$  。其中，草本植物的含量  $67\%$  ，木本针叶植物占  $16\%$  ，木本落叶阔叶植物占  $4\%$  （图三二九）。

草本植物有Polygonum sp.（蓼属）、Artemisia sp.（蒿属）、Cyperaceae（莎草科）、Amaranthaceae（苋科）、Gramineae（禾本科）等。其中，禾本科植物含量最高，占 $62.46\%$ ，这可能与现代地表种植水稻有关。

# 1.8000年以前古植被和古环境推测

距今8000年以前，下部灰黄或灰褐色黏土层沉积中仅有少量的水生环纹藻，上部铁锰结核层除有环纹藻以外，还发现少量乔木植物栎和杉。灰黄或灰褐色黏土代表还原环境下静水沉积，这层土壤在八十挡遗址所在的澧阳平原有广泛分布，说明该时期水域面积较大，在该层中仅见水生藻类植物，未见其他植物，正是这种环境的反映。铁锰结核是氧化环境下的产物，说明该时期水域附近出现一些岗地，在这些岗地上生长着乔木植物。

# 2.8000年以后古植被和古环境推测

# 1）彭头山文化时期

从植被类型来看以禾本科和松属花粉为主，常见落叶阔叶植物，被子植物中的香蒲取代了下伏地层的藻类植物环纹藻。香蒲是一种挺水植物，惯见于池沼、废弃的水田、水边。说明遗址周围存在池沼或河流。水中生长着香蒲，高岗地生长着高大的乔木松树和其他落叶阔叶植物。

值得一提的是，该文化层中发现的大量禾本科植物花粉。这些花粉显微镜下的形态观察，萌发孔比一般的禾本科植物大，可达12微米，虽然不能肯定说是水稻，但地层中有大量炭化米出土，推测很可能与当时稻作农业有关。

古气候和古植被是密切相关的。从总的植被面貌来看，彭头山文化层的孢粉和耕土层非常接近，孢粉的组合都是以禾本科 + 松属为优势种，阔叶植物也都是亚热带常见类型。所反映的植物群面貌为亚热带植被类型，反映的古气候亦为亚热带型。但如果对两个地层的植物类型进行详细的对比的话，可以看出他们在古气候上还是存在一定差异。

一个大的区域，常绿阔叶植物、落叶阔叶植物、针叶植物的含量变化，可以衡量该区域古气候的变化，而低矮的草本植物和蕨类植物，往往代表一个小的局部环境（易受人类影响）。因此，我们在进行彭头山文化和现代气候对比讨论时，用常绿阔叶植物、落叶阔叶植物、针叶植物孢粉百分含量的变化，作为衡量区域范围内古气候变化的指标。

# 2）皂市下层文化

该文化层以松属、枫杨属为优势种，这些也是亚热带常见树种，反映亚热带针叶落叶混交林植被类型。由于孢粉数量较少，不宜详细分析。但值得注意的是，从发现的少量孢粉来看，该文化时期植被类型与彭头山文化最为显著的差异是未见草本植物。更确切地说，彭头山文化中大量出现的禾本科植物，在皂市下层文化中未见。根据彭头山文化层禾本科花粉显微形态分析，和已经发现近万粒炭化水稻来看，彭头山文化中大量出现的禾本科植物花粉很有可能就是水稻花粉。按照文化的连续性，皂市下层文化也应该种植水稻，地层中应该看到禾本科的花粉。是什么原因造成这种禾本科花粉在皂市下层文化中出现“断层”，这个断层的出现，是与孢粉取样有关还是和文化的背景有关，还值得今后进一步研究。

需要说明的是，八十挡遗址两个取样剖面，都位于遗址分布区内，在这样的区域内采集的土壤样品，或多或少都会受到人类活动的影响。若仅用这些孢粉来恢复当时的古环境，显然具有一定的片面性。因此，在今后的工作中，应该努力寻找和文化层同时代的自然堆积地层，并据其孢粉对古环境做出更准确、更科学的分析。

# 第五节 木材鉴定

澧县八十坞遗址是长江流域最早的新石器时代文化遗址之一，距今约8000年。遗址大致呈长方形，聚落内分布着成排的房屋，聚落外有壕沟和古河道环绕。遗址地处中亚热带常绿阔叶林北部亚地带的两湖平原，植被区划属于栽培植被和水生植被区，植被

组成成分反映出由亚热带向暖温带过渡的特征①。

遗址出土一些木材和木器，我们受湖南省文物考古研究所委托，对其中13件木材或木器样品进行鉴定，并试图通过确定树种，以便获得遗址的植被类型、生态气候及古代先民对木材利用的信息。

# 一 试验方法

将采集的标本经室内加工，做横向、径向、弦向三个方向切片，先在显微镜下观察、记载木材特征，进行树种的鉴定，根据《中国木材志》②专著得出结论，然后将木材样本粘在铝质样品台上，在真空干燥箱里干燥，最后，在样本表面镀金，并在日立S-530扫描电子显微镜下进行拍照。

# 三 讨 论

# 1. 八十挡遗址的生态环境分析

植被是自然界中对气候变化最灵敏的指示物，植被的状况可以在相当大的程度上反映气候状况。宋长青和孙湘君根据孢粉和气候之间存在着统计学上的某种相对稳定的数量关系，建立了花粉一气候因子转化函数，认为栎属的存在，表明当时气候温暖湿润①。

麻栎起源于古新世早期，以长江流域及黄河中下游最多。麻栎在年平均气温  $10 \sim 16^{\circ} \mathrm{C}$ ，年降水量  $500 \sim 1500$  毫米的气候条件下都能生长②。喜树喜温暖湿润，不耐严寒

干燥；榆属喜光，喜温凉或温暖气候；朴树喜光，喜温暖气候，不耐严寒；杉木是亚热带树种，喜温喜湿、怕风、怕旱。从鉴定出的树种的生物学特性看，多数树种喜欢温暖湿润的气候，因此，可以推测当时的气候温暖湿润。

# 2. 八十挡遗址居民对树种的利用分析

木质材料对人类的经济有着举足轻重的作用。木质材料是指能提供木质部分或植物纤维以供利用的天然物质，如木材、竹材、藤本、灌木、作物秸秆类①。其中，木材的重要性是第一位的，自古以来，木材就是人类生存所依赖的主要原材料。木材的利用价值是多种多样的，例如：建筑材料、制造各种器具的用材、加工业的原料、燃料等。然而，并不是任何一种木材适合于一切用途，由于不同木材的特性不同，它们各自的用途也不同。

柘树为落叶小乔木，高10米，稀达18米。常见树种之一。由于质硬、耐腐朽、强度大，多用做各种农具和器具。

厚壳树为落叶乔木，高达20米，胸径至60厘米。很耐腐，做房屋建筑的门窗、柱子房架，农具柄、牛轭、板车。

麻栎为乔木，高25米，胸径1米。木材强度大，耐冲击，适合作屋架；有弹性，颇耐腐，适于用作枕木、坑木、篱柱、农具柄、木桶；木材硬，用做门框；发热量高，为优良的薪柴及烧炭用材。

喜树为落叶乔木，树高  $20\sim 25$  米，用做房屋建筑、日常用具及燃材。

榆属木材适合作屋架、农具和车辆材，又适合作燃料。

朴树为落叶乔木，高达20米，胸径1米。喜光，喜温暖气候，不耐严寒。做房屋建筑的门窗、车厢、船舶，也可作枕木、柱子、木桩等。

杉木耐腐性强，板材为优良的船舶用材，如淮北柳孜运河沉船木构件，其中一种木材为杉木。另外，在古代，常为名贵的棺材原料，如长沙马王堆西汉墓1号墓内外椁、印山越王陵墓室独木棺、广州汉墓木椁等均由杉木制造。

从鉴定树种的木材性质和制作的器物两方面考虑，我们发现八十塔回遗址古人类已经开始了有意识地利用木材。譬如，木锥、木杵为器具，木末为农具，说明古代居民有意利用柘树木材特性制作农具和器具。再如，钻孔木牌用的是杉木，杉木耐腐性强，常为名贵的棺材原料，古代居民选用杉木，说明钻孔木牌是一种在古人类看来并不一般的东西。

# 四结论

对八十挡遗址出土的木材和木器进行鉴定和研究，确定了这些木材和木器的树种分别为柘树、厚壳树、麻栎、喜树、朴树、榆属及杉树等，为当时的树种资源提供了历史的见证。根据这些树种的生物学特性，推测当时生态气候温暖湿润。从鉴定树种的木材性质和制作的器物两方面考虑，我们发现八十挡遗址的古代人类能有意识地利用木材，适材适用。
