# 湖南石门县皂市下层新石器遗存

# 湖南省博物馆

石门县位于湘西北，地处澧水中游，北与湖北鹤峰、五峰、松滋三县交界，东与临澧、澧县接壤，南连桃源，西毗慈利、桑植。县之东北、西北、西南均为山地，中南部是丘陵和平原。澧水及其支流澧水流贯本县。皂市（旧名皂角市）在石门县城西15公里南溪流入澧水处，遗址位于澧水东岸的坡地上（图一）。1960年，湖南省博物馆曾在此发现商代遗存①。据此线索，1977、1981年相继二次在这里进行了发掘，所掘面积1100平方米。参加发掘的人员除本馆的何介钧、熊传新、付举友、金则恭、胡树其、李光远、胡德兴、付聚良等同志外，湖南省第一期考古训练班的全体学员也一同参加了发掘。

2. 陶器 手制，在许多器物的内壁可见手指按窝痕迹，胎骨厚薄不均，火候不匀，器表颜色斑驳。陶系几全为红陶。因火候不匀，故出有相当数量的褐红陶和酱色陶片。此外，出有少量由胎骨内植物质炭化所致的夹炭陶片。所出陶片炭化甚厉，据整理统计，夹砂陶多于泥质陶，其中夹砂红陶与褐红陶分别占  $38\%$  与  $19\%$  左右，泥质红陶与褐红陶分别占  $21\%$  与  $14\%$  左右，酱色陶占  $14\%$  左右，夹炭陶占  $1.5\%$  左右。从陶片表皮与剖面观察，绝大部分的泥质红陶片表皮呈红色，胎心则大部呈灰黑色，相当数量的夹砂陶片也是这种情况。有些陶片剖面可看到明显的层次，疑为贴塑而成。

陶器装饰主要采用打印、压印、刻划、剔刻、镂孔、戳印等方法。此外，也发现少量在白衣红陶上绘彩的作法。纹样丰富发达，据统计，有纹饰的陶片占总数的  $47\%$  左右。主要见有交错细绳纹、横断绳纹和横、斜、竖刻的组合划纹、雨线划纹、网格划纹，还有相当数量的篦点纹以及少量的剔刻纹和戳印纹等（图六、七）。其中交错绳纹最多，刻划纹次

之，篦点纹又次之，其余少量。彩绘一般是在高圈足盘的托盘下部或圈足上绘带状图案，绳纹多施于夹砂高领罐肩腹部，划纹多施于泥质陶的罐、盘等器物上，篦点纹则多见于罐类器的肩部。有的器物颈部也常饰绳纹、划纹或戳印纹。镂孔为透雕，常以长方形和三角形的组合图案施于高圈足盘的圈足上。再者，在同一器表，常可见到以绳纹、划纹、篦点等多种纹样组合的图案，也可以见到以篦点纹为地，再在其上施划纹的二重装饰法。

# （二）动物遗存

在遗址西区北部所发现的新石器遗存堆积层中，发现了大量的动物残骨，多为牙齿和残破的颈骨等。经鉴定，动物种类包括有梅花鹿、水牛以及羊、豪猪、老鼠、麂、龟等，其中以鹿、水牛和猪的牙齿居多，它们是否由人工畜养，还待进一步研究。

# 三、结 语

石门阜市下层遗存是近几年来湖南考古的重要发现，遗存中不仅有一群富有特征的日用陶器，而且还有为数不少的生产工具。生产工具包括采用砾石加工而成的磨制石器和用燧石打制、压制而成的小型石器(细石器)。从细石器的加工方法和功能看，同中原以及

西樵山等地的细石器都很接近。因此，皂市下层出土的这种小型燧石工具应归入“细石器传统”的范畴。这一发现对于重新认识长江中游地区的早期原始文化以及探索这一地区的“细石器传统”问题提出了重要线索。遗存中的陶器，除了极少量陶质松疏的夹炭陶和酱色陶外，基本上属于红陶系。器类简单，制作粗放，火候不匀，颜色斑驳而纹饰丰富。其中直口折沿高领罐、IV式双耳曲腹罐、III式高圈足镂孔盘、I和II式高圈足镂孔器座、I和II式钵、直口深腹罐等器物具有典型意义。这一器物群与其所共存的石器、细石器一起构成了一种明显有别于长江中上游已发现并被公认的“大溪文化”、“屈家岭文化”的原始文化遗存。不仅其文化特征显现出它的相对的独立性，而且，在时间的纵坐标上，其C标本测定数据为  $6920 \pm 200$  年③，显然要早于前二种文化。从遗存中的陶系、器物形制和纹饰上看，与地理位置相近的湖北城背溪近年所发现的新石器早期遗存有着某些共同的因素④，如与以往长江中、上游地区所发

现的原始文化相比，似与湖南澧县丁家岗下层遗存存在着源流关系⑤。丁家岗下层中出土的燧石工具、I——III式钵、IV和V式罐、I式盘、III式碗等器物及其纹饰风格似乎可从皂市下层遗存中找到其发展的轨迹。那么，皂市下层遗存是不是它的祖型呢？这种在时代上比“大溪文化”、“屈家岭文化”更久远、在文化内涵上相对独立的原始文化遗存是否可作为长江中上游地区的一种新的“文化”而诞生？亟待考古界的同行们共同研讨，当然，也需以更多的发现和发掘来证明。
