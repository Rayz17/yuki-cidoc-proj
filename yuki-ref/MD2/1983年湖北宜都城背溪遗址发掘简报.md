# 1983年湖北宜都城背溪遗址发掘简报

湖北省文物考古研究所

城背溪遗址位于湖北省宜都县（现改为枝城市）城关镇北面约105公里处，西南距吴家岗约0.5公里，北距宜都红花套遗址[1]约7公里，东临长江，西边10—40米处为长江防护堤（图一）。长江流出三峡口以后，折向东南，流经宜都县境，遗址即位于这段长江西岸的冲积平原上，较为平坦。由于历年江水冲刷，现在遗址绝大部分已被破坏。

宜都县城背溪遗址早在1973年长江流域第二期文物考古干部训练班在宜都红花套遗址发掘时就已经被发现。1982年宜昌地区进行文物普查时，又进行过一次调查。1982年

12月与1983年4月，北京大学考古系、湖北省博物馆考古部（现为湖北省文物考古研究所）和宜昌地区博物馆联合对这个遗址进行了两次复查。1983年10月上旬至10月28日，由湖北省博物馆主持，北京大学考古系、宜昌地区博物馆和宜都县文化馆参加，联合组成宜都考古发掘队，对遗址进行了第一次发掘。

1983年11月上旬至1984年2月，我们对第一次发掘资料进行整理和简报编写工作。通过室内整理，我们认为位于遗址东北部（北区）的T1、T2二个探方遗存的年代约为夏商时期，位于遗址中部偏东南（南区）的T3一T6等四个探方遗存的年代为新石器时代。现简报如下：

# 一、新石器时代遗存

# （一）地层堆积

城背溪遗址南区的T3、T4、T5等三个

探方，都在长江西岸一级台地上，地层堆积分为四层：第一层为农耕土，第二层为现代扰乱层，第三、四层为新石器时代早期文化层。现以T5东壁为例：

第一层：耕土层，灰褐土，厚0.25—0.3米。

第二层：近现代扰乱层，深灰土，深0.25—1.10米，厚0.85—1.05米，这层出不穷的砖瓦和现代砖瓦。

第三层：新石器时代早期文化层，黄褐土，深085—1.90米，厚0.7—0.85米。该层出土陶钵、碗、罐、盘等残片，还有陶纺轮、陶器耳和石斧等，其中以夹砂绳纹和夹碳绳纹陶片的数量最多。

第四层：新石器时代早期文化层，浅黄土，含沙土较多，深1.60—2.60米，厚0.55—1.00米，此层出土遗物较少，主要有陶盘和罐的残片，以及石斧、石片等，其中以泥质和夹碳绳纹陶片最多。

位于长江西岸河漫滩上的T6，西距T4约5米，堆积层是从一级台地上崩塌下来的“断层”。原耕土层、扰乱层已被江水长期冲刷而无存，在文化层上只有一层灰褐色的河滩淤土，厚约0.2米，包含物有江水冲积的新石器时代早期陶片以及近现代的瓷片和砖瓦块等物。河滩淤土层下的第二层为新石器时代早期文化层，黄褐色土，很薄，主要分布在探方西端，文化遗产物较少：第三层为浅黄色土，在探方中部靠西边有一条长约5米、宽约2.5—3.5米的沟状地带，最厚处约0.4米。在沟状地带集中了大量陶片，其中有不少可以复原的完整器。主要有陶罐、盘、钵、釜、支座、碗、盆、小碟、器耳等种，并发现不少兽、鱼骨和少量骨、石器T6在江边的河漫滩上。洪水期间长期淹没于江水之中。T6地层是否“倒转”呢？为了弄清这个问题，发掘队曾在T6西边的江岸断坎上铲出剖面，观察T6与T3—T5地层的对应关系。江岸断面地层的堆积如下：

# 2、陶器

陶质有夹砂、泥质和夹碳等，其中泥质陶掺入淤砂，显得较粗糙。夹砂陶和一部分夹碳陶主要为釜、罐、支座等炊器或器具；泥质和夹碳陶多为盘、碗、盆、碟、钵等盛食器与水器。陶色有红褐色、灰褐色、黑色、黄、白和红色（红陶衣）。其中以夹砂红褐陶最多，泥质红褐陶、夹砂灰褐陶以及夹碳红褐陶与夹碳灰褐陶次之，夹砂橙红陶较少，而夹砂黑陶极少。纹饰有绳纹、线纹、素面、压印纹、刻划纹、镂孔纹等。其中以绳纹最多，素面次之，其余纹饰都很少。线纹和绳纹多施于罐、釜、钵、碟等器外表，盘多为素面，盘圈足多镂孔，刻划纹、压印纹多饰于支座器表。少部分涂红或黄、白陶衣，彩绘陶仅在一件夹砂灰褐陶盘上见到。这些陶器的制法都是手制，在圈足陶盘上有明显的手制痕迹与拍印的绳纹痕迹。根据陶胎分层等现象观察，容器为“泥片贴筑法”制成。许多器皿的制作很不均匀对称，器壁也不规整。陶容器以圜底器最多，圈足器次之，平底器极少，未见三足

器。主要器形有夹砂罐、小罐、釜、盆、圜底盘、圈足盘、大圈足盘、碗、平底钵、圜底钵、瓮、支座、双耳壶、碟、双耳罐、纺轮等。

# 三、结 语

1983年，宜都城背溪遗址出上的新石器时代文化遗产十分丰富，是湖北省内的重大发现。陶、石器的文化特征较原始，与本地附近的宜都红花套、枝江关庙山遗址发掘的大溪文化、屈家岭文化都有较大的差异。应属于一种时代更早的文化

城背溪遗址保存面积窄小。不见灰色土层，文化堆积比较集中。南区出土的石器大多数是不很规范的长方形或梯形的斧、锛、凿类工具。还有网坠和石球等渔猎工具。这些石器只有少数经过局部磨制。大多数为打制或琢制。有的只是将天然砾石略加打制即成。这些石器作风与枝江关庙山大溪文化石

器普遍经过磨制或通体磨光、形体规整的情况有较大差异，明显地表现出石器制作与使用方面的原始性。城背溪遗址出土的新石器时代陶器，以红褐陶为主，灰褐陶次之，还有一些红陶衣、黄陶衣和白陶衣陶。陶质以夹砂陶最多，泥质陶和夹碳陶也有相当数量。纹饰以交错绳纹最多，素面陶的数量也不少，线纹、压印纹、刻划纹、镂孔纹较少，绳纹是陶器成型后修整、加固留下的痕迹。圜底器发达，圈足器也较盛行，平底器很少，三足器极少见。陶器均为手制，用泥片贴筑法成型。器形不大均匀对称，器壁厚薄不一，表面不平整，保存许多制作过程、方法的痕迹。烧制的火候不高，估计温度不超过  $75^{\circ} \mathrm{C}$  。一些器表面常见有黑烟斑块，这是烧制时燃料贴近器壁的痕迹。许多情况表明，城背溪陶器比大溪文化陶器原始。T6发现不少接近石化的动物骨骸[如圣水牛头骨（T6③.96）和陶支座（T6③.97）胎内的青鱼右咽喉齿]，也表明了城背溪遗存的年代久远。我们认为城背溪新石器时代文化遗存应属于一种新的新石器时代文化，它的相对年代当早于大溪文化。

城背溪遗址北区发掘的夏商陶器也很重要[3]。其中陶罐和灯座形器最有特色，相邻的毛细套、向家沱和三峡地区的秭归鲢鱼山也有这些器物。而鄂东黄陂盘龙城商代遗址则不见。这为探索鄂西地区夏商文化提供了重要信息
