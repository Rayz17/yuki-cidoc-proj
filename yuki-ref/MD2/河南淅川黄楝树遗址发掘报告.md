# 河南淅川黄楝树遗址发掘报告

# 长江流域规划办公室考古队河南分队

浙川县位于河南省的西南部。其西北邻陕西，西南接湖北，东部与西峡、内乡、邓县相邻。县境内西北部为深山区，东南部为丘陵地带，中部和南部为丹江中游和老灌河下游组成的河谷平原。七十年代初期起，随着丹江水库的修建，中部和西南部逐渐成为风景秀丽的水库区。

为了配合丹江水库的建设工程，早在1957年，水库勘测的前夕，就对丹江流域进行了文物调查，发现多处古文化遗址和古墓葬，并重点发掘了下集、双河镇、李家庄、留嘴、下王岗、黄棟树等六处古文化遗址及下寺、毛坪两处楚国墓葬区。

# 贰 仰韶文化遗存

# 一 遗迹

属于仰韶文化的遗迹有两座房基，它们周围分布着两个石头坑，五个灰坑，一个兽坑，四座成人墓，五座瓮棺葬。在此尚未见有早于这些遗迹的人类活动的痕迹，所以它们应是遗址中年代最早的遗迹（图六）。

# （一）房基

F34、F35皆系圆形建筑，是在黄色生土上挖筑成的土台。台的土质坚硬，居住面平整。在居住面的周围，发现有木柱洞。这两座房基因在高岗的西侧，很易遭受水害，为了避免水灾，在土台的四周挖出沟槽，使积水流出，以保持居址的安全。F34直径2.2—2.4米。在居住面的中心和周围，残存四个柱洞。柱洞的设置没有规律，一个在居住面的中部略偏东南，另一个在沟槽内，其余二个在沟槽外沿边上。圆形建筑顶部情况不清（图七，3）。这两座房基详情请见附表一。

# （二）石头坑

在仰韶时期人类活动的地面上普遍铺垫着陶片和石头，放置它们的目的，可能因该地潮湿低洼，而填铺上去的。经过先民们多次踩蹋，许多陶片和石头都已没入胶泥内。其中堆积比较密集的石头坑有两个。石头坑1在发掘区的东北部，与F35相毗邻。坑的平面呈椭圆形，东西长8米，南北宽6米，深0.4米。石头坑2在发掘区的西南部，它的南边有一兽坑。此坑中的石头分成两小区，东边的为椭圆形，南北长2.25米，东西宽1.5米；西边的近圆形，南北长1.8米，东西宽1.55米，深约0.2米。这些石头坑的底部稍凹，并积有绿色的水渍物。所铺石头皆不规则，大小、颜色亦不同。最大的石头长40厘米，小的约为6厘米。以白色石头为多，酱红色和浅黄色石头较少。它们均为河卵石。

# 屈家岭文化遗存

# 一、遗迹

由于当时的先民在此居住的时间较长，故属屈家岭文化的文化层堆积较厚，且遗迹较多，有房基、灰坑、墓葬等（图一八）。

庭院的平面呈长方形。就现存情况看，庭院西北部已被雨水冲毁，东南部保存尚好。东部长21.5—31.5、残宽15.75米。院内土质坚实，地面平整，但稍向西倾斜。院内中部偏南处，有一单间房F28，房门朝向东北。就该房单独设在庭院的中部以及门向东北等现象观察，该房房主的身份与众不同，它可能为氏族首领的住室或开会的地方。

这座庭院中房基的门多已无迹可寻。仅就现存有门的F7、F11、F33和F28来看，大体有三个方向：即朝向西北、西南和东北。F7设房门四个，其中三门向西南，一门向西北；F11设房门二个，过道门一个，其中二门向西北，另一门向东北；F33的房门向西南；F28的房门向东北。前述三种朝向的房门因房主身份不同，其用途可能也有区别。面向西北即黄岭河的门，便于居民汲水和捞取河内鱼虾，面向西南的门便于居民出入庭院，面向东北的门可能有二个用途，如F11的房门将有利于居民进入后山猎取野兽，而F28的房门则可能为氏族首领出入庭院的通道。

2. 房子的结构：此期房子的形状为方形或长方形。是就地挖筑的木骨建筑。房子分单间和双间两种。墙壁或隔墙大部分是先挖出沟槽（也有少数是将建房的地面下挖0.03米），之后在其四周挖出柱洞，立柱筑

墙。就出土的墙壁碎块观察，墙壁（隔墙）是以木柱和竹竿作骨架，再以烧土碎块掺和粘土、稻杆、稻壳搅拌成泥，抹糊为墙的。屋内地面是用黄砂土铺垫成的，并经夯打，涂敷白灰，也有把白灰涂抹至墙壁脚上。还有由于房屋的使用时间较长，地面破裂，致使多次铺垫黄土和涂抹白灰面。

门分房门和过道门两种。在建造屋墙时就留下缺口，再在垫铺屋内地坪时筑起一条高出屋面的门槛。过道门建筑在双间房的隔墙上，作为往来的通道。它是在修建隔墙时建成的。就发掘情况看，这种房门多被破坏，保存好的较少。

柱洞设在墙壁的中部，洞的形状、大小，依据柱的粗细而定，一般的柱洞为圆形或椭圆形。为了减轻柱子和墙壁的压力，常在柱洞的底部填以陶片、灰渣、鹅卵石块做成磷墩。此外，也有在屋内地面上为了支撑屋顶，树立柱子，这些柱子的底部，有的为柱洞，有的在木柱的下端铺垫草泥，有的是堆出圆形土柱台，上面再树立木柱。

火塘是保存火种和炊煮饭食的地方。每室皆筑有火塘。火塘的数量一般是一室一塘，但也有设置三个火塘的（如F8西室）。火塘的位置多在墙角或靠近墙壁处。

有少数房子的门外残存有白灰地坪，其形状不甚规正，但其表面皆平整光滑。

# 伍结语

黄棣树新石器时代文化遗址不仅面积大，而且遗存丰富，它包含着仰韶、屈家岭、龙山三个时期的文化遗存，是豫西南地区丹江流域的一处重要遗址。尤其是以25座房子组成的庭院式房群，进一步丰富了屈家岭文化的内涵，它在鄂西、豫西南屈家岭文化遗址中，也是首次发现。这些发现为探讨屈家岭文化的社会性质提供了重要的物质依据。

# 一、黄棣树遗址文化发展序列

黄棣树是一处人们长期居住的遗址。根据地层关系和遗物特征，可分为早、中、晚三期。早期属仰韶文化，中期属屈家岭文化，晚期属龙山文化。

早期遗存较少。就陶器看，制法原始，以手制为主，兼用轮制。夹砂红陶最多，另有少量泥质灰陶。陶器表面多为素面，间或饰以弦纹、条纹、细绳纹、附加堆纹和指甲纹等。器形有鸭嘴形足的罐形鼎、瓦形足的钵形鼎、敛口圆肩平底瓮、折沿鼓腹圜底罐、敛口弧壁圜底钵、小口尖底瓶、器盖等。这期人类居住的房址甚为原始，多为黄土台，并在台的周围挖以沟槽，树立柱子，

另在沟槽外面铺垫石头和陶片。台呈圆形，径在2.20—3.00米间。墓葬的形制简单，全为单人仰身直肢，无任何随葬品。

中期为屈家岭文化。这种文化较仰韶文化有很大进步。14C测定的年代距今约4700年。这期石器的制作，陶器的形制，墓葬的结构以及房子的建造技术等都和早期文化之间有着显著的差异。也就是说，两者间存在着较大的缺环。这可能是与两个不同的氏族先后在这里居住密切相关。中期的石器大都经过磨光。小部分石器上钻有圆孔。这种钻孔技术的应用，标志着石器制作技术有了很大的改革。这些有孔的生产工具能穿系绳索，捆绑木柄，而一些有孔的蚌、骨、石类装饰品，可穿联成串悬挂在身上，藉以显示出他（她）们爱美的观念。关于孔的钻制，根据孔壁的痕迹和钻孔芯观察，钻孔的钻具多为空心管（疑为竹管）。用这些空心管，在器物上反复旋转，即可钻制出各种圆孔。其钻法又分双面钻和单面钻两种：所谓双面钻是指在器物正、背面预定的孔眼处，进行对钻，钻成的孔眼，正、背面圆径皆外大，内小。单面钻是指仅在器物的一面进行钻制，这样的钻孔，皆一面大，另一面小。钻制的对象为陶、石、骨、蚌器。由于钻管粗细不同，钻孔的大小也不一致，大的1.6、小的（如骨针）0.3厘米，一般在0.8厘米左右。陶器的种类很多，以轮制为主，兼用手制和模制。夹砂和泥质灰陶数量最多，并有少量的泥质和夹砂红陶及泥质黑陶。陶器的形制，除少数沿用早期的罐形鼎、钵形鼎、圜底罐、圜底钵、器盖外，出现很多新器形。这些新器形的制作精致，造型美观，胎壁较薄，并往往在器壁上镂孔，或于器表涂以彩绘图案。如高圈足豆、高圈足杯、薄胎黑陶杯、深腹缸、短颈折肩壶、敞口杯等，它们的表面除素面或磨光外，在其圈足上常镂以圆、椭圆、三角、矩形孔以及羽状划纹；此外，在敞口杯、短颈折肩壶上饰以红色或黑色的精致的彩绘图案，图案的内容灵活多变，富于写实

感，有涡纹、弦纹、点纹、方格纹、折线纹等。另外，此期陶纺轮形式很多，表现出屈家岭文化的特有风格，除其他遗址常见的双面平齐的纺轮外，还出现一些新的样式。如有的纺轮为一面圆鼓，有的为双面鼓起。施彩图案也较丰富，有旋转纹、涡纹，或将纺轮均分四份，间隔施以圆点及弦纹，还有围绕圆孔划出射线者。

中期已能有计划的营建由多座房子组成的庭院。这25座房子是江汉流域屈家岭文化中的重要发现。它充分显示了当时的先民们精湛的建筑技术。其建筑程序可概括为：先平整地面，再开挖基槽，然后立柱，筑墙，架椽，结顶，铺垫屋面，修建火塘、土台、门槛，并涂抹白灰地面，建造房外棚式门廊和户外地面以及露天灶等。

此期墓葬多为土坑竖穴单人葬，仰身直肢，头多向西南，个别墓内随葬有石镯、耳饰（耳坠）、石珠、陶罐等。这些情况初步反映出部族成员们的财产已有多寡之分。所发现的三座成人和婴儿的合葬墓（M11和W21、M15和W24、M23和W35）引人注目。墓中成人皆仰身直肢，头向西南，盆骨下面分别葬一瓮棺。M11内的W21下面还随葬一猪头骨。这种葬俗是否如山东大汶口墓葬中的猪头，象征着死者财富的多少，尚值得探讨。M15墓主头部两侧分别发现一套耳饰（或称耳坠），腰间悬挂着成串的石珠，这说明墓主的身份异于常人。

晚期遗存较少。就陶器看，以轮制为主，兼用手制。夹砂和泥质灰陶最多，泥质红陶次之，黑陶较少。陶器的形制中鼎、罐、钵、豆、杯、碗、器盖与中期近似，但其表面常饰有篮纹、条纹、弦纹、划纹、附加堆纹，这已不同于中期陶器表面的镂孔和彩绘。它标志着这些陶器包含着浓厚的龙山文化因素。引人注意的是新发现的大量篮纹陶器，如盆、捏足碗、罐、瓮，还有素面。这些情况表明，中、晚期文化遗存间虽有差异，但较早、中期之间的差异要小得多。

晚期房子的布局、筑法与中期近似，惟房数少，分布零散。但筑房技术较中期有明显的进步。除有中期的单间和双间房子外，开始新建居住面积较大的多间房子。另外，房间面积也有所增大，如最大一间的面积可达30平方米。

# 二、黄棣树遗址与其他文化的关系

丹江是汉水伸向豫西南的一大支流。近三十年来，先后在丹江中游发掘了黄楝树、下王冈、双河镇、李家庄、雷嘴和丹江支流老灌河下游的下集，以及汉水中、下游的京山屈家岭、郧阳下寺、郧县青龙泉、均县朱家台等遗址。发现了房基、灰坑、窑、灶、墓葬和数以万计的遗物以及稻、粟等粮食遗骸。特别重要的是在浙川县的下王冈、黄楝树、下集，郧县青龙泉，郧阳下寺等五处遗址中发现的仰韶、屈家岭、龙山这三层文化的叠压关系，由此证明这三种文化是普遍存在于丹江流域和汉水中、下游新石器时代文化遗址内。这种文化发展脉络是研究这一地区原始文化的宝贵资料。

# （一）与下王冈文化的比较

下王冈遗址位于浙川县老县城西面丹江南岸的红石冈上。西距黄棣树遗址约5公里。该遗址文化堆积厚达4米，遗存甚为丰富。1971年发掘时把该遗址分为早一期、早二期、中期、晚一期、晚二期等五期（第二次发掘又分为九期）。下王冈早一期和黄棣树的早期（仰韶）相似。两处的墓葬均为土坑竖穴单人葬，仰身直肢。惟黄棣树的人骨头向西南或东南，无随葬品。墓的位置分散，无集中的墓地。而下王冈的墓向多朝西北，排列井然有序，显然为一氏族墓地，墓内多有随葬品，如陶鼎、罐、壶等。其中一墓殉葬狗1、龟1、陶鼎1和陶罐等。另外，未见瓮棺葬。下王冈陶器以夹砂和泥质红陶和棕陶较多，细泥黑陶较少，器表多为素面，部分器外饰以弦纹和绳纹。黄棣树的鼎（W26：2）、钵（T8③：164）、罐（M49：

1）均见于下王冈一期。

黄楝树的中期（屈家岭）和下王冈的中期较为接近。两处都发现房基，房形和筑法相同。黄楝树的25座房子建筑在两条线上，组成一个宽敞的院子。而下王冈只见1座双间房子。下王冈未见成人墓，但两地的瓮棺葬制相同，均以深腹罐作为主要葬具。在黄楝树发现3座土坑墓和瓮棺葬埋在一起的合葬墓。陶器的制法、形制和类别基本相同，惟黄楝树的陶器以轮制为主，兼用手制和模制。夹砂和泥质灰陶最多，红陶次之，泥质黑陶较少，器表多素面，主要陶器为鼎、豆、罐、杯、盆、碗等，其中以薄胎折腹杯、薄胎彩绘敞口杯和薄胎涡纹壶最为精致。下王冈的陶器以夹砂和泥质红陶最多，棕陶次之，黑陶和灰陶极少。陶器形制除上述者外，与黄楝树诸多类同。两地均有平面陶纺轮，但黄楝树新见鼓面纺轮、刺纹纺轮和式样新颖的彩绘纺轮。

黄楝树晚期（龙山）和下王冈晚一期比较接近，但又存在一定的区别。两地文化层内均有磨制的石器，如石斧、石锛、石凿、石网坠等，但下王冈不见石镰、石刀。两地均发现骨镞、骨锥、骨簪，而黄楝树的蚌镞、骨针、彩绘陶纺轮不见于下王冈。陶器的制法相同，皆以轮制为主，兼用模制。陶器表面除素面外，间或饰以条纹、方格纹、篮纹、弦纹、附加堆纹及镂孔，含有较多的河南龙山文化的因素。陶器的质地、颜色近似，惟下王冈有夹砂和泥质棕陶。陶器的种类，虽皆有鼎、甕、甑、罐、杯、碗等器，但仔细观察却有些不同。如黄楝树的鼎身呈敞口罐形和敞口钵形，足为“瓦”状；而下王冈的鼎身为敛口罐形，足有饰竖划纹的宽板足和圆锥形足。黄楝树的罐为敛口，鼓腹，平底，体饰篮纹；下王冈的罐的小口，深腹，小平底，体圆而细长，部分器表饰小方格纹。黄楝树豆盘为敞口，折腹，下附喇叭形圈足；下王冈的豆盘似盆，浅腹，附矮足。黄楝树有圈足

碗和“捏耳”圜底碗；下王冈为敞口平底碗。黄楝树有厚胎带把杯和薄胎彩绘敞口杯；下王冈仅有薄胎素面敞口杯。另外，如、甑等器经两地相比也有细微的差异。上述差异的成因，大概是因为居住在黄楝树和下王冈两个毗邻的氏族虽同属于龙山文化，但由于客观条件的影响，在制作陶器方法上各有其独特之处所致。

# （二）与青龙泉文化的比较

青龙泉遗址位于湖北省西北部的汉水北岸③，坐落在玉钱山南麓的缓坡台地上，北距黄棣树遗址约50公里，同属于汉水流域的一处重要文化遗址。文化内涵丰富，有仰韶、屈家岭、龙山三种文化遗存。

青龙泉遗址仰韶期的5座房子，皆系圆形地上建筑，和黄楝树遗址的仰韶期房子类似。就其保存较好的1座看，居住面直径2.4米，周围挖有沟槽，槽内填石块和烧土块，其上立木柱23个，门向东，居住面用细泥作成，较坚硬，中部的2个木柱，大概是支撑房顶用的。这座房子与黄楝树仰韶期的圆形建筑相比，显然青龙泉房子在建筑技术上有很大的进步。青龙泉仰韶期的4座瓮棺葬，也以陶罐为主要葬具，形制与黄楝树的类同。两地主要陶器的形状相同：青龙泉的深腹矮足钵形鼎（简报图三，1）、深腹罐（简报图版贰，1）、平底盆（简报图三，3）、敛口平底钵（简报图三，5）、纽形花边器盖等，分别与黄楝树仰韶期的鼎(T8③:30)、罐(W19:1)、盆(W3:2)、钵(W3:2)、器盖(T6③:152）的形制类同。

青龙泉屈家岭期发现双间房1座，单间房3座。皆为地面建筑，其筑法和形状略与黄楝树屈家岭期的双间和单间房相似。青龙泉双间房的墙壁用粘土屧烧土块筑成，每间都有房门，隔墙似有过道门。和黄楝树不同的是：房子四壁下未挖沟槽，没立柱子，未设火塘，墙壁内外皆涂一层掺有稻壳和茎叶的细泥。在门口皆设一硬土门槛，两室居住面上各立3根柱子用以支撑屋顶，居住面

上涂细泥并经火烧成红灰色，质地坚硬。另外，在一间的居住面上发现长方形土台，而另一间内有一长方形烧土凹槽，其上置陶鼎等。这类土台和凹槽可能是用来放置餐具或进用餐的桌子。还有的居住面上埋有陶罐，从罐内残存的柴灰看，大概是保存火种的容器。单间房墙壁的筑法与黄楝树略同，采用开挖长条沟槽的方法。在F1南、北、西墙下面发现30多个柱洞，居住面西北隅也设长方形土台，其附近可见陶豆、陶罐等。青龙泉的土坑竖穴墓和瓮棺葬，皆无随葬品，其葬俗与黄楝树相同。青龙泉的陶器以素面或磨光的灰陶和黑陶为主，其制法、质地、种类、纹饰也与黄楝树颇多相似。如曲腹圈足器、蛋壳彩陶等，但黄楝树的薄胎黑陶杯(F11：33）、薄胎彩陶杯（T8②：196）以及鼓面、施彩、刺纹陶纺轮均不见于青龙泉。青龙泉屈家岭的年代，据F1二号柱洞中木炭的14C测定为  $4500 \pm 200$  年和  $4370 \pm 200$  年，树轮较正  $5020 \pm 235$  年④。

青龙泉龙山期墓葬30座，其中合葬墓1座，成年单人墓24座。瓮棺葬5座。多数成人墓的葬法和黄楝树龙山期墓葬相同，多为土坑竖穴，仰身直肢，另有仰身屈肢和侧身屈肢各1座。有9座墓随葬陶罐、钵、盆、纺轮，石环、嵌，玉饰和猪骨等。另有2座墓的随葬品较特殊，M27墓主左侧放有14付猪颌骨，腰下埋陶罐、钵各1件。钵置罐口上，钵底有一圆孔（作者认为是瓮棺葬，与M27为一合葬墓。这种葬俗与黄楝树屈家岭墓葬相似)。M31墓主头右侧置猪颌骨一堆。这种随葬猪颌骨的现象，可能与山东大汶口葬俗有关。瓮棺葬具仍以陶罐为主，其上盖陶盆、钵等。陶器制法：青龙泉以手制为主；黄楝树以轮制为主，兼用手制。陶器的质地、纹饰等均极近似。夹砂和泥质灰陶较多，并有少量的夹砂和泥质红陶，泥质黑陶较少。陶器表面均多素面和磨光，也有施以篮纹、方格纹、附加堆纹、弦纹、彩绘等。器形都有鼎、、甑、罐、盆、钵、豆、盘、器盖等，

但如作比较，在一些器物的细部甚至主要部位仍有显著的差异。

# （三）与京山屈家岭文化的比较

京山屈家岭遗址位于鄂中丘陵地带的两河交汇处的椭圆形岗地上，文化层堆积厚0.3—3米。该遗址的地理环境略与黄楝树相似。通过发掘，将京山屈家岭分为早期和晚期两层，而晚期又细分为晚一和晚二。黄楝树屈家岭文化与京山屈家岭的晚二期文化较为近似。

京山屈家岭晚二期遗迹较为简单，只发现一个长方形烧土台，台面不甚平整。东西长8.9、南北宽6.62、高0.55米。南侧有呈一条直线的柱洞4个。这应当是先民们活动的场地。墓葬1座，方向  $26.5^{\circ}$ ，无墓坑和随葬品，葬式为屈肢葬。生产工具以石器最多，另见骨锥2件、骨针1件，未见蚌器。这许是因当地土质酸性强，具有腐蚀性，故骨、蚌质器不易保存。石器制作精致，均经磨光，个别器物上钻有圆孔。器形有斧、锛、刀、镰、铲、凿等。其中数量最多的菱形石与黄楝树的石（T6②：380）极为相似。陶纺轮的数量也较多，分素面和彩绘两种。其中彩绘纺轮是屈家岭文化中最具特色的一种生产工具。京山屈家岭和黄楝树两地纺轮的形式基本相同，都有平面、鼓面、算盘珠三种形式。如京山屈家岭晚二期纺轮（T93：4（9））和黄楝树纺轮（F14：7）皆为算盘珠形，为屈家岭文化中少见。纺轮中以素面为多，彩绘纺轮的颜色多为红、褐两种，其纹饰两地基本相似，都有直线、涡纹和圆点，其组合方式亦大同小异。但黄楝树独具一格的刺纹纺轮却不见于京山屈家岭。陶器的形状两地诸多近似，但也有一定的差异：如京山屈家岭IV式罐形鼎和黄楝树的I式罐形鼎基本相同；京山屈家岭I式钵

形鼎和黄楝树的Ⅲ式钵形鼎相似，但前者鼎为折腹，后者腹壁呈圆弧形；京山屈家岭Ⅲ式盆形鼎和黄楝树Ⅱ式盆形鼎相似，惟前者腹部施一周堆纹，而后者在腹部按两盏手。另外，在碗、杯、罐、壶、缸、器盖等器物上，两地均有一些各自的特点。这大概是因两地制陶者的制陶风格不同所致。值得提出的是黄楝树Ⅱ式蛋壳双腹杯（F11：33）为山东龙山文化的典型陶器，但这种陶器不见于京山屈家岭文化中。

后记：黄棣树新石器时代文化遗址是于1965年和1966年两次发掘的。参加发掘的有裴明相、孙传贤、杨肇清、张静安、王明瑞等同志。田野工作结束后，于1973年由裴明相、贾峨、杨育彬、赵青云四同志编写出报告初稿。1986年经裴明相同志重新审定，编出此稿。照片是张建中、王兆文同志摄制的，插图是高秋菊、李永青、臧广兰、李爱云、杨磊等同志绘制的。由于水平所限，可能有某些不足之处，请提出宝贵意见。
