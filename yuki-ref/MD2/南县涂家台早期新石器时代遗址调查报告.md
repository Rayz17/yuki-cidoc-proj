# 南县涂家台早期新石器时代遗址调查报告

# 益阳地区博物馆 南县文物管理所

一九九四年二月至三月，笔者与南县文物管理所谈国鸣同志在复查南县涂家台遗址时，发现一批与该地区以往时期文化遗存面貌皆有区别的遗物，随即开了一条  $1 \times 2.5$  米的探沟，并清理了一条暴露在外的灰沟，获得了一批重要标本。现将收获报导如下：

# 一、遗址位置与层位关系

涂家台遗址位于南县九都山乡大郎城村，北距县城约4公里。遗址北端有九个小土包，每个小土包相距不过200米。涂家台位于九个土包最南边，其东、南、西三面是一望无际的湖积平原。遗址所在土包高出地面2至3米，为长条形。南北向。东西宽50米，南北长约200米，面积约一万平方米，由于遗址中部被渠道切断，故可分成南北两半。其中南半部已遭到严重破坏，文化层堆积所剩无几。北部地势稍高，保存较好，调查时沿断崖所开探沟，以及清理的灰坑均位于该处。其中探沟编号为南涂  $\mathbf{T}_{1}$  ，灰沟在其西南约30米，编号南涂  $\mathbf{G}_{1}$  （图一）。通过探沟可大体得知该遗址文化层的堆积，状况及深度。

现以  $\mathbf{T}_1$  西壁剖面为例说明：

第①层：耕作层。含现代白瓷片。厚  $15\sim 25$  厘米。

第②层：浅灰色土，结构松散。厚  $16\sim 22$  厘米。夹现代和明清时期的白瓷片、青花瓷片。

第③层：灰褐色土，稍松。夹有少量红烧土颗粒。厚  $5\sim 14$  、距地表深  $50\sim 60$  厘米。出土陶片主要为夹炭红陶和泥质红陶。

第④层：红褐色，土质松散。夹有大量细红烧土颗粒。厚  $10\sim 23$  ，距地表深  $65\sim 75$  厘米。以胎质坚硬的泥质陶占多数。

第⑤层：土质紧，呈青灰色。厚  $5\sim 8$  、距地表深  $75\sim 85$  厘米。遗物较④层减少，出土砺石1件。

第⑥层：浅灰色，土质紧实。夹有少量红烧土颗粒。厚  $8\sim 26$  、距地表深  $90\sim 100$  厘米。出土遗物少。主要为陶质疏松的夹炭陶。

第⑦层：青灰色，土板结。厚  $12\sim 30$  、距地表深  $105\sim 115$  厘米。出土陶片与⑥层相同。

第⑧层：灰褐色粘土，结构紧密，北边夹有红烧土块。厚  $20\sim 25$  、距地表深  $130\sim 140$  厘米。包含物少。均为薄胎易碎的夹砂夹炭陶。酱褐色陶占有一定的比例。

第⑨层：棕黄色粘土，较紧实，含积水。厚17～25、距地表深  $150\sim 155$  厘米。出土有盘口高领罐等。

以下是生土，土质为结构紧密的灰黄色粘土。

从上述文化层中所出遗物来看，③至⑤层出不穷陶片大体相近，主要是泥质红陶和夹砂红陶，夹炭红陶次之，泥质黑陶胎质坚硬、细腻，纹饰丰富，器形规整。且种类较多，有双耳罐、圈足盘、盘口罐、折沿罐等。在⑥至⑨层中，极大部分是夹砂陶，少量夹炭陶，胎质均薄，质地疏松。有直口高

领罐和盘口罐等。从采集和地层所出遗物中仅发现2件砺石。

另外， $G_{1}$  的层位关系与  $T_{1}$  不同。据剖面观察，其上部第①层是机耕路，厚  $20\sim 30$  厘米。第②层是扰乱层，厚  $15\sim 20$  厘米。第③层是浅灰色土，土质松散。厚约15厘米。第④层为青灰色土，土软湿润显粘性。  $15\sim 25$  厘米。出土遗物较多，主要是胎质炭黑的泥质红陶，其次是泥质灰陶。纹饰有刻划、戳印、篦点、弦纹、镂孔、绳纹等。第⑤层是黄色土，土质紧，极少见包含物。灰沟即开口在③层下，打破第④、⑤层，打破生土。由于清理的范围很小，灰沟整体情况不明。

# 二、遗物

陶器：质地以泥质陶为主，约  $80\%$  。夹砂陶次之。胎质以炭黑色和灰黑色居多。 $\mathbf{T}_{1}$  地层中出土的夹砂夹炭陶含砂比例较重。 $\mathbf{G}_{1}$  和采集的陶片中，夹炭夹砂陶比例很小。陶系几全为红陶和红褐色，个别灰陶。早期地层中陶器多施陶衣，极少见陶皮。陶器烧成温度低，陶质疏松，夹炭陶质松散。因为地下水的浸润，陶片极易碎，有的松散呈粉状。陶皮有相当程度的剥落，陶衣已剥落殆尽，露出炭黑或灰黑色胎骨。较晚的地层中陶多施陶皮，陶胎较细腻纯净，结构紧密坚硬。内外表施一层泥质表皮。大多数器物内外表一致，但也有的器物内黑外红，内褐外红，内灰外红或内红外褐等。有的器物表层颜色斑驳，色泽不一。造成这些区别的原因，可能是陶土成份不同和烧成的温度有一定的差别。早期地层夹炭陶胎薄，易碎，手制，许多器物内壁可见手指按窝痕迹，胎质厚薄不匀。但是在采集的标本中，有少量泥质陶片胎质极薄，器物小巧。晚期地层中出现的器物形态规整，纹饰种类较多，首尾呼应，线条流畅。当时可能出现了慢轮修整。

陶器装饰主要是采用拍印、戳印、压印、刻划、镂孔、剔刻等方法。纹饰丰富多样，有斜、横细绳纹，交错横断细绳纹以及绳纹与竖刻划纹，弧线划纹、弦纹相组合的图案。还有篦点纹、刻划纹、雨线纹、凹弦纹、网格纹等。戳印纹、刻线纹一般饰在器物的口沿和器物的上部，弦纹、篦点纹

饰在器物的颈部和肩部，绳纹多数饰在器物的上部和下部，个别饰在器物的口沿和颈部，刻划纹一般饰绳纹之上（图二）。

从地层中出土的陶片和采集的标本中，无完整器形。口沿较多，未见圜底器和三足器，有圈足器和平底器。主要器形有圈足盘、卷沿罐、折沿罐、高领折沿罐、直口高领罐、盘口罐、双耳罐、敞口罐等。此外，遗址中还出土了一批小型器物，口径在8至15厘米之间，形态十分规整，主要为卷沿罐和简腹罐。现按器物的形制分别叙述。介绍器物时，如果是胎质呈炭黑色的泥质红皮陶，不再作说明。

# 结语

自1984年文物普查以来，我省在常德市、岳

阳市、怀化地区、湘西自治州等地先后发现近百处早于大溪文化的新石器时代文化遗存，这次在南县发现的涂家台遗址也属于这一时期。从而扩大了洞庭湖地区早期新石器时代文化的分布范围，对研究洞庭湖地区早期新石器时代文化的体系、文化发展序列都提供了重要的依据。

由于没有进行正规的发掘，对遗址的居住方式，家畜饲养等主要经济生活方式不甚了解。不过所采集的陶片种类较多，从中可测知遗存的部分文化内含及其有关特点。

涂家台遗址与洞庭湖北部地区早期新石器文化相比，既有它们的相似之处，也有遗址自身的文化特征。

相似之处主要表现在皆以红陶系为主，器物形态比石门皂市下层和胡家尾场出土器物更显规整。其中遗址中所出A型I式、C型Ⅱ式盘与胡家屋场A型Ⅲ式圈足盘和E型圈足盘相似。C型Ⅱ式与石门皂市下层Ⅱ式圈足盘十分接近。B型双耳罐与石门皂市Ⅳ式双耳罐形制相同。数量

较多的卷沿高领罐、折沿罐、简腹罐，在石门皂市下层和胡家屋场遗存中都能找到许多相同或类似的器形。此外，从遗址中采集到一批器形轻巧、胎质极薄的筒腹罐、折沿罐，与皂市下层、胡家屋场的同类器形风格一致。这就表明该遗址不仅年代与石门皂市下层接近，而且在文化性质上也有明显联系。值得注意的是，探沟内出土的陶片，有一部分是夹砂陶，以及夹炭陶。器形主要是盘口罐，酷似澧县丁家岗第一、二期遗存中出土的盘口器。具有一定特色的Ⅲ、Ⅳ式器座，在安乡汤家岗第二次发掘的下层中，出土有风格类似的遗物。只是其口沿外纹饰更显发达而已。据此估计，涂家台遗址的年代下限有可能晚于皂市下层和胡家屋场。

关于涂家台遗址的自身特点，由于出土和采集的标本有限，尚表现不明显，但在遗址中采集到的一批方唇卷沿罐，方唇直口罐在洞庭湖地区同类遗存中没有发现，这些现象均为进一步认识遗址的完整内涵和性质提供了有益的线索。

（上接160页）鼎，以及与鼎共存的印纹白陶、筒形器、双耳罐，实际上是同处于磨山类型文化面貌大转换的临界点。在鼎与印纹白陶共存期之前，受皂市下层文化的影响，是筒形器、直口高领罐、高领双耳罐等的发达与延续。在鼎与印纹白陶共存期之后，筒形器、高领罐、双耳罐消失或基本消失，鼎迅即成为数量多、覆盖面广、型式多样的构成文化面貌主体的器形。鼎的这种发展，使洞庭湖区与湘江中、下游地区的文化面貌迥然不同。鼎与印纹白陶共存时期，也可以被视为洞庭湖区文化对湘江中、下游地区文化发生强烈影响的结束。磨山类型独立走上以鼎为主体的勃然发展的道路。实际上，磨山类型是一种很早就以鼎的特别发达为主要特征的文化。这种文化生长、发展于湘江中、下游地区，至今我们仍没看到这种发达的鼎文化是受影响于周边文化才发展起来。相反，在磨山类型与洞庭湖区大溪文化并行发展之时，象车轱山等一些遗址也出现以鼎为主的现象，很难说其中没有磨山类型影响的因素。
