# 株洲县磨山新石器时代遗址试掘报告

# 湖南省文物考古研究所

# 株洲市博物馆

株洲县属湘中地区。磨山位于株洲县城以东8公里处，西北距株洲市区16公里，南面3.5公里处是渌水，西面10公里是湘江(图一)。磨山为平坦农田中一高出约10米的山包，文化遗存分布在山上及山下的农田，面积约3万平方米。西南头有一条小溪由北向南流。

遗址在1986年6月文物普查时发现。1987年8月，由湖南省文物考古研究所主持，会同株洲市博物馆、株洲县文化局，对遗址进行试掘，共开探方7个（图二），发掘面积96平方米。

# （二）、早期二段遗存

遗物大多为陶器，仅有少量石器。陶器以手制为主。

据  $\mathrm{T}_{4}$  ③出土陶器的陶系统计表明，器物 $56\%$  为夹砂，  $44\%$  为泥质。陶色，以灰褐色数量最多，占  $30\%$  ，其次为红褐色，占  $26\%$  ，其它数量较多的有红色、黑灰色、橙红色、浅灰色和白色等。与一期相比，泥质白陶明显减少，其数量仅为总数的  $3 \%$  。器物的装饰，继续流行戳印纹，并出现大量的红衣装饰，其它主要纹饰有弦纹、绳纹、曲折纹、羽状纹等（图八）。装饰的风格，讲究有规律的变化和组合，讲究图案和线条的单一性，与此相适应的是，素面器物增多。

器形有釜、钵、盘、罐、豆、碗、鼎足、筒形器、圈足器等。其中以釜、罐的数量为最多。

釜：继续沿用A型。新出现B、C、D型，以B型数量最多。

$\mathbf{A}_{\mathbf{v}}$  式：圆唇，盘口，腹饰细绳纹。标本  $\mathrm{T}_{4}3$  ：22，夹砂，橙红陶，口径16，残高4厘米（图九，6）。

B型：折沿，沿面平直。全部夹砂陶，可分三式。

$\mathbf{B}_{1}$  式：尖唇，宽沿面，外沿面平直，内沿面成多道微弧。外沿端饰二道戳点横带纹。标本  $\mathbf{T}_{4}$  ③：23，橙红陶，口径20，残高5.2厘米（图九，1）。

B.式：圆唇，溜肩，肩、腹饰弦纹、间断绳纹。标本T.③：19，灰黄色胎，口径20，残高6.8厘米（图九，12）。

B.式：圆唇，溜肩，近成筒形腹，肩饰绳纹。标本  $\mathbf{T}_{4}35$  ，黑褐色陶，口径28，残高3.6厘米（图九，9）。

# 1、遗址出土的文化遗物

出土遗物绝大多数为陶器。

本期陶系与早期明显不同的是，出现了一定数量的硬陶。据  $\mathrm{T}_{3}$  ②出土器物陶系统计，软陶类陶器占  $88\%$  ，硬陶类陶器占  $12\%$  。软陶类中，泥质陶占  $58\%$  ，夹砂陶占  $42\%$  。陶色以红褐色为最多，约占  $35\%$  ，其它依次为：黑褐陶占  $26\%$  ，橙黄陶占  $21\%$  ，灰陶占  $18\%$  。器表装饰如同三期，更趋简单化，且一种器物一般只装饰一种纹饰。绳纹成为最流行纹饰，其它数量较多的纹饰有：曲折纹、方格纹、弦纹、S纹等(图十三)本期素面器物数量大增，约占总数的  $36\%$  。红衣陶基本消失。硬陶类中，陶质基本为泥质，陶色以灰色和橙黄色为最多。纹饰多为曲折纹和小方格（图十三），素面陶器约占三分之一。

共24座。除4座位于遗址南边的  $\mathbf{T}_3$  外，其余20座均分布在西南边的  $\mathbf{T}_{5},\mathbf{T}_{6},\mathbf{T}_{7}$  内。计  $\mathbf{T}_{5}$

# 四、结语

关于磨山早、晚二期的年代，参照邻近地区新石器时代遗存的面貌，可推测如下。

早期一段器物，器表多做繁褥装饰，多种纹饰同集于一器，且多采用戳印、戳点、刻划、模印、拍印等手法。这与澧县丁家岗一期的装饰风格极为相似。而其多圈足器、多釜形器的文化面貌与长沙大塘遗址基本相同。其A型釜与大塘遗址的VI式、IV式釜的形态基本一致。早期二、三段遗存出自不同的地层，年代上虽有早晚之分，但文化面貌却十分接近，其年代应是紧密相接的。二、

（上接75页）是当时一个专门制陶、烧窑的场所，其功用相当于后世的制陶工场作坊。三座房基，无论是地面式建筑，抑或半地穴式建筑，从其柱洞的排列，都可看出房子中不分小间，不是小家居室，而是集体住所。五座墓葬中有四座是单人葬，两座有简陋的陶器随葬，两座空无一物。M5人骨多，明显不属一个个体，几乎在坑口至坑底，层层都有人骨发现，只是数量多寡不一，但有一点却是肯定的，就是这些人骨都属二次葬。而这些人骨究属合葬性质或乱葬墓，还有待进一步分析。四个陶料坑，坑内大多保留有制陶的原料，陶土纯净，已经拌和加工。坑内有的还留有制陶工具陶拍。陶窑七座，无论是瓢形窑、圆形窑，或者椭圆形窑，都保留有灰烬、陶片。很显然，对门山遗址并非当时一般的居住遗址，而是专门用来制造、烧制陶器的一个工场。在这里从事烧制陶器的是专门陶工、窑工，他们主要从事制陶，居住在一起。前述墓中所葬，无论是单人葬多人葬，都应是在这里从事制陶的工匠死后草率入葬的。前面

三段较流行的泥质红衣陶，也多见于华容车轱山一期和丁家岗二期。其装饰风格较一段的简化，与丁家岗二期、三期总的装饰发展趋向相同。器物多三足器，常见器形为鼎、釜、罐、钵，而鼎足又多饰按窝和戳印纹，这与车轱山早二期文化面貌相似。早期二段的I式碗为丁家岗二期所常见。因此，磨山早期遗存基本相当于洞庭湖区的大溪文化时期。

磨山晚期遗存，包括晚期地层和所有的墓葬。多绳纹，多夹砂灰陶釜。墓葬制度，墓坑为狭窄的竖穴浅坑，全部为二次葬，墓坑中遗留有灰烬渣和碎骨，这与岱子坪二、三期遗存完全相同。墓葬中出土的常见器物为釜、罐、豆、壶，壶均为磨光泥质黑陶，长颈、鼓腹。豆均为粗高柄，柄多饰镂孔。这也与岱子坪二、三期遗存大致相同。因此，磨山晚期遗存应与岱子坪二、三期年代相当，即为长江中游地区龙山文化时期。
