# 湖南澧县彭头山新石器时代早期遗址发掘简报

湖南省文物考古研究所

澧县文物管理所

# 一 遗址地形与古环境

彭头山遗址是近年在湘西北澧县新发现的一处新石器早期文化的代表性遗址。以此遗址为代表的文化现已定名为“彭头山文化”。

遗址位于澧县县城西北，距县城约12公里（图一）。这里是一处小土岗，海拔高度不足45米，相对高度5米。周围地势开阔平坦，西、南残存澧水支流涔河的小支流河段。

遗址地处澧水北岸的澧阳平原，是现今湖南最大的平原之一，介于武陵山余脉与洞庭湖盆地之间，为过渡地带。东连湖区，西北邻近山地，海拔高程  $36\sim 40$  米。属河湖冲积平原。

根据湖南省文物考古研究所孢粉实验室对遗址文化层土壤的孢粉分析，在新石器时代早期，这里的植被多杉木和湿生蕨类孢子植物，属暖性针叶林为主的森林草原环境，气候暖湿，气温较现代略低①。

由于在遗址的孢粉组合中明显缺失水生类植物，又由于洞庭湖地区秦汉时的自然景观仍属河网切割平原；因而，可知遗址当时的地貌与现代情况接近，处于平原之中由小土岗丘连接而成的地势较低矮的缓坡地带，而不是处于湖滨沼池边缘。

# （二）墓葬

18座。墓坑小而浅，有方形、长条形、圆形、不规则形等数种。多属二次葬，墓内不见骨骼。随葬陶器或完整，或残破，或二者兼有，数量  $1\sim 4$  件不等。因墓坑较浅，体形较大的器物均被砸碎。一次葬的墓也有发现，墓内保留骨架，随葬石质装饰品。根据湖南省土壤肥料研究所对各墓葬土壤标本的测定，一次葬墓底土壤的磷、钙元素含量明显高于二次葬。这或许暗示在第二次埋葬时没有回收或只回收了少量遗骨。

# 四 稻作遗存

经体视显微镜观察，遗址陶片中央大量稻壳和稻谷。因全部炭化，形态不完整。目前又无可靠方法使之从陶胎中剥离出来，故有关专家对它们是否属栽培稻尚不能予以确认。下面选2件含炭化稻壳、稻谷遗存的陶片标本予以介绍。

T6H9稻3：粘附在1块双耳高领罐领部的陶片上。陶片表面的细长黑点全部为稻壳及稻谷标本。此外，陶片断面上的炭化稻壳与稻谷也十分明显。这说明上面的稻壳并非只出于某种目的而粘附在陶器表面的（图一○）。

T6H9稻1—1：粘附在1件大型小口深腹罐中下部的陶片上。陶片为内、外两层结构。稻壳标本粘附在外层的内侧，呈人字形分作2片。通过显微放大，稻壳的内部层理及中间网络结构均较清晰(图版伍：1、2)。

# （二）主要制陶方法

体积较小的陶器多直接捏塑成形，较大的陶器多用泥片贴塑法成形，但也有许多器物两种方法兼用。

由于陶器制作工艺原始粗糙，胎壁普遍较厚，尤以器底为甚。胎壁断面还可观察到

许多因贴塑泥片而形成的分层现象。器物大多整体歪斜，器表凹凸不平，口沿呈波状起伏。为掩饰造型遗留的杂乱痕迹并加固胎壁，器物内、外表面常有刮削、抹平、打磨的印记。标本T9⑤：7为釜的残片，壁厚0.5厘米。内壁未经打磨，有许多捏塑时留下的手指按窝，近口部分接泥片，接缝痕明显

# 七 遗址年代与发掘意义

# （一）遗址年代

在遗址正式发掘之前，北京大学考古系曾将调查采集陶片用碳十四测定法测试年代，数据为距今  $9100 \pm 200$  年、 $8200 \pm 200$  年。最近，北京大学考古系又测试了发掘所获的木炭和竹炭标本，其中T14②层距今  $7815 \pm 100$  年、T14⑥层距今  $7945 \pm 170$  年。

以上数据（均未经树轮校正）除第一个偏早外，其余都较接近。以此作为依据，遗址的绝对年代推测为距今  $8200\sim 7800$  年之间。因此，这是在长江流域迄今发现的最早的新石器时代遗存，其相对年代既早于中游地区的石门皂市下层文化，又早于下游地区的河姆渡下层文化，与中原裴李岗文化的最早年代相当或略早。

# （二）主要发掘意义

1.遗址自文物普查发现时起，就引起了考古工作者的关注。它所显露的原始、古朴、粗放的风貌与本地区已知各种新石器时代文化都明显不同。经这次正式发掘，进一步证实它是一支新的文化代表，使这一地区新石器时代文化的谱系研究向前推进了一大步，形成了彭头山文化  $\longrightarrow$  石门皂市下层文化  $\longrightarrow$  大溪文化  $\longrightarrow$  屈家岭文化  $\longrightarrow$  龙山时代文化的发展序列。基于彭头山文化与后续者之间，在原始农业、生产工具、陶器制作、建筑风格诸多方面的实际发展水平都存在阶段性的重要差距，我们认为，在长江中游地区，真正属于新石器早期的文化应该是距今8千年以前的彭头山文化，后来继起的其他文化则分属中、晚期。

2. 经过这次发掘，发现彭头山遗址与周围及近邻地区的旧石器晚期遗存，在大型打制石器方面存在一些相似性。其中大石片刮削器皆以宽大扁薄为特点，破裂面略隆起，较平坦，其制法似与贵州猫猫洞的锐棱砸击法相似。此外，单面二次打击形成的单刃砍砸器也是两地共有的器种。显然，这些因素均可作为洞庭湖西缘，乃至长江以南地区旧石器与新石器两大阶段有机联系的文化纽带，为研究这些地区古人类向新石器时代转变的模式提供线索。

3. 彭头山遗址的陶器虽然原始，但就整体而言，已经迈出了初始阶段的门坎。主要的两种制陶方法显示了曾存在一个以泥片贴塑成形为代表的制陶工艺阶段，进而推知，

在此以前尚有一个直接捏塑成器的阶段。彭头山遗址磨制石器选用硬度较低的石料，以装饰品为主。这或可以理解为磨制石器初级阶段的特点。

4.本次发掘最重要的收获是稻作遗存的发现，它不仅是我国，也是世界上已知最早的稻作农业资料。虽然目前尚无能力确定是否属于栽培稻，但从遗址出土陶器的泥料中普遍掺稻壳、稻谷的现象，以及在7千年以前长江下游的河姆渡下层文化已有较发达的稻作农业等情况分析，有理由把彭头山遗址的稻谷遗存作为我国8千年以前即已存在稻作农业的标志。不过，从遗址的地貌、孢粉分析所显示的以森林——草原为主的生态环境、位于河网切割平原中地势低矮的岗丘缓坡地带的自然条件，以及大量存在的打制石器分析，当时人们的经济生活仍以采集、渔

猎为主，稻作农业处于辅助地位。

5.自本世纪30年代以来，常有我国南方石灰岩洞穴及河旁台地发现新石器早期遗存的报道。但囿于地质条件的特殊性，材料又零散，学术界对这些发现一直持极谨慎的态度。彭头山遗址的发掘，将为长江以南地区新石器时代早期的研究树立一个标尺。另外，彭头山遗址所出双耳高领罐与中原裴李岗文化的同类器有相似之处，这似乎表明，在当时两个文化之间已有一定交往和接触。

参加发掘的人员有裴安平、曹传松、何新发、张春龙、向桃初、刘劲、徐祖祥、席道合、盛兆华、向安强、吴贤龙、罗仁林等。

过萧象墓志的。南朝文人济济，好的文章流传下来不少，其中有不少是墓志，如《宋故尚书左丞孙缅墓铭》、《宋故御史中丞孙竑墓铭》⑤，作者是江淹。梁朝著名文人任昉为萧象嗣父萧融写过墓志⑥。《梁书》主要作者之一姚察也多次为人写墓志。所以，当时赏读本朝人的墓志，或者参考墓志来撰写本传，都在情理之中。

萧象墓志虽然残缺甚多，但还有几处保存得较好。从这几处看，墓志字体工整遒劲，已显然是较成熟的楷书。与镇江出土的南齐刘岱墓志比较，笔画不那么方正和有棱有角，而是比较圆润，既不同于东晋时的粗犷，又不同于唐时的秀丽。由于当时选择石灰岩一类石料做墓志刻石，镌刻得又较浅显，所以大多保存极差，萧秀和萧伟墓志都是如此，有的竟只字不留。萧象墓志尽管腐蚀了不少，但尚保存近600字，在南京地区梁墓志中仅次于萧融墓志和王慕韶墓志，为我

们研究梁代史实及书法等提供了十分珍贵的资料。
