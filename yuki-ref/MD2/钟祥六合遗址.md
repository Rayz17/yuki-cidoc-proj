# 钟祥六合遗址

# 荆州地区博物馆 钟祥县博物馆

六合遗址位于钟祥县皇庄区长城乡高庙一组，西距县城郢中镇约二公里，南临汉钟公路及南湖，（图一）。遗址是在一处高出周围十多米的岗地上，南北长300米，东西宽200米，原有面积约6万平方米。1981年和1983年，荆州地区博物馆，钟祥县博物馆配合取土工程，在这里进行了两次发掘，由于工程紧，故分三片同时开方，北面开方4个，编号  $\mathbf{T}_{1} - \mathbf{T}_{4}$  ；东面开方13个，探方号从10开始，编号  $\mathbf{T}_{10}$  。

一  $\mathbf{T}_{22}$  ；南面开方18个，探方号从31开始，编号  $\mathrm{T}_{31} - \mathrm{T}_{53}$  。计开  $5\times 5$  的探方35个（图二），发掘面积875平方米，发现了一批新石器时代和西周的遗存，其中新石器时代遗存又可分为四个文化期。现将主要收获报告如下：

# 乙 屈家岭文化早期遗存

屈家岭文化早期遗存包括墓葬、灰坑和文化层三部分。

# （一）墓葬

1、概况：这期墓葬共14座，其中11座在遗址东侧，3座在遗址西侧，由于地层早期扰动较严重，原来的排列密度已不了解。墓坑边缘不清楚，可能为长方形浅穴。骨架保存不好，但朽质尚存。葬式皆为仰身直肢葬，头向在  $175^{\circ} - 190^{\circ}$  之间。有7座为一次葬，6座为二次葬，一座葬法不明。随葬品主要为陶器，生产工具较少，有一座墓随葬猪下腭骨。陶器有的放于头前和脚端，有的放于身上或身旁，石器一般放于下腹或手旁，随葬品最少的为2件，最多的有25件见（表一）。现举例说明。

M3、M4、M5：打破  $\mathbf{T}_{10}④$  ，坑边不清楚，骨架之间相隔不到10厘米，无互相打破现象，应属同时埋葬。M4为一次葬，M3和M5为二次葬，头向均为  $190^{\circ}$  ，M4头部

置一大曲腹杯，其余陶器均置于脚头。M3和M4脚后放3付猪下腭骨，随葬品中无生产工具（图版壹，1）。

M9、M10、M11：打破  $\mathrm{T}_{18}④$  ，坑边不清楚，骨架间相隔约20厘米，也是同时埋葬。三墓皆为二次葬，M9脚端和胸部各置一段长骨，M10肋骨和胫骨位置错乱，M11头骨不远处放一根长骨。头向皆为  $190^{\circ}$  ，随葬品中，除M10、M11各有一件石器外，其余全为陶器（图版壹，2）。

# 四 结 语

六合新石器时代遗存包括四个文化时期，第一时期是以红陶系为主的较早遗存，第二时期为屈家岭文化早期，第三时期为屈家岭文化晚期，第四时期为石家河文化，其中屈家岭文化早期和石家河文化又可以进一步分段或分期。

第一时期遗存发现不多，陶片较零碎，对其文化特征尚难进行归纳。从现有的材料看，这期陶器是以泥质红陶为主，部分涂红衣，泥质黑陶为次，灰陶最少。绝大部分陶器皆为素面，纹饰简单，只有弦纹和浅附加堆纹等，其中链条形浅附加堆纹较有特点。器形方面，数量最多的为盆、罐。盆以C型为主；罐以A，B两型为特点。无论盆还是罐，口沿部分大都加厚凸出。关于这种红陶系遗存的文化性质，仅靠该遗址的材料还不足以进行分析，但是近几年，汉水东部调查和试掘了几处类似的遗存，例如京山油子岭下层①，天门龙咀②，谭家岭下层③等，已初步将这类遗存定名为大溪文化油子岭类型④。六合第一期中的A、C型盆，A、B型罐、A型豆，曲腹杯，舌形足鼎，都是油子岭类型中比较常见的器形，因此六合第一期应属于大溪文化油子岭类型。但是油子岭类型比较常见的圈足盘，在六合第一期却未见到，这可能是由于陶片太碎和太少，不好辨认。六合第一期虽然材料很少，但它是我们在汉东地区第一次发现的以红陶系为主的遗存，为后来在这一地区继续寻找和发掘此类遗存，提供了重要线索。

屈家岭文化早期遗存是这次发掘的重要收获，是继屈家岭下层⑤、朱家咀⑥、放鹰台遗址⑦之后，在汉水地区发现的又一批重要的屈家岭文化早期的资料。其主要特点是，陶器以泥质黑陶为主，墓葬中的主要器形有鼎、曲腹杯、豆、盆、罐、小罐、壶、

盖等，多小型明器。文化层中的主要器形有盆、罐、釜、鼎、曲腹杯、壶形器、碗、盖等。在这批资料中，14座墓葬又可以分为二组，第一组以M3、M4、M5为代表，与此比较接近的有M1、2、6、21；第二组以M9、M10、M11为代表，与此比较接近的有M7、8、24、25。从墓葬登记表中可以看出，两组墓葬的组合关系是有区别的。第一组曲腹杯比例大，多为A、B型，无C型，无壶；除M21有一纺轮外，其它墓均不随葬生产工具；第二组墓曲腹杯比例小，多为D型；鼎多出B型，小罐中C型较多，大量出壶，M24中的C型豆为高圈足，饰成组的镂孔，和屈家岭文化晚期特点接近，多数墓葬随葬生产工具。此外，第二组随葬品的差别较第一组明显，灰陶比例要高一些。这些说明，两组墓间存在着时间上的差别，第二组墓要晚于第一组墓。以上两组墓虽然有以上这些差别，但是陶系和器形方面变化尚不显著，是否具有分期的意义，尚难定论，本报告暂将它们分为前后两段。H16所出的陶片和墓葬相当接近，它们应属于同一时期的遗存。至于屈家岭文化早期文化层中的遗存，情况要复杂一些，以T32⑥和T33⑦等下部地层为代表的遗存，和墓葬、H16较为接近，它们也应属于同一时期的遗存。但以T36⑤和T40⑤为代表的地层，黑陶比例略有下降，器形组合方面也有一些变化，这部分遗存要晚一些，由于文化层中主要器形复原太少，分期工作尚无条件进行。

屈家岭文化晚期遗存是六合遗址中最丰富的部分，它进一步充实和丰富了汉东地区屈家岭文化晚期的内容。墓葬虽然只有六座，但墓坑和葬式清楚，为研究该时期的埋葬制度增添了新的资料；灰坑十四个，出土遗物丰富，对于进一步分析和归纳屈家文化晚期遗存的特征，有重要的作用。

根据遗迹和遗物分析，六合遗址屈家岭文化晚期遗存的主要特点是：1、房基用土

和小卵石屑和铺垫，然后烧烤。2、墓葬为长方形竖穴，葬式为仰身直肢，头朝南。3石器以上窄下宽的中小型石斧为代表。陶纺轮以棱边为主，新出直边和半弧面两种，厚度比屈家岭文化早期要薄，彩陶纺轮较多。4、陶器以泥质灰陶为主，其次为泥质黑陶，纹饰主要为弦纹，镂孔和彩陶，其它纹饰稀少。典型器形有双腹碗，双腹豆、盆形鼎、鸭咀足罐形鼎、壶形器、斜腹红陶杯，宽曲沿深腹盆，矮圈足杯等。以上这些特点和屈家岭遗址同期的遗存基本相同，因此，六合该期遗存应属于屈家岭类型。

六合屈家岭文化早晚期之间，关系密切，晚期地层直接迭压早期地层、早晚关系清楚。从类型学角度看，两期都以泥质陶为主，早期以黑陶为主，晚期以灰陶为主，符合于江汉地区新石器时代陶系发展规律。在纹饰方面，两期都以弦纹和镂孔为主，只是具体形式有所变化。晚期彩陶母题和早期近似，应是从早期承接和演变而来。在器形方面，晚期一些典型器形的初型已见于早期，例如晚期的盆形鼎是从早期的仰折沿盆形鼎发展而来，宽沿深腹盆是从早期的窄沿深腹盆变化而来，因此六合屈家岭文化早晚期间有着比较直接的继承发展关系。

石家河文化时期可分为两期。生产工具方面，石器仍以中小型石器为主，新出现长方形穿孔石刀，纺轮以弧边、扁薄为特点。房屋遗迹仅发现一处，居住面用泥砂等和铺垫，比屈家岭文化晚期进步。陶器方面，两期都以泥质灰陶为主，泥质黑陶次之，有少量泥质红陶。制法仍以手制为主，陶胎普遍增厚，器形不如屈家岭文化晚期精致，多大型陶器。纹饰上，第一期陶器绝大多数为素面，纹饰以篮纹为主，一般为横篮纹，还有

少数方格纹、弦纹、附加堆纹和彩陶。弦纹趋于潦草，不如屈家岭文化晚期规整。第二期有纹饰的陶器所占比例大大增长，其中交错篮纹较多，但方格纹、绳纹、附加堆纹明显增加，流行横切纹、弦纹、彩陶基本消失。在器形上，第一期大多数承袭屈家岭文化晚期，例如双腹碗、壶形器、小口高领罐、高圈足杯、斜壁红陶杯，只是胎骨、纹饰和器形的局部小有变化。新出现了、篮纹盆等器形。第二期器形与第一期相比，变化较大，屈家岭文化晚期的典型器形基本消失，变化较大，屈家岭文化晚期的典型器形基本消失，新出现瓮、盖形器等大型陶器和筒形圈足豆，饰双凸棱或划纹的鼎及鬲等。综合比较两期陶器的特征，可以看出第二期是从第一期发展而来的，但两期间存在着缺环。六合石家河文化中出现的鬲，仅为一块器形陶片的弧证，还需要今后考古发现的证实。

六合遗址西周时期的鬲，其柱足中高，时代大体在西周中期①，文化面貌与汉水流域西周遗存均一致，大体属于一个地方类型⑨，与关中地区相比，风格比较接近。如两地鬲同为瘞裆，制法完全一致⑩。只是汉水流域所出陶鬲多为柱足，陶色以红陶为主，与关中地区以灰陶为主不一致。与楚鬲相比，不同之处在于楚文化的陶鬲裆部不内瘞，为圆弧裆，但二者以红陶为主的风格是一致的⑪。汉水流域是“汉阳诸姬”的属地，周王室为了加强对江汉地区的控制，从周初就十分注重对该地区的经营，通过几次大分封，把一批“周王子孙”分封到这里。六合遗址当是“汉阳诸姬”的活动地点之一。
