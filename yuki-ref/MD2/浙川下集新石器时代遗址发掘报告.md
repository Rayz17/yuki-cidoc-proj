# 浙川下集新石器时代遗址发掘报告

原长办考古队河南分队

浙川位于河南省的西南部，地处伏牛山的南麓。西南与湖北省郧县、均县毗连，西北和陕西省商南县为邻。境内多山，老贯河和丹江由北向南在旧县城东南相会后注入汉水。下集新石器时代遗址坐落在老贯河东岸的台地上，东西长约210米，南北宽约100米，文化层厚4.5米（图一）。

1959年3月，在配合农田水利建设中，长办考古队河南分队，对该遗址进行了发掘，发掘面积725平方米。清理房基5座、灶1座、窑址2座、烧火池2个、灰坑21个、墓葬51座，并获得生产工具和生活用具1000余件。

# 一、地层关系

遗址的地形，呈东高西低的倾斜台地，东部灰层厚达4.5米，西部逐渐转薄至1米左右。从开掘的几个探方来看，该遗址文化堆积可分为三层；（以探方7东壁为例）（图二）。

耕土层：厚0.15米。土质松软，色黄灰，内加杂有烧土块，出土有陶鼎、陶钵，残碎陶片以及现代的砖头瓦块等。

第一层：厚0.25—1.50米。出土有石斧、凿、矛、网坠、弹丸、陶质的纺轮、罐形鼎、弦纹瓮、深腹盆、器盖、杯、豆和鸭嘴、鬼脸鼎足。陶器外面的纹饰有篮纹、绳纹、方格纹、弦纹、划纹、附加堆纹等（图十九）。陶器的颜色以灰色最多，红色次之，黑色较少。另外还发现灰坑5个（H20、21、22、25

# 二、早期（第三层）的遗迹和遗物

# 甲、遗迹

早期的遗迹和遗物较为丰富，出土有房基、灶、火池、陶窑、灰坑等。

（一）房基：共5座，位于遗址的西部，他们的距离相隔6—6.5米左右，其周围设有灶、烧火池和陶窑等。墓地是在居住区的东北部，也有个别墓葬紧临着房基。这些迹象表明住区与墓地似有一定的区分，两者虽有一定的范围，但并不十分严格。

1、房基1和房基2（图四，图五：1）

房基1、2为一座双间房子，叠压在一、二层之下，坐落在第三层之上。房门向东，房内平面近方形，除西南隅被晚期灰沟挖去外，其它保存基本完整，南北长4.90米，房基中间有界墙，把房分为南北两间（即  $\mathbf{G}_1$  和 $\mathbf{G}_2$ ），每间略成长方形，南间宽3.08米，北阔宽1.86米。

该房基位于探方T7内，北距房基1、2约6米，与房基1、2在同一平面上，其形制和建筑手法与上述房基1、2相同。该房基内出土有石斧、石凿、陶弹丸、陶钵、尖底瓶、骨镞。

# 六、结 语

下集新石器时代遗址的发掘，是我省六十年代初期河南考古工作的重要收获，在它之后，1962年至1966年又试掘了浙川县双河镇、黄棣树、李家庄等遗址。1971年5月对浙川下王岗进行较大规模的发掘。从发掘资料上看，下集遗址与下王岗遗址的早一、二期，中期，晚一、二期文化性质基本一样（见《河南浙川下王岗遗址的试掘》《文物》1972年10期）。

下集遗址其文化层明显地包含着“仰韶”、

![](images/8b56f02b5d2e91d45fd1050ffbe8ffc010d88ce2aa4dbc88b50291cd6aa5734f.jpg)

“屈家岭”、“龙山”三个时期的文化层次：晚期一层属于龙山文化，叠压在中期二层屈家岭文化层之上，而屈家岭文化层又叠压在早期三层（三A、三B）仰韶文化层之上。从而可以证明中原地区和江汉地区新石器时代文化发展的相互关系。

通过对浙川下集出土遗物的分析对比，不仅可以看出它们之间有明显的不同文化面貌，还可以看到某些器形彼此之间发展变化的关系。例如：早期（三层）所出土的遗物中，陶器种类较少，以红陶为主，不见黑陶，纹饰简单，除附加堆纹、划纹外，大都是素面。彩陶以黑彩为主，纹样有弧边三角纹、弦纹、米字纹、几何三角纹、圆点纹。这些图案风格，与河南庙底沟仰韶文化比较接近。釜形鼎、盆、钵、束腰陶器座、器盖与庙底沟的  $\mathbf{D}_{30:01}$  釜形鼎、  $\mathbf{A}_{206} \mathbf{H}_{2:19}$  束腰陶器座、  $\mathbf{B}_{80} \mathbf{T}_{135:12}$  器盖等基本相同，说明下集早期文化与中原地区的仰韶文化有着密切关系。但也有些器物如盆形鼎、直壁杯、器盖等，又具有屈家岭陶器的风格，也说明下集早期仰韶文化中已孕育着屈家岭文化的因素。

中期（二层）所包含的陶器中，不仅有

屈家岭文化主要特征的陶器，还具有明显的龙山文化的特点。例如：陶圈足杯、高圈足小陶壶、菌状把手器盖、浅盘高圈足豆、彩陶纺轮、彩陶壶等与屈家岭所出土者基本上类同。该期开始出现的半月形镰、带孔石刀、蚌刀、五角形陶杯、篮纹陶罐、方格纹陶壶等在龙山文化中也常见到。

晚期（一层）所出土的陶器中如：方格纹深腹罐、宽扁足罐形鼎、篮纹瓮、长方形孔圈足豆、直壁小陶杯、不仅与下王岗晚一、晚二期相同、和郑州俎蚤王龙山文化遗址中所出土也基本上类同（《郑州俎蚤王遗址发掘报告》，《考古学报》1958年3期）。

总之，通过上述出-土器物的比较，我们可以看出，下集遗址早、中、晚三期，从发

展的顺序来看，它们之间存在着相互联系，承上启下直接发展的关系。文化的发展不是孤立的，江汉、中原两个地区诸文化之间有密切的联系，据现有发掘资料来看，屈家岭文化北抵河南南阳、淅川、内乡、镇平一带，河南龙山文化南达湖北郧县、均县一带，二者在发展的过程中，延伸到豫南浙川一带相互重合。目前已在下集、下王岗、黄棣树地层叠压上发现“仰韶”、“屈家岭”、“龙山”的叠压关系。

# 明代青花假腹碗

河南省文物商店在近几年的文物征集中，于郑州收购了一件较珍贵的传世文物——明嘉靖时期的青花假腹碗。该碗通高7.5、口径15.5厘米，胎质肥厚，釉色白中闪青，青中泛紫，光泽莹润，异常艳丽。器口、近底腹部及底足一周均以双线条勾勒。器内有对称的团菊花四朵，花朵两周规则的饰以草叶纹。器外腹中部，有三只狮子，脖系绸带，作奔驰状；空间处，上饰小云朵纹，下画小草纹。整个画面用写意手法，布局错落有致。这件器物的胎质、釉色、图案，具有明嘉靖时期青花瓷器的明显特征，是一件不多见的珍品。其独特之处在于双层底。上层底设在碗腹中

部，圈足底部（即下层底）中心有一圆孔，两层底间隔约3厘米。传说这种碗是诸葛亮所发明，俗称“诸葛碗”或“诸葛亮碗”。
