# 湖北黄梅陆墩新石器时代墓葬

中国社会科学院考古研究所湖北工作队

# 一、前言

陆墩遗址位于湖北省黄梅县东南部的龙感湖中，归属北岸的下新镇管辖，两地直线距离约7公里。东与安徽省宿松县接壤，南临长江与江西省九江市遥望(图一)，陆墩以北一片湖面，另称源湖，湖水较浅，遗址孤立于湖中，为一处荒芜的漫坡小土墩，经常被水淹没或略露出窄条墩顶。冬春枯水季节，当湖面海拔在12.02米时，露出水面的土地范围，东西长约150米，南北最宽处(东部)约70米，墩顶高出水面半米多，全形近似西窄东宽、北凸南凹的弯镰状。表层土质较硬，地表散布的少量陶片都被冲刷得缺乏棱角，一些地方夹杂有螺壳碎渣。为了鱼类生长和灌溉用水等需要，不让湖水随便外泄流入长江，而通过数处闸口控制湖中水量。同时，即使在枯水期，水位也很不稳定，因刮风引起的湖水浪潮，顷刻便会使已经露出水面的土墩漫坡地浸淹大片。

最初于1958年9月，全县文物普查中发现了陆墩遗址。同年，经湖北省博物馆核检，确定为新石器时代遗址。后经主管部门批准定为县级保护单位。1983年春黄冈地区文物普查工作队做过调查，并发表了简报①。1986年5月6日和12月10日，中国社会科学院考古研究所湖北工作队两次调查。1987年3月4日—18日，湖北队进行第一次发掘。发掘地点位于土墩东北部的墓地，分南北两片同时进行，揭露面积155平方米，清理墓葬21座(图二)。我队的调查和发掘工作，都得到了湖北省、黄冈地区和黄梅县、镇各级

有关主管部门的支持，黄梅县博物馆予以具体协助，在此一并致以深切谢意。

# 二、墓葬概述

墓葬21座。一般铲去数厘米的薄层地表土后，即显出墓坑口，个别墓葬的部分器物已稍露出地表。坑底距地表的深度，浅者仅存0.1米，深者可达1.48米。墓坑形状为长方形竖穴，长1.5—3.39、宽0.5—1.65米；坑壁多竖直。填土普遍为杂质深灰土或杂质黄灰土，其土色一般都与坑外棕色生土层有别。5座墓葬近底部四周还有熟土二层台（M3、5、20)或生土二层台（M2、19)，二层台宽0.1—0.5米，现高出坑底近0.1—0.73米，使墓坑中形成一个窄长的人架坑。M12儿童墓坑北部，为高约0.12米的低矮熟土台，与坑等宽，长0.67米，占墓坑全长的1/3。M2人架坑两端散布有薄层青膏泥。M1人骨下断断续续发现极薄的草木灰烬，M2人骨下是微含草木灰烬的黑色泥土。

墓中人架普遍不是规整的样子，骨骼也不齐全，有些缺失较多。深坑中的骨殖保存较好，大部分墓主遗骨酥软，有些粘附土上仅能剔出大致轮廓。人架都是头在北，5座能辨面向的分别为向前(南)、朝上、朝下和朝东。其中特殊的是M17，头骨已翻转，面部朝下，枕部大孔朝上，颌骨在北，缺下颚骨，其他四肢骨、盆骨等也错动移位很大。从十多座墓尚存较多主要骨骼的相对位置观察，大体呈仰身直肢状，唯一些骨骼明显错位或较凌乱，但又确实不是受破坏性的扰动所致。我们认为，不能把这种普遍现象一概归之于自

# 四、小结

陆墩遗址现处地理环境特殊，在不同寻常的工作条件下，对墓地进行了初次发掘。从已经清理的21座墓葬看，墓坑清楚，形状规整，都属长方形竖穴土坑，并非不挖墓坑的平地堆土葬。每坑一人，头向东北。尤为突出的是，这里普遍实行一种大体仰身直肢姿势的二次葬，它有别于把尸骨捡聚成堆的二次葬形式，这为我国新石器时代的葬俗增添了内容。在个别墓中，发现有明显使用木质葬具的痕迹。无论死者成年与否，各墓普遍放置随葬品，数量不等，种类也有些差异。主要是陶器，基本上属实用器，多放在脚部附近。以陶壶为最多，较常见的还有鼎和豆。甑都与鼎共存。纺轮与斧钺基本不同出。此外，有4座墓分别在坑底或填土中，随葬猪下颚骨、兽骨和鱼骨。

黄梅东与安徽毗邻，陆墩遗址与皖西南的潜山薛家岗②、望江汪洋庙等遗址关系密切。陆墩碟形豆与薛家岗第三期碟形豆和一部分盘形豆的豆盘形式，有近似之处。两者不同的地方主要是，陆墩豆把较矮，未见镂孔，圈足面呈球面或高台座式；薛家岗豆把高，普遍镂孔，圈足大体呈喇叭形而在足底略起低台。两地钵形豆的形制也与上述情况类似。陆墩Ⅱ式矮领壶M20:1、III式高领壶M11:4，分别与薛家岗第三期IV式壶T

8④:28、VII式壶M46:1相比较，外形都较接近，但也存在局部差异。盆形甑在陆墩出土多件，在薛家岗发现一件(M31:4上部)，两者腹壁的弧斜程度、器底算孔和圈足高矮稍有差别，陆墩另有凸平底无圈足的一种。陆墩的圆腹罐形鼎，与薛家岗第四期鼎T8③：86的器形纹饰一致。陆墩ⅢI式扁折腹釜形鼎，与汪洋庙上层的Ⅱ式釜形鼎，也有部分相同之处。此类釜形鼎不见于薛家岗第三期，当属晚于薛家岗第三期的遗物。陆墩还发现了粗泥夹植物陶卷边足鼎、小口高领大罐、贯耳壶等新器形。篮纹在薛家岗第三期已露端倪，陆墩中数量有所增加。从陆墩出土器物较多的墓葬中可知，上述陶器具有一定的共存关系。因目前发掘材料有限，初步认为，陆墩这批墓葬遗存，主要的已进入归属薛家岗遗址第四期文化的范畴，并从陆墩可以窥见它既从薛家岗文化演变而来、两者有一定联系的重要线索。

陆墩出土的贯耳壶，表明与长江下游的良渚文化曾有联系。陆墩的直口盆形鼎，含有受江西樊城堆文化直接影响的因素。陆墩也发现了成人拔齿的现象，在广泛分布于我国东南部的这一文化习俗圈中，又增加了新地点。一些迹象透露出，处于长江中下游之交的陆墩遗存，吸收了其他几种原始文化的营养，从而丰富了自身的内涵。

江西省地矿局九一六地质大队刘荣贵、本所潘其风、周本雄先生，分别鉴定了石器岩性、人骨和猪骨，谨志谢忱。
