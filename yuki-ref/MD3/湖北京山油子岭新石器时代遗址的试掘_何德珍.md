# 湖北京山油子岭新石器时代遗址的试掘

# 湖北省荆州地区博物馆

油子岭遗址位于京山县钱场镇钱场村一组，北距县城约25公里，天(门)——京(山)公路从遗址的东边通过(图一)。遗址北端高出地面5米多，其他三面为漫坡，面积两万余平方米。

该遗址于1982年全省文物普查时发现，由于当地农民建窑取土，遗址遭到很大破坏。为了解遗址的文化内涵，1985年冬荆州地区博物馆会同京山县博物馆在遗址的西北边缘进行了试掘。开  $5 \times 5$  米的探方四个，编号T1—T4。共清理墓葬11座，灰坑4个。出土遗物较多，可分为三期，以第一期文化遗存为主体。现将此次发掘情况报告于下。

# 一、地层堆积

试掘地点保存情况较好，下面以T1西壁剖面(图二)为例说明。

第1层：耕土层。浅灰色，厚20—40厘米。此层下发现墓葬6座，随葬陶器均以折

沿圈足罐、豆为基本组合。据其特征可分为两组，第一组与第一期文化遗存的地层所出同类器基本相同；第二组属于第二期文化遗存。

第2层：灰色粘土，厚40—55厘米。质较松软，含零星红烧土粒。出土陶片较多，可辨器形有鼎、折沿圈足罐、红陶盘、器盖等。

第3层：浅黄色土，厚约50厘米。出土物少，器形有小鼎，折沿圈足罐、豆、圈足盘、卷沿盆、矮钮器盖等。

第4层：分为4A、4B两小层。4A层为红烧土层，厚25—65厘米，出土少量陶片；4B层为灰黄色土，厚10—25厘米，出土大量陶片。

第5层：分5A、5B两小层，出土大量陶片。5A层为深灰色土，厚约25厘米；5B层为灰黄色土，厚约20厘米。

5B层下即为深黄色生土。

# 二、第一期文化遗存

第一期文化遗存包括探方的第2层一第5层，发现灰坑1个，墓葬4座。出土大量陶片，但复原的器物不多。

# 1. 灰坑

H3 位于T3北壁边缘，一半在探方外，未作扩方清理。开口于第3层下，打破第4层。坑口呈椭圆形，剖面为锅底状。长、宽均0.3、深0.11米。坑内填土黑色，含大量草木灰烬，包含物少，复原陶釜1件。

# 2.墓葬

4座，编号为M5、M8、M10、M11，均开口于第1层下。M5、M11位于T1，M8位于T2，M10位于T4。发现时都只见成组的陶器呈南北向排列在一起，墓坑界线辨别不清。骨架已腐朽无存，葬式不明。每墓随葬品2—8件，共出陶器17件，基本组合为圈足罐、豆和碗。

# （2）陶器

全部为生活用品。陶系以红陶为主，黑陶次之，灰陶极少。以T1第5层为例：泥质红陶占  $54\%$  、夹砂红陶占  $18\%$  、夹碳红陶占 $6\%$  、泥质黑陶占  $15\%$  、夹砂黑陶占  $2\%$  、泥质灰陶占  $3\%$  、夹砂灰陶占  $2\%$  。第3层黑陶比例则有明显增加。素面陶器较多，纹饰有镂孔、弦纹、戳印纹、按窝、浅附加堆纹、刻划纹、压印纹及少量彩陶(图四，1一8)。镂孔多为圆形，长圆形和三角形极少，主要饰于圈足上；弦纹饰于罐的腹部和器盖上；按窝饰于鼎足根部；戳印纹有点状、圆圈、指甲形几种，以戳点纹数量最多，成组饰于豆、圈足罐、盘的腹部；刻划纹和压印纹主要饰于盆、罐的腹部。彩陶有蛋壳彩陶和厚胎彩陶两种。蛋壳彩陶在橙黄、灰和灰黄地色上绘黑彩，饰于杯、碗的口沿内、腹部与器底，图案由横带、点、菱形格子、曲线、斜线和豆荚纹组合而成。厚胎彩陶极少，为红地和白地黑彩，纹样有圆点、弧线三角。主要器形有鼎、釜、罐、豆、盘、盆和器盖等。

# 五、结语

油子岭遗址包含大溪文化和屈家岭文化两种遗存，它们之间虽存在缺环，但发展关系还是有迹可寻的。

第一期文化遗存的主要特征是：陶系以泥质红陶为主，大部分属粗泥陶。器表多施红衣，少数陶器外红内黑或外红内灰，黑陶绝大多数磨光。主要纹饰有圆镂孔、弦纹、按窝和戳点纹。以戳点纹最具特色，类似篦点纹，普遍饰于A型罐、C型罐、豆、C型盘、A型钵的口沿和腹部。蛋壳彩陶也是此次发掘的重要收获。典型器有鼎、釜、圈足罐、豆、盘、盆、碗、蛋壳彩陶杯等。其中B型鼎、A型釜、C型罐、D型罐、B型盘、C型盘具有鲜明的地方特色。此外的诸多因素与大溪文化相同和接近。

第二期文化遗存局限于墓葬。器类少，组合简单。泥质黑陶占绝大多数，未经磨光。纹饰有镂孔(多数长圆形)、弦纹两种，不见一期的戳点纹。主要器形如子母口豆、折沿圈足罐、器盖，可看出是由一期的同类器发展而来。其文化特征与公安王家岗①、钟祥六合②等遗址的屈家岭文化早期遗存基本相似，其年代则应稍晚。

第三期文化遗存所出的罐形小鼎、双腹碗、壶形器、彩陶杯、纺轮等主要器形，同属江汉地区屈家岭文化晚期遗存。

油子岭遗址的试掘，对大溪文化和屈家岭文化的深入研究提供了新资料。目前，对一期文化的定性问题，有关专家、学者存在不同看法。据现有资料粗浅分析，本文赞同张绪球先生的观点，将一期文化暂定为“大溪文化油子岭类型”⑧，这一观点有待今后更多发现的不断完善。至于一期文化的相对年代，
