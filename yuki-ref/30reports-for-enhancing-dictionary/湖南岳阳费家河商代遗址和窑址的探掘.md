# 湖南岳阳费家河商代遗址和窑址的探掘

# 湖南省博物馆 岳阳地区文物工作队 岳阳市文管所

费家河是一条由东向西注入洞庭湖的河流，河口在岳阳市南40公里。

1972年，黄秀桥公社曾名大队在距河口十多公里的费家河北岸兴修渔池，掘出一件商代铜饶①，省博物馆当即派人在其附近进行调查，于铜饶出土地点西400米处一个叫水庙咀的河滩上发现了多个红烧土坑，清理了其中的一个，确认为陶窑，编号为Y1。在Y1中出土了一件完整的夹砂红陶大口缸。1981年12月，岳阳地区文物工作队在水庙咀清理了陶窑10座，编号为Y2—Y11。1982年5月，省博物馆、地区文物工作队、市文管所协同进行了调查发掘。参加调查发掘的还有武汉大学考古专业78届学生二人。这次，在费家河的支流青龙河口东西两岸又发现了多处陶窑。计有：水庙咀(包括原已发掘的)17座，双燕咀6座，扑拜咀4座，杉刺园3

座，窑田子4座，王神庙29座，总计63座（图一）。先后共清理了其中的32座，计：水庙咀17座（编号Y1—Y17）、双燕咀6座（编号Y18—Y23），扑拜咀3座（编号Y24—Y26），王神庙6座（编号Y27—Y32）。

# 一、窑址

由于河床和水位的抬高，窑群所在地的地貌不断发生变化。现在，水庙咀、双燕咀、王神庙为坡度很小的河滩；扑拜咀、杉刺园、窑田子为高出河面约2一3米的台地。

陶瓷排列整齐，往往成组排在一条直线上。如水庙咀一排7座，双燕咀一排6座（图二）。王神庙有19座窑分两行排列，窑室间距离最远不超过1米，最近只有0.2米（图三）。

已发掘的32座窑，有两种形式。一种为圆形竖穴窑，28座。另一种为“8”字形窑，4座。

圆形竖穴窑中以Y19最大，口径0.8、底径0.64、深1.4米。底部积有厚0.45米的炭渣、草木灰，其上堆积灰褐色土和红烧土，内杂少量夹砂红陶片，再上则是倒塌的窑壁和扰乱土层。窑壁敷草拌泥，厚10一12厘米，经火焙烧，呈棕红色，上部硬度较大，下部与窑底基本垂直，底平整，硬度小。双燕咀一行6座，全是圆形竖穴窑(图四)。烧造方法推测为：在窑底先铺上一层厚谷壳或其它植物籽实的壳，作为基本燃料，其上放置三、五件陶坏，然后在陶坏的周围和上面填充谷壳、植物籽实壳、木柴、稻草等燃料，一次点火，不再补充燃

料, 焙烧三、五日, 即可烧成。用这种陶瓷烧造的陶器, 据湖南省礼陵陶瓷研究所和岳阳瓷厂鉴定, 火候大概在  $600^{\circ} \mathrm{C} - 700^{\circ} \mathrm{C}$  之间。圆形竖穴窑中最小的一座是 Y27, 窑口径 0.44、深 0.96 米, 底部炭渣厚 0.3 米。

“8”字形竖穴窑4座，都在水庙咀。与另外三座圆形竖穴窑排成南北向的一排，每两

座间距离为0.2米左右。窑室大小基本相近。以Y3为例，全长1.24米，窑室直径0.84米。窑壁棕红色，上敷一层草拌泥，厚0.1—0.12米，经火焰烧。火口呈新月形，火口下有梯形竖穴窑门，高0.58米，火膛紧与窑门相连并伸入窑室。窑室内有半月形窑台，高出窑室底部0.12—0.18米，是放置器坯的地方。无火道和窑算。窑壁略有弧度。壁上部封顶及出烟口已破坏。窑壁残存高0.66米（图五；图六）。窑内充满淤泥，内杂大量烧土、灰烬、炭渣、夹砂陶片、硬陶片及少量釉陶片，器形有大口缸、鼎足、硬陶盘等。这种类型的窑具有添柴、鼓风的功能，属封闭式窑，火候可到 $1200^{\circ}C$  左右。

在清理的32座陶窑中，出土陶片540片，其中最多的是夹砂红陶，其次是红胎黑皮陶。硬陶占  $10\%$  左右，釉陶占  $2\%$  。器形、纹饰与王神庙H1所出相同，应是同一时代的文化遗存。因此，陶窑中出土的可以复原或比较成形的器物，将和H1中所出器物一并介绍。

# 二、灰坑(H1)

王神庙在青龙河河口西岸，与双燕咀隔着600米宽的河面，现属岳阳市友爱公社金星大队，为坡度极缓的河滩地，稍一涨水即可全部淹没。

灰坑在王神庙之西南，东距窑群仅6米。呈椭圆形，南北径5.72、东西径5、4、深0.7米，呈锅底状。地表草皮铲除后即露出坑口。坑内依土色的变化可分为上下两层。上层为灰褐色土，内含较多的红烧土块，厚5—15厘米。下层为松软的黑灰土，最厚处达65厘米。上下层出土物无十分明显的区别。

胎黑皮陶、硬陶、夹砂灰陶、泥质灰陶、泥质红陶、细砂灰白陶。夹砂红陶占全部出土陶片总数的  $60\%$  以上。H1上层夹砂红胎黑皮陶略少于硬陶（分别为  $6\%$  和  $10\%$ ），下层夹砂红胎黑皮陶多于硬陶（分别占  $10\%$  和  $2.4\%$ ）。其它陶系所占比例甚少。夹砂陶一般砂粒极细。硬陶火候很高，叩击出铿锵声，表面为灰色或灰白色，胎质有红、灰、灰白和白色等种。其中白胎硬陶质地极细腻，颜色白洁纯净，从外观看与以后瓷器的胎质几无区别。化验了灰坑上层的一片标本，成分为  $\mathrm{SiO}_2$  占  $72.12\%$

绝大部分器物上都饰有方格纹，一般均细密规整，印痕较深。此外，还有绳纹、梯格纹、凹凸弦纹、划纹和极少的附加堆纹。绳纹除饰于部分罐釜形器外，主要见之于大口缸近底部，有粗细绳纹和分段绳纹。梯格纹见之于釜、瓮类器。凹弦纹常见于豆柄和盘口。硬陶上多施弦纹、刻划的斜线纹、水波纹、偶见曲尺纹和浅云雷纹。

器形主要有大口缸、鼎、罐、釜、瓮、豆、盘、钵等，硬陶有盘、瓮。

大口缸 依器底计算，共57件，均为夹砂红陶。敞口，口沿下有凸棱，深腹近直，底呈管状或短柱状。器身大部饰规整的方格纹，近底部饰绳纹。可分二式。

I式：敞口，尖唇，管状底。Y1:1，口径25.6、通高30.4厘米(图七，4)。Y3:1，器身较肥，口径30、通高28厘米(图七，5)。H1（上）：1，体型较瘦长，管状底，外形似锥柱。口径24、高30.8厘米(图七，7)。

II式：实心短柱状底，口微侈近直，平沿方唇。H1（上）：2，口径28、高32厘米（图七，6)。I、II两式数量接近。无论在灰坑和陶窑中，大口缸都是最常见的器物。其用途有人说是水器，有人说是熔铜的坩埚。在H1中，部分缸底内有黑色烧结，显然比外表更硬，火候更高，似经烧灼，因此，不能完全排除用作坩埚的可能，也许两种用途兼而有之。

# 四、结语

费家河的窑址和遗址中都大量出土夹砂红陶大口缸。此式缸，很近似于郑州人民公园和殷墟所出的“将军盔”。与黄陂盘龙城、石门皂市、郑州二里冈所出相比，时代显然要晚。但，据目前所见材料，这种缸，到西周即已消失。因此，我们认为费家河遗址和窑址，时代大概相当于中原商代晚期。

与澧水流域和湘西北其它时代相近的遗址比较，费家河所出硬陶比例显然要大，刻划的水波纹、曲尺纹以及梯格纹，具有地方特点。各种形式的圜底罐、宽沿釜、浅盘方格纹豆、硬陶折肩瓮、敞口圈足硬陶盘，特别是釜形扁平足方格纹鼎，很能反映它的文化特征。这里所出的折肩桥形耳硬陶瓮，在湘东的浏阳曾经出土。这里所出浅盘细高柄豆，在长沙杨家山商周时期遗址里也能见到②。这里所出沿内有环状耳的陶釜，虽难以找到完全相同的器形，但在江西鄱阳湖区和赣江流域商周时期遗址中有相似作风的其它器形。由于鄂东南、赣西北商周时期遗址发掘不多，因此，尚难以全面与之进行比较，不能确定文化面貌相似的程度。但费家河遗址和窑址，应是能代表湘江下游商周之际的一种地区性文化的。
