# 上海市金山区招贤浜遗址发掘简报

# □ 上海博物馆考古部

招贤浜遗址位于上海市金山区亭林镇（图一）。它发现于1973年，原名为张堰口遗址，确认为新石器时代和商周时期的文化遗址①。后因遗址附近新开河名，更名为招贤浜遗址，1984年被公布为上海市文物保护地点②。2003年3月，为了配合上海郊环高速公路南段工程，上海博物馆考古部对遗址进行了调查和试掘。试掘按照坐标法布方，将遗址划分

为I、II、III、IV四个发掘区，共开4米  $\times 4$  米探方5个，4米  $\times 5$  米探方2个，1米  $\times 5$  米探沟16个，发掘面积共200平方米。发掘出土了大量马桥文化遗存和少量西周——唐宋时期的遗物，现将发掘收获简报如下。

# (二)遗物

有陶器、石器等，以陶器的数量最多。

# 1. 陶器

根据质地，陶器分泥质陶、夹砂陶和少量的硬陶陶片与原始瓷片。泥质陶有泥质红陶、泥质灰陶和泥质黑陶。其中泥质红陶数量最多，占陶系总数的 $48\%$  左右，罐类是其主要器型。泥质灰陶和泥质黑陶的数量占  $20\%$  左右，主要器形有盆、豆、盏、蝉、觚、尊和器盖等。夹砂陶有夹砂红陶和夹砂灰陶，大部分含砂粒较粗，鼎、赢是其主要器形。硬陶数量较少，因为胎质较硬，火候较高而称之，颜色有灰褐、红褐、紫褐等，主要器形有鸭形壶、豆等。

陶器装饰，夹砂陶的鼎和甑的器身以绳纹为主。泥质陶的纹饰主要有条格纹、篮纹、绳纹、叶脉纹、折线纹、

方格纹、席纹等，在篆等器物上见有少量的云雷纹（图五）。在少量陶罐口沿的沿面上，发现有刻划陶文，根据观察，皆为入窑焙烧前刻划的（图六）。

# 四. 结语

马桥文化是夏商时期分布于环太湖地区一个考古学文化，其典型遗址就是位于上海市闵行区的马桥遗址③。近年来，发掘面积较大的马桥文化时期遗址有浙江湖州昆山遗址与钱山漾遗址等④，其他遗址已发表的发掘资料较少。招贤浜遗址的发掘，丰富了马桥文化的内涵，为了解上海地区马桥文化的分布提供了新的资料。

本次发掘表明，招贤浜遗址中心区域主要分布于现在招贤浜的两侧，面积大约在1万平方米左右，遗址的堆积以马桥文化为主。值得注意的是，1975年的考古调查采集文物中，曾发现有新石器时代良渚文化的陶片，但是本次野外工作，在已发掘的范围

内未见新石器时代遗存。

招贤浜遗址的马桥文化遗存的文化内涵与马桥遗址十分相似，它不仅体现在遗物所反映出的纹饰作风、制陶技术等特征上，其器物形制基本上也能在马桥遗址中发现相似类型。如招贤浜遗址的D型小盆，下腹近底部内凹弧曲较大，底部周缘凸脊较明显，与马桥遗址的Da型Ⅱ式小盆特征相似，鲜，假圈足处弧曲明显，与马桥遗址Aa型鲜Ⅱ式器型相近因此，招贤浜遗址大体与马桥遗址的前段相当，属于马桥文化早期遗存。招贤浜遗址也有少量的马桥文化晚期遗物，如AⅡ式鸭形壶，高颈，扁圆腹，高圈足，形体瘦高，“尾部”弱化，是探讨马桥文化晚期遗存的重要线索，但是由于招贤浜遗址发掘面积较小，出土遗物较少，无法作进一步的分期研究

招贤浜遗址中还出土了少量西周——唐宋时期的遗物，其中有一件完整的宋代白瓷瓜棱罐比较珍贵。然而，遗址中没有发现这一时期比较单纯的地层堆积，可以确认的遗迹也仅有一座晋唐时期的水井。但是，这些零星的发现也为了解当时上海地区古人类的活动提供了重要的线索。

# 本期导读

# 一.《上海市金山区招贤浜遗址发掘简报》

马桥文化因最早发现于上海马桥遗址中层而命名。从年代上来讲，马桥文化紧接着良渚文化，但文化面貌上截然不同，马桥文化继承了少量良渚文化的文化因素，但整类良渚文化因素在马桥文化中不占主导地位。研究成果表明，马桥文化来源于浙西南山地的原始文化，同时它还包含了山东地区的岳石文化、中原地区的二里头文化因素。对照中原地区的王朝序列，马桥文化的年代大致与中原的夏和商相当。《简报》中招贤浜遗址的堆积以马桥文化为主，从遗物的纹饰特征、制陶技术、器物形制分析，属马桥文化早期遗存。也有少量的马桥文化晚期遗物。由于发掘面积有限、出土遗物较少，进行分期研究尚有难度。尽管如此，招贤浜遗址的发掘丰富了马桥文化的内涵，为了解马桥文化在上海地区的分布提供了新的资料。

# 二.《江西宜丰县秋形坳商周遗址发掘简报》

赣西的萍乡、宜丰、万载等县市在以往的文物调查工作中屡有商周遗址的报道，现经正式发掘的有萍乡禁山下、宜丰秋形壻两处商周遗址。萍乡禁山下遗址文化堆积保存较好，共分三期，第一期为新石期时代晚期，距今约  $4000\sim 4500$  年；第二期文化是在第一期文化发展而来的，同时又受到同时期来自北方中原文化因素的影响，其绝对年代为夏～早商阶段；第三期文化则发生了明显的变化，除了在少数器物中能找到一、二期的身影外，主要文化面貌均为西周时期(详见《考古》2000年第12期)。秋形壻商周遗址由于雨水冲刷厉害，上层为春秋时期遗物，保存较好的为下层商代文化堆积层，器物组合大体为鼎、鬲、釜、甑、豆等，平底器为多，次为圜底器，少量圈足器。在《简报》中，作者对器物流行的带耳作风作了较详尽的分析，并和同时期万年类型器物流行带鳖或捉手的作风进行比较分析，得出装饰风格上与万年类型接近，器形和纹样方面接近吴城文化类型，同时在纹样装饰(块状方格纹、田字纹、粗方格纹等）、制造手法(大量流行带耳器，在器内口沿与器腹交接处饰立耳)上又有自己的风格的结论，据此作者提出该遗址所表现出来的文化面貌是否有别于江西吴城、万年类型文化而属于另一个类型文化，虽然该推论尚有待于在今后的工作中进行进一步论证，但无疑为今后赣西先秦遗址的发掘、研究和编年序列的建立提供了新的思路。

从赣西现有的发掘资料看，秋形坳商周遗址根据器形、装饰及纹样分析，其绝对年代相当于吴城二期偏晚阶段，该遗址从分期上可与萍乡禁山下遗址在时代序列上互为补充，但由于发掘资料尚不丰富，它们各自的发展脉络、相互之间的关系尚不清晰，需要我们今后的工作进行补充和完善。

(樊昌生 王上海)
