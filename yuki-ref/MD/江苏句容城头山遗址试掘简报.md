# 江苏句容城头山遗址试掘简报

# 镇江市博物馆

城头山遗址位于句容东北约5公里处的句容水库内，现为高出水面略呈椭圆形的小岛，表面平坦，南北长约150、东西宽约200、顶面海拔高度为30米（图一）。该遗址于1957年文物普查时发现①。当时，水库尚未修筑，遗址所在地为高出地面7米的土墩，墩下周围为水田和沟渠。1958年，遗址被圈入水库后，保存情况尚好，只是边缘缓坡常年受水浪的冲击，多坍塌露出断面。

1981年6月3日至15日，镇江市博物馆在遗址东南部试掘探方一个，编号为  $\mathbf{T}_{1}$  ，面积  $3\times 10$  米，后因发现灰坑H4，又向西扩方 $3\times 4$  米，试掘面积共为42平方米。

米，现以北壁剖面为例，说明其地层的堆积。

第一层：耕土，灰黄色，松软厚约20一28厘米。

第二层：黄灰色，质较硬，厚约80—108厘米，所含遗物以陶器为主，有夹砂红陶、泥质灰陶、泥质黑衣陶、泥质红陶以及硬陶、原始青瓷，器形以鬲、鼎、罐、盆、盘、豆为多见，还有少量的碑、刀等石器。

第三层：夹片状灰土，含较多的草木灰，厚约40—80厘米，出土遗物与第四层一致，数量较少。

第四层：棕色土，质较松软，厚约80—100厘米，出土器物以鬲、罐、刻槽盆、粗砂缸、钵、豆等为主，石器有碑、斧、半月形刀等。

第五层：黄色土，土质硬，厚约30—45厘米，陶类中有夹砂红陶、泥质灰陶、泥质黑衣陶和泥质红衣陶，不见硬陶和原始青瓷，器形有鼎、瓶、罐、豆、杯等；其下为生土（图二）。

根据地层关系及所出遗物的特征，文化层可分为三层：第一文化层为耕土下面的黄灰土层；第二文化层为棕色土及其上之夹片灰土层，因棕色土下部存在一层较薄的堆积，表现出早期特征，故第二文化层又分为二层，上层为2A层，下层为2B层；第三文化层为黄土层。

# 五、结语

1.第三文化层所出的I式小口垂腹鼎、I式和II式小口广肩圆腹罐、宽沿灰陶盆、花瓣足杯、矮圈足碗、刻槽盆、鸟饰弧面形盖、多种

型式的带流器以及施凸弦纹和鸡冠状把手，泥质灰胎红衣陶在各类陶中占有相当的比重，这些都与崧泽遗址中层的晚期墓葬遗物特征一致②，而夹砂陶凿形足亦与草鞋山崧泽墓葬（M60:1）设宽腰沿、内置承簞凸棱的结构相近③；同时，另有一部分遗物如I式扁三角形足、平底杯、罐式匝等又曾见于张陵山遗址上层④。因此，我们认为第三文化层的时代，大致相当于崧泽文化晚期，至于其中的罐式匝、绳索状器耳等已含有良渚文化的成份。

2. 第二文化层的 2B 层, 虽然堆积薄, 遗物少, 但所表现的早期特征还是比较明显的。圆锥形或扁三角形多目式鼎足、瘦长身高弧裆式, 与二里头晚期的鼎、特点类似; 而竹节状豆、刻竖向细槽纹的刻槽盆以及单线或多线的弦切纹, 又保留有新石器时代文化的遗风, 至于多弦切纹, 无疑是后来流行的梯格纹的雏形。

2A层，文化堆积厚，造物丰富，内涵属典型的湖熟文化。其中，以Ⅱ式鬲、各种陶质的刻槽盆、扁耳硬陶体、角状把手及大量梯格纹装饰等最富于地方特色；而I式鬲、直口深腹小底粗砂缸、浅细套方格纹的硬陶器以及蚌刀等，都与二里冈二期的同类器物一致⑧。

看来，2B层延续的时间较短，大致相当于早商时期，2A层则相当于中原商代中晚期。

3. 第一文化层的遗物属湖熟文化的晚期，其带角状把手屑、高档半实心足、Ⅱ式和Ⅲ式盘、溜肩深腹瓮、小口垂腹瓿、圈足豆、青铜以及盛行的几何形组合纹饰等，都与江南西周土墩墓的遗物相同⑦，其时代亦相当于中原西周时期。

# 三、D4基址的建筑使用年代：

此次发掘，在不少灰坑、窖穴中出土了一定数量的木碳，我们均做了收集。在  $\mathbf{C}^{14}$  绝对年代数据还未公布之前，只能依据文化层及

遗迹现象的相互叠压与打破关系，推测其相对年代。此次发掘范围之内，地层堆积比较简单，文化层堆积与各种遗迹相互之间的时代关系清楚。直接叠压在D4基址之上的第4层堆积属商代文化层，据出土器物判断，其时代属二里冈上层时期；清理的38个商代灰坑、窖穴、水井，均叠压或打破D4基址，其时间早晚虽有所区别，但也均属二里冈上层时期。应特别提及的如H12，其坑穴已毁坏了南庑的夯土隔墙，时间显然应在D4建筑停止使用之后。为保持D4基址的完整，此次清理仅利用汉代破坏沟对基址进行了局部解剖。在基址的下面没有发现文化层。能表明基址的建筑、使用年代的夯土、路土内的遗物甚少且碎。目前，只能说D4基址的建筑，使用年代早于二里冈上层。

J1规模宏大，总面积达四万平方米以上，D4基址面积约1600平方米，仅占J1的二十五分之一。我们相信，随着J1整体的揭露，一座宏伟的商代前期宫城基址将展现在人们的面前。
