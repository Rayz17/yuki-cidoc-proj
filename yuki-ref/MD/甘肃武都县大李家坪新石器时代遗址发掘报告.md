# 甘肃武都县大李家坪新石器时代遗址发掘报告

北京大学考古学系

甘肃省文物考古研究所

武都县地处陇南白龙江中下游的秦岭谷地，属凉亚热带季风气候，无霜期达8个月左右，年平均降水量500毫米以上，是甘肃省降水最多的地区。地表起伏较大，以“山大沟深”著称，一般在河流两岸，尤其是两河交汇处，有发育较好的台地，是古代先民生存和物业发展的良好场所。

大李家坪遗址即位于武都县马街乡东约2公里的大李家村北峪河南岸的二级台地上(图1)，南依中梁山，北隔河为略武公路。大李家坪自东向西由庙坪、安坪、张坪3个小台地组成，中间被冲沟隔开。遗址海拔约2200米，东西长约500米，南北宽约300米，面积达15万平方米，地貌基本呈南高北低的斜坡状。多年来，修造梯田等活动对遗址破坏较严重，在梯田断崖上常见有灰层、灰坑和红烧土分布。文化堆积通常厚1米~4米，文化遗存分布的特点一般是早期遗存距河岸较近，晚期遗存距河岸较远。长江流域规划办公室考古队甘肃分队和甘肃省文物考古研究所等单位分别于1974年和

1988年对大李家坪遗址进行过两次调查[1]，对遗址的文化面貌已有初步的了解。1995年春季，北京大学考古学系和甘肃省文物考古研究所、武都县博物馆合作，对大李家坪遗址进行了为期2个月的正式发掘。分别在庙坪和安坪发掘了9条探沟和探方，揭露面积达200平方米，发现有灰坑、窖穴等遗迹，并出土了大量陶器、石器、骨器等遗物，为陇南白龙江流域新石器文化的研究提供了一批重要的实物资料。

参加这次发掘工作的有甘肃省文物考古研究所的王辉、北京大学考古学系硕士研究生张强禄，以及武都县博物馆的杨万华、郭伟洲等同志。

# 一 文化堆积

庙坪和安坪均为南高北低舌形斜坡状黄土台地，庙坪北缘距北峪河南岸约200米，与现河床高差约50米左右；安坪北缘现距北峪河南岸约50米，与现河床高差约30米左右。庙坪和安坪现均已被修造为梯田，各级梯田之间高差2米~6米不等，一般靠梯田外缘文化堆积较厚，耕土层下往往有平整土地时的铺垫土，靠梯田内缘堆积较薄，扰动较多，常常是耕土层下即为新石器时代文化堆积，或直接为生土，发掘区内文化层多不连续。我们根据不同类型遗存的分布特点，有选择地在庙坪发掘7条探沟（2米×10米、3米×10米、2.5米×5米），在安坪发掘1条探沟和1个探方（2.5米×5米、5米×5米），发现有仰韶文化遗存，尤以仰韶文化晚期遗存最为丰富。以下，我们根据不同地段文化堆积的特点，选择典型探方作一介绍。

第3层 红褐色砂土，较致密。大致呈自南向北的斜坡状分布。深50厘米~70厘米，厚10厘米~30厘米。包含物甚少。

第4层 黄土，较致密。自南向北斜坡状分布。深70厘米~130厘米，厚10厘米~60厘米。包含物有近现代的瓷片、瓦片和新石器时代的陶片，应为原地表层。开口与第4层下的遗迹单位有灰坑MH24。

第5层 灰褐土，较疏松。分布厚薄不均。深100厘米~145厘米，厚10厘米~35厘米。包含物主要是陶片、石器、骨器及动物骨骼等。陶片中泥质灰陶、橙黄陶和夹砂红褐陶较多，其次是泥质砖红陶和夹砂灰陶。纹饰以绳纹常见，其次是彩陶和附加堆纹等，彩陶以橙黄底黑彩为多，图案有水波纹、弧线纹、圆点纹、旋涡纹、网格纹等。可辨器类有敞口钵、折沿或卷沿盆、罐、缸、小口尖底瓶、壶等，时代约在仰韶文化晚期。开口于第5层下的遗迹单位有灰坑MH25和MH26。

第6层 灰黄土，疏松，略含沙性。南部分布较厚，西部分布较薄。深110厘米～175厘米，厚20厘米～45厘米。包含物有陶片、骨器、石器及动物骨骼等。陶质陶色和纹饰特征与第5层差别不大。可辨器类有敛口钵、敞口钵、卷沿或折沿盆、罐、缸、小口尖底瓶、壶等，时代亦相当于仰韶文化晚期。开口于第6层下的遗迹有灰坑MH27、MH44和MG4。

第7层 可分二小层。7a层：黄灰土夹黄褐土，质地疏密不一。主要分布于T6北部。深150厘米~200厘米，厚20厘米~50厘米。包含物丰富，有陶片、石器、骨器及动物骨骼等。陶质陶色和纹饰特征与第6层差别不大。可辨器类有敛口钵、敞口钵、卷沿或折沿盆、罐、缸、小口尖底瓶等，时代亦在仰韶晚期。开口于第7a层下的遗迹单位有灰坑MH33、MH39。7b层：灰土，疏松。主要分布于T6中部偏西。深180厘米~225厘米，厚5厘米~40厘米。包含物不甚丰富，主要是陶片、石器和动物骨骼等。陶质陶色和纹饰与第7a层也无明显差异。可辨器类有敛口钵、折沿盆、罐、壶等，

时代大致也在仰韶文化晚期。开口于第7a层下的遗迹单位有灰坑MH34、MH37、MH38、MH40等。第7b层以下为生土层。

# 五 文化分期特征及归属

# （一）典型陶器演化轨迹

钵第一期遗存只见直口圜底深腹钵。第二期和第三期遗存流行敛口钵和敞口钵。敛口钵，第二期早段均为砖红陶，施黑彩，曲腹较甚；晚段出现橙黄陶和灰陶的敛口钵，微曲腹。第三期遗存早中段多为灰陶，口微敛或近直口，腹较深；晚段均为灰陶敛口钵，敛口较甚，腹亦较深。敞口钵，第二期遗存发现较少，早段均为砖红陶或橙黄陶的深弧腹小平底钵，施内彩，器表修整精细；晚段为橙黄陶或灰陶钵，腹亦较深，但下腹刮削修整痕明显。第三期早中段以橙黄陶素面钵为主，敞口较甚，下腹多斜直，刮削修整多显粗糙；晚段则不见敞口钵。

盆第一期遗存未发现。第二期遗存早段多为橙黄陶饰砖红色陶衣的卷沿或折沿曲腹彩陶盆，沿用面趋平；晚段则以橙黄陶的宽平折沿彩陶盆为主。第三期早中段流行宽平折沿或折沿下垂的彩陶盆或灰陶素面盆，并出现卷沿下有凹槽的灰陶盆、上斜宽折沿的彩陶盆等器形；晚段则以折沿下垂的灰陶素面盆为主。

双鎏盆 见于第二期和第三期遗存。第二期早段均为橙黄陶饰砖红色陶衣的无沿敛口折腹盆，鎏手位于折腹处；晚段以橙黄陶黑彩或灰陶的曲腹盆为主，鎏手多在曲腹略靠下处。第三期早中段流行微敛口曲腹的彩陶双鎏盆或灰陶双鎏盆，鎏手多在曲腹靠下处，鎏手变小；晚段不见无沿双鎏盆。第三期遗存出现折沿曲腹双鎏盆。

侈口罐 第一期遗存只发现侈口卷沿罐，口沿施数道弦纹。第二期和第三期遗存侈口罐常见，主要分卷沿和折沿两种。卷沿罐，第二期早段卷沿较短，唇部、颈部不施纹。第三期早中段卷沿加长，微侈口，唇部和颈部开始施纹饰；晚段卷沿更长，侈口较

甚，唇部和颈部一般都施纹。折沿罐，第二期早段折沿较短，且折棱不明显，唇部和颈部不施纹；晚段折沿加长，折棱较明显，唇部开始施纹。第三期早、中段折沿较长，折棱明显，唇部和颈部多施纹；晚段折沿亦较长，折棱亦较明显，唇部不施纹饰，但颈部多施附加堆纹。

瓮第一期遗存未见，第二、第三期遗存流行。由敛口较甚发展为微敛口。

小口尖底瓶 第一期遗存未发现，第二、第三期遗存较普遍。第二期遗存早段只发现腹片，多为橙黄陶。晚段发现有砖红陶或灰陶微敛口或直口的尖底瓶口沿，重唇不明显。第三期遗存均为敞口，以灰陶为主。

2. 第二期遗存 早段，泥质陶质地已不如前期精细、硬实，陶器形体显得相对轻、薄。夹砂陶器夹砂颗粒基本一致。绳纹痕迹依然较深，但间距趋密，排列虽不凌乱，但不如前期有序，纹理以右上向左下斜为主，左上向右下斜者较少。灰陶均为素面，多经

磨光，有光泽。彩陶均为红底黑彩，图案有圆点纹、弧线纹、直边三角纹和弧边三角纹等，笔道粗细变化大，有些呈晕染现象。附加堆纹多为宽条状或纹索状，上施指窝状按纹，常饰于罐、缸中下腹部，一般只一道。晚段，整体风格接近早段。泥质陶中有一部分外表不作磨光处理，略显粗糙。彩陶以橙黄底黑彩略占优势，图案有圆点、弧线纹、交叉条纹等（表2）。

第二期文化遗存 早段，I式双鎏盆MH16:2，A型及B型I式敛口瓮MH16:66、MH16:52，缸MH16:58及Ba型I式侈口罐等与宝鸡福临堡遗存中的双鎏盆H45:9，敛口瓮H37:13、H106:22，罐H8:4，缸H8:5[5]形制纹饰相同，与大地湾四期下层遗存[6]中的同类器物也比较接近，说明其大致处于同一时代，属仰韶文化庙底沟期到半坡晚期的过渡阶段，或者是通常所说的“石岭下类型”早期阶段。晚段，Ⅱ式双鎏盆、B型Ⅱ式敛口瓮、I式尖底瓶与大地湾四期上层遗存中的敛口双鎏盆H307:58、H838:2，敛口瓮F901:13，小口尖底瓶H857[7]形制接近，时代也应相当，即大地湾四期晚段或者“石岭下类型”晚期阶段。

第三期文化遗存 大李家坪第三期文化遗存与马家窑类型遗存既有很大的差别，又存在一定的相似性。如兰州西坡岘遗址[8]彩陶色彩浓黑，线条粗健、宽厚，与第三期早段遗存彩陶风格相似，前者所出的彩陶钵H11:2上的图案纹饰在早段遗存中也能找到雷同者。器形方面，西坡岘遗址所出的I式盆T13:3、Ⅱ式盆T13:12、Ⅲ式盆T13:11等与早段遗存的A型I式盆、A型I式双螯盆相近，所处时代应大体相当。雁儿湾遗址[9]彩陶线条均匀细密，活泼流畅，内彩发达，图案有水波纹、同心圆圈纹、平行横线纹加圆点纹、旋涡纹、网格纹等，这与第三期中段彩陶风格相似。器形方面，前者所出的I～Ⅲ式盆H1:47、H1:37、H1:42、H1:44，I式碗H1:123，Ⅱ式碗H1:35，I式罐H1:61等与后者中的A型Ⅱ式盆、A型Ⅱ式钵、Ca型Ⅱ式壶等形制接近，说明二者所处时代相差不远。东乡林家晚期遗存[10]中的Ⅱ式罐F8:12与第三期晚段遗存中的侈口罐MH20:9形制相似，只是前者腹略鼓。前者的Ⅱ式罐F8:1虽为夹砂罐，但器形与后者Ⅱ式缸接近，均深弧腹。前者Ⅱ式罐F24:6卷沿溜肩鼓腹平底，为早期罐的特点，而后者Ⅲ式彩陶罐为卷沿立领溜折肩平底，与前者近似，差别可能只是时代早晚不同。敛口四钮罐也是二者共有的器形。兰州王保保城M1[11]出土的1件彩陶盆L.B.M1，盆底内彩构图与第三期晚段遗存中的彩陶盆MH20:17接近，均为同心圆内填十字平行线纹，并加圆点、弧线纹。由此看来，二者时代接近。

比较而言，大李家坪第三期文化遗存与河湟区马家窑类型遗存有很多相似之处，但值得注意的是，二者存在的差异也十分明显。陶系和纹饰，前者灰陶一直占优势，且呈上升趋势；林家遗存灰陶一直未占主要地位，且下层灰陶略多于上层。夹砂陶质地，前者夹砂颗粒较大，火候不高，质地较松脆；后者则胎粗质坚。夹砂陶纹饰虽均以绳纹和附加堆纹为主，但前者绳纹排列紧密，痕迹不深，纹理方向多近竖向或近横向，后者早段清晰规整，晚段则粗疏凌乱，以斜向交错绳纹为主。彩陶比例，前者占  $7\%$  左右；后者西坡岘遗址和雁儿湾遗址分别占到  $43\%$  和  $65\%$  ，远远高于前者。陶器器形方面，大李家坪第三期遗存有一定数量的尖底瓶，敛口，重唇不明显，多为泥质灰陶，是其典型陶器之一；河湟区马家窑类型遗存不见尖底瓶，渭河上游与河湟区交界处的陇西和天水地区有彩陶尖底瓶，均为平唇，喇叭口，橙黄陶施黑彩，是仰韶晚期尖底瓶上施马家窑类型彩陶图案的混合体[12]。此外，后者带耳器比例也多于前者。生产工具方面，前者石器以打制为主，常见两侧带缺口的长方形打制石刀，加工粗糙，选料不精，钻孔技术不发达，基本不见陶刀；后者石器多磨制，选料精，硬度高，且多通体磨制，形制规

整，棱角分明，钻孔技术较发达，以两侧带缺口的石刀、长方形穿孔石刀、复合的骨梗石片刀以及梯形石斧、石锛最为常见。可见，大李家坪第三期遗存与河湟区马家窑类型遗存的差别还是比较大的。这种差别，我们认为主要是因其源于大地湾四期文化，较多地保留并发展了大地湾四期的很多文化因素，与河湟区马家窑类型遗存同时代但文化性质有别，当属于仰韶文化序列，但受到马家窑类型的强烈影响，带有较多马家窑类型的文化因素，同时也有许多自身的地方特点，似可作为仰韶晚期文化的一个地方类型划分出来。

# 六 结 语

大李家坪遗址的发掘，填补了白龙江中下游地区未有正式田野考古发掘的空白，通过对大李家坪遗存的研究和分析，不仅对大李家坪新石器遗址文化面貌有了较为全面的认识和了解，并初步建立了大李家坪第一期（相当于仰韶文化半坡期）  $\rightarrow$  大李家坪第二期（相当于大地湾四期）  $\rightarrow$  大李家坪第三期（仰韶文化晚期）的发展序列，其间虽然还

存在某些缺环，有待材料的进一步充实，但该序列的建立，无疑有利于推动白龙江流域新石器文化的研究，同时对探讨白龙江流域新石器文化与周邻地区，尤其是与川西北新石器文化的关系也提供了新的资料，对马家窑文化和仰韶文化的关系这一问题的探讨，相信也会有所帮助。

# 颉吉普

大李家坪遗址经鉴定的石器共118件，其中由单矿物石英制成的1件，占总数的 $0.9\%$ ；由岩浆岩制成的1件，占 $0.9\%$ ；由沉积岩制成的共62件，占 $54.4\%$ 。其中包含的岩石类型有：亮晶灰岩10件、泥晶灰岩8件、硅质灰岩1件、硅质岩2件、粘土岩11件（其中页岩1件、钙质岩2件、铅质泥岩8件）、长石砂岩3件、杂砂岩17件、石英砂岩10件；由变质岩制成的共50件，占 $43.9\%$ ，其岩石类型有：变质石英砂岩7件、变质细砂岩7件、变质砂质凝灰岩1件、千板岩3件、片岩23件，其中石英片岩4件、片岩19件、蛇纹岩2件、混合花岗岩1件、大理岩6件。

从石料的岩石特征来看，这些石器是就地取材，并经过有目的选材和因材使用而制成的。

就地取材的特点表现在仅118件石器就采取了上述26种岩石（矿物）类型，这么多不同类型的岩石绝大部分都应当是就地在遗址附近的河（沟）谷冲、洪积物中挑拣的。

有目的选材和因材使用的特点表现在不同用途的器物选用不同类型、不同特点的石料。例如：纺轮、石球和个别石环，采用中厚层状（层理厚度3厘米～10厘米）的亮晶灰岩、泥晶灰岩和理岩制成。这类岩石的刻划硬度小，一般在3左右，岩石比较致密，但在风化、搬运过程中，容易裂成小块，便于人的挑拣、磨制。它们往往含有不同色调的角砾、团块和生物化石，稍经磨制、抛光后就会呈现出比较艳丽的色泽和图案，增加美感。

砥磨石（砺石）选用了各种砂岩和极少部分含砂质较多的面岩、泥岩，它们均具有一薄层状层理（层理厚度小于10厘米）。硬度多在3~4之间，其钙质胶结的砂状结构，很适合磨研。

羿用两种石料制成，一种由蛇纹岩制成，这种变质岩比较致密，硬度在3.5左右，经抛光后具有鲜艳的绿色和油腊光泽、蜡状光泽，现代称之为岫岩玉；另一种由钙质泥岩制成，呈灰色，致密程度低，硬度3，虽然这类羿远不如蛇纹岩制成的美观，但其石料充足，制作容易。

石环也分两类，一类用洁白、细腻的大理岩制成；另一类用分布广泛、取材便利的泥灰岩或钙质页岩制成。

石斧、石锛、石凿选料主要考虑石料的坚硬程度和韧性，选用了硬度  $6\sim 7$  ，硅质含量高、固结和重结晶程度深的玄武岩、硅质岩和变质石英砂岩。仅1件石斧MH1①：4用杂砂岩制成，为钙质胶结、砂状结构，薄层状（层理厚度小于3厘米)，硬度4。

石刀的石料比较复杂，既有沉积岩又有变质岩。沉积质的岩石类型为种砂岩的石灰岩；变质岩的岩石类型为变质砂岩、变质凝灰岩、千板岩和片岩类。它们的结构千差万别，硬度各异，一般为  $3 \sim 7$  ，矿物成分区别也很大。但沉积岩均选用有薄层状构造的

岩石，变质岩则选用片理和千板状构造较高的岩石，这些构造决定了岩石在风化作用下往往会破裂成薄片，容易制作，也适合于制造不同形状、不同硬度、不同用途的石刀。

# 附录2 大李家坪遗址孢粉研究报告

# 杜乃秋 赵慧民 孔昭宸

# （一）前言

囿于陇南地区的孢粉学研究工作以往涉及寥寥，考古学文化有关古代植被、环境的研究之鲜少尤为甚，承蒙北京大学考古学系提供甘肃武都县大李家坪遗址土壤标本，其重要性不言而喻。

# （二）自然环境与采样地层

大李家坪遗址位于甘肃省南端与四川北部接壤的岷山东北余脉，相当于岷山山脉与秦岭山脉之间的山地，现代植被主要是偏干性常绿、落叶阔叶混交林，有一定数量的华北型落叶阔叶树，表现出亚热带与暖温带的过渡性。

遗址位于白龙江支流北峪河南岸，地貌特点主要是堆积的河流谷地和山坡地。

样品均采自探方地层和灰坑，属于大李家坪二期遗存的有MH16、MH13、MH17、AT2③、MH28；属于大李家坪三期遗存的有MT2⑦、MH2、MH21、MH39。

# （三）标本工作方法

1. 将每一单位样品定量取重50克，加盐酸除去钙质。

2. 用移液管外加预先制备的石松孢子溶液。

3. 加热除去有机物。

4. 用LD-2A离心机分离水分等杂质。

5. 加入重液进行浮选。

6. 加入氢氟酸除去硅质。

7.分离孢粉。

8. 光学显微镜观察。

9.计算机数据处理、分析。

# （四）孢粉分析

大李家坪遗址所获孢粉的绝对数量虽然偏少，但我们仍可以从中读取到当时植被环境的一些信息。

所提供的遗址样品计10个，除2个出自探方地层外，其余皆出自灰坑。样品中均发现不等数量孢粉，其中数量在100粒以上者，有AT2③、MH13、MH16、MH17、MH21③、MH21⑤、MH28；低于100粒者，有MT2⑦、MH2、MH39。共统计孢粉1720粒，分

别属于16个类型。木本花粉有：松科（Pinaceae）、铁杉属（Tsuga）、云杉属（Picea）、冷杉属（Abies）、桤木属（Alnus）、桦属（Betula）；草本孢粉有：山萝卜科（Dipsacaceae）、蒿属（Artemisia）、蓼科（Polygonaceae）、禾本科（Graminese）、藜科（Chenopodiaceae）、百合科（L.Liaceae）；蕨类孢子有凤尾蕨属（Pteris L.）、水龙骨科（Polypodiaceae）、里百科（Gleicheniaceae）、环纹孢等。

# （五）讨论

大李家坪遗址样品均采自考古发掘现场，采样原则、方法以服从考古学研究为基准。

样品所出土的灰坑和地层在空间上没有严格的连续性，样品的年代属性则受考古学

文化发展、演变规律的支配。

遗址所在区域位于中国植被的亚热带常绿阔叶树区的西北部边缘。与它接触的是另外两个植被区：高寒草甸、草原区和温带草原区。确切地讲，遗址属于北亚热带常绿、落叶阔叶混交林带。

现有孢粉资料的分析结果反映了大李家坪遗址距今5200年～4800年之间植被的大致情况，以及自5200年B.P以降500年间的气温变化，结合中国全新世大暖期气候变化规律以及孢粉分析的气候冷暖、干湿波动事件，推测当时很可能有一个气温下降的过程。

# 黄蕴萍

大李家坪遗址所有地层单位动物骨骼均被采集，初步鉴定结果如下。

猪数量最多，多未成年，2岁以上者很少，均为家养，说明已经存在一定的饲养业。马、牛、羊、狗均发现不多，熊也有少量发现，反映出狩猎在当时经济类型中也占一定比例。鹿数量较多，有大、中、小型三种，其中一类可能分布在南方，这也反映了陇南地区在仰韶文化中晚期气候是比较温润潮湿的。鸟类至少有两种，一种形体大小同鸡，但是否是鸡尚不能肯定；另一种形体较大，种属尚不确。同时还发现有龟甲腹片和钻孔蚌壳。

工具当中骨器多是由大型偶蹄类动物的肢骨、指骨等制成，没有发现鹿角做出的工具。
