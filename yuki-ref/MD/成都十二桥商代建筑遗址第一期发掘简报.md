# 成都十二桥商代建筑遗址第一期发掘简报

四川省文物管理委员会

四川省文物考古研究所

成都市博物馆

1985年12月，成都市干道指挥部在修建综合楼地下室时，发现一处商代木结构建筑遗址。此遗址位于成都市西郊，北及中医学院，南邻文化公园，西倚省干休所，东靠十二桥（图一）。其范围东西长约142、南北宽约133米，总面积达15000平方米以上。

十二桥遗址第一期的发掘，进行了两次，揭露面积1800平方米。第一次在1985年12月至1986年7月，开  $6 \times 6$  米探方29个（发掘区域编号为I区），方向北偏东32度，面积约 $1_{100}$  平方米；第二次1986年9月至1987年4月，开  $6 \times 6$  米探方17个(编号为Ⅱ区）、  $10 \times 10$  米探方1个，面积约700平方米（图二）。现将第一期发掘的主要收获简报如下。

# 一、文化堆积

十二桥遗址的文化堆积厚达4米以上，地层从上至下可分十三层（图三）。

第一、二层：灰色粘土，两层共厚69—100厘米。为近、现代堆积。

第三、四、五层：黄褐色粘土，质细密，较硬，三层共厚132—197厘米。遗物以成都青羊宫窑青瓷器为主，器类有璧形足碗、饼足碗、小实足凹底盅、单耳杯、四系罐、高足盘、滴水足砚、蹄足砚、盘口壶等；另有诸如支钉、垫筒、垫圈等窑具。还发现莲瓣纹瓦当及“开元通宝”铜钱。遗迹有6口砖井（八角形为主）、窑址及作坊。年代当属隋唐时期。

第六、七层：浅黄色粘土。第六层含沙较多，质地疏松。两层厚33—140厘米。遗物为汉代常见的折腹钵、广肩平底罐、绳纹釜、深腹罐及“五铢”钱和云纹瓦当等。还发现陶井4口，井圈饰绳纹。

第八层：浅灰色粘土，厚10—90厘米。出土战国秦汉之际常见的器盖、钵、罐、圈足豆、釜等。此层出现大型建筑的夯土台基（夹部分卵石），台基上可见东西排列成行的“柱洞”（图四）。已揭露部分长约23、宽近18米，面积400余平方米。

第九层：浅黄色沙质土，厚5—20厘米。

# 1.建筑材料及构件接合方法

十二桥木结构建筑的材料，有圆木、方木、木板及圆竹、竹篾、茅草等(图一O)。圆木多未加工，有的还附着树皮；方木经加工，较整齐。

构件接合方法有三种：1.竹篾绑扎；2.原始榫卯与竹篾绑扎相结合；3.榫卯连结。前两种方法多用于小型建筑构件，即在木构件连接处，直接用竹篾绑扎或先凿出较浅的卵口，再用竹篾绑扎牢固。第三种方法用于大

型建筑构件，如IT25的地梁，做法是先把圆木加工成整齐的长方木，在上面凿出精确的卯孔，以立柱架梁。这些卯孔是用凿一类工具加工而成的。可见，当时的营造、加工技术已达到相当高的水平，加工工具也较先进。

# 2. 建筑基础

十二桥木结构建筑的基础，表现出以下两种形式。

（1）地梁基础：用于大型建筑。在I区T25中的五根地梁，I号地梁与Ⅲ号地梁有着对应关系。I号地梁2、3、4号方孔与Ⅲ号地梁12、13、14号方孔相对应，I号地梁1、5、6号圆孔与Ⅲ号地梁11、15、16号圆孔相对应；I号地梁5、6号圆孔的间距，与Ⅲ号地梁15、16号圆孔的间距基本一致。这种现象说明，这座建筑存在的结构上的对应关系。从I号地梁与Ⅲ号地梁的卯孔眼观察，也能发现在同一根地梁上卯孔眼也存在对应关系。假设I号地梁的5、6号圆孔间的中点为“0”，Ⅲ号地梁15、16号圆孔间的中点为“0”。I号地梁的5和6号圆孔与“0”的距离均为80厘米，4号和7号方孔与“0”的距离也相等。Ⅲ号地梁的15和16号圆孔与“0”的距离为92厘米。假设0与 $0^{\prime}$  相联形成一条中轴线，地梁上卯孔距中轴线的距离相等，卯孔在中轴线两侧相互对称，这与中国传统的木建筑左右对称的特点相吻合。如果这一假设成立，对I号地梁予以复原，其长度当在12米左右，北端还应有三方一圆的孔眼，与1、2、3、4号孔眼相对应；Ⅲ号地梁亦然。Ⅱ号、Ⅳ号地梁与I号、Ⅲ号地梁的长度基本相同。

综上所述，我们认为，如此规模的地梁遗迹，可能为宫殿类建筑的基础，地梁上相对对称的卯孔应是“柱洞”。从I、Ⅲ号地梁的间距仅2米左右来看，地梁遗迹可能是宫殿建筑的庑廊部分的基础。

（2）桩基础：用于小型建筑。先将许多下端削尖的圆木桩打入土中，形成密集的桩网。在圆木桩上端绑扎纵向排列的主龙骨，做成方格网状的结构层。其后，在地龙骨上平铺木板，作为居住面。小型建筑的基础，在I区T22、T23和Ⅱ区T30、T40中最为清楚。另外，基础的平面呈长方形，南北当是建筑的

进深，约7米。东西当为建筑的面阔，因东、西边缘尚未弄清，故面阔尚不清楚。这种在密集的木桩上的长方形建筑基础，使居住面略微抬高，建筑的下部架空，应属于千阑式的结构。

# 3. 墙体结构

小型建筑的墙体结构，是用直径6一11厘米的圆木，纵横相交绑扎成方格网状的木骨架，再把用小圆竹和竹篾编织的竹篾笆绑扎在木骨架上，做成既便于冬季围护防寒，又便于夏季通风挡雨的灵便墙体。此种做法与现代四川某些民居的木骨编竹墙体极为相似。从I区T6、T22存残高300、宽175厘米的竹编墙体；可以推测建筑的墙体高度不会矮于3米，这为复原这座建筑提供了参考资料。

# 4. 房顶结构

小型建筑的房顶，也采用原始榫卯加绑扎的方法。先将作为檩、椽的圆木连接成方格网状，再铺上茅草，并且竹篾绑扎。房顶为两面坡形式。在Ⅱ区T36中，有一根西至南方向，长约350、直径18厘米的脊檩。距脊檩约145厘米处，平行排列另一根直径16厘米的檩子，两根檩上有椽搭接，其上覆盖大量用作房顶材料的茅草层（图版壹：3）。

综上所述，此木结构建筑的基础、墙体、房顶均以圆木构件，用较原始的榫卯与绑扎相结合的方法，连接成方格网状的骨架，组合成框架式的主体结构。而房屋内的居住面高于户外地面。故十二桥木结构建筑，属于“干阑式”体系。我们根据T22、IIT40内的桩基、居住面、墙体、屋顶部分，结合IIT36的两面坡顶形式，试绘了房屋结构复原图（编号F1）（图一一）。

十二桥木结构建筑的废弃，推测与洪水有关。在如此众多的木构件中，不见火烧痕迹，屋顶茅草亦保存很好，从而排除了火灾的可能。这里地势西北高，东南低，许多构件恰均由西北向东南方向倒塌。地层中也明

显出现洪水冲积层，出土遗物上也多见洪水冲刷的痕迹。古邾江故道由成都西北九里堤向南流经故城西，至今通惠门折而东流，经西校场、南校场等地，至南河口与南河相汇。今遗址所在地，在西郊河、摸底河与南河之间，正濒临古河道旁，历史上受洪水的侵害，是可以想见的。

# 四、文化分期

# （一）陶器分期及演化特点

就遗址文化堆积及出土遗物的排比分析，十层以下文化层可分为三期。早期——第十三层，中期——第十二层，晚期——第十一、十层。

早期

典型器物以折腹小平底罐为主。还有1式敞口罐、高领罐、1式尖底罐、1式尖底盏、I型1式尖底杯、Ⅱ型1式尖底杯、Ⅲ型1式尖底杯、小圈足杯、I型1式杯形豆、Ⅱ型1式盘形豆、Ⅲ型1式豆、Ⅳ型1式罐形豆、1式盎等。

陶质以夹砂褐陶为主，泥质灰陶次之，另有少许夹砂灰陶。多素面，也出现附加堆纹、云雷纹、弦纹、绳纹等纹饰。制法有手制、捏制、轮制、泥条盘筑施以慢轮修整。多薄胎，少厚胎。火候较低，烧制不匀。

中期

早期的折腹小平底罐明显减少，新出现喇叭口鼓腹凹底罐、绳纹圈底釜、尖底盂、觚、碗等。另有2式尖底罐、2式尖底盏、3式尖底盏、I型2式尖底杯、Ⅱ型2式尖底杯、Ⅱ型3式尖底杯、Ⅲ型2式尖底杯、I型

2式杯形豆、Ⅱ型2式盘形豆、Ⅲ型2式豆、Ⅳ型2式罐形豆、2式蚤等。

除早期陶质外，中期出现少量夹砂红陶。纹饰新增加鸟纹、菱形回字纹等。制法以轮制为主，火候较早期为高。

晚期

器物种类大大减少，早期折腹小平底罐、敞口罐、高领罐已不再出现。目前所修复的只见4式尖底盏、5式尖底盏、6式尖底盏、I型3式尖底杯、Ⅱ型4式尖底杯、Ⅲ型3式尖底杯、IV型3式罐形豆等。

夹砂灰陶大量增加，还出现少量夹砂黑陶。纹饰仅见弦纹、绳纹。轮制为主，火候较高。

早、中、晚三期的陶器，有一定的演化规律。如I型尖底杯，早期的1式为直口，折棱在上腹部，尖底略平，底径大者2.1厘米。中期的2式变为侈口，领部加高，最大径由肩部转折处上移至口部，折棱开始下移。发展到晚期的3式，折棱则移至下腹，底径小者仅0.3厘米。Ⅱ型尖底杯，早期的1式为斜直腹，小平底，胎较薄。中期的2式则腹部加深，器底完全成了尖底。3式形呈角状，胎略变厚。发展到晚期的4式，器形则显肥胖，略呈弹头状。Ⅲ型尖底杯，早期的1式口微侈，鼓腹。到中期的2式则变为斜腹。晚期的3式则变为直口折腹了。又如尖底盏，演变亦很明显。早期的1式为敞口，口沿外折，弧腹，乳突状尖底。中期的2式口外侈并逐步缩小。3式则为外翻沿，弧腹发展为斜腹，乳突状尖底逐渐变小。到晚期的4、5、6式，则为敛口，无沿，腹略变深，乳突尖底已不明显，略近圜底。尖底罐，早期的1式为侈口，束颈，广肩外凸，弧腹疾收成尖底。中期的2式口部则微敛，领部加高，曲腹加深，下腹收势变缓。

遗址内出土的大量陶片，多数器形难以复原，特别是盎、豆等类器物，只凭遗存的盎足和豆把很难找出其演化规律。但从残存

部分，仍能看出一些变化关系。早期的1式蚤，腿部瘦长呈尖锥状。中期的2式蚤则发展为乳突状，袋状蚤腿亦由瘦长变为短胖。早期的I型1式杯形豆为喇叭口，深腹微鼓，接竹节豆柄。中期的I型2式，腹部加深，又较早期的瘦。又早期的IV型1式罐形豆无柄，下接外撇圈足，罐为折腹。中期的IV型2式则为外撇圈足，略出柄，上接斜腹或直腹罐。发展到晚期的IV型4式则出现短柄，上变为斜腹罐形。

# （二）年代

早期的1式折腹小平底罐、2式折腹小平底罐，与广汉三星堆遗址二期的典型器物相同。3式折腹小平底罐，与三星堆遗址三期偏早的器物相同。这类器物在成都抚琴小区遗址中也有所发现。这就为早期的年代推定打下了基础。另外，十二桥遗址早期的圆木标本 $^{14}$ C测定数据为：距今  $3520 \pm 80$  年（北京大学考古系 $^{14}$ C实验室）； $3630 \pm 80$  年，树轮较正为 $4010 \pm 100$ 年（中国社科院考古所 $^{14}$ C测验室）②。广汉三星堆二期 $^{14}$ C测定数据为距今 $3615 \pm 80$ 年③；成都抚琴小区同时期遗址 $^{14}$ C测定数据为距今 $3680 \pm 75$ 年（树轮较正 $4010 \pm 95$ 年）④。这几处遗址同期的 $^{14}$ C测定数据，前后相差不到100年，应较为可信。与我们就器物组合及地层关系对相对年代的推断也较为一致。故我们推定，早期的年代约为距今3700—3500年，相当于商代早期。十二桥木结构建筑出于第十二层之下，为早期遗迹，其年代亦当商代早期。另外，据上述陶器特征及演化特点，早、中、晚三期变化不是很大，其年代相差也不会很远。中期所出尖底盏，与广汉三星堆一号坑所出尖底盏相同。而一号坑时代相当殷墟一期。故这个遗址中期的年代，应与它们相近。晚期的年代，大概在商末周初之际。

# 五、结 语

十二桥遗址中发现的商代木结构建筑遗

迹，显示了蜀地先民因地制宜，就地取材，采用打桩法、竹篾绑扎法、榫卯联结法，所创建的一种具有独特风格的建筑形式。大型建筑的地梁，柱洞纵横对应整齐，推测上部已形成较为规矩的梁架。就结构而言，它较中原地区同时期的大型建筑所用的纵向梁架先进。故十二桥商代木构建筑遗址为研究古代蜀地的建筑形制、建筑风格、营造技术提供了重要的实物资料，是对中国建筑史商代部分的重要补充。

遗址内的小型房屋遗迹，显然属于大型宫殿的附属或配套建筑，它们互相连结，形成一个规模庞大的建筑群体。但由于第一期发掘刚结束，故整个建筑布局尚不清楚，有待以后的发掘。遗址的八、九两层还发现有春秋战国之际大型建筑的墙体、散水和秦汉时期大型建筑的夯土台基，且时代明确，地层叠压关系清楚，这也是重要的建筑史资料。

十二桥遗址早、中、晚三期遗存反映出独特的文化面貌。它有一组区别于其它文化，以小平底器、尖底器、高把豆为典型器物的陶器组合。具有此种特征的文化，在四川广汉三星堆、月亮湾，新繁水观音，成都方池街、岷山饭店、抚琴小区等同期遗址中，均有发现。由此可见，这一文化的分布范围，几乎遍布整个川西平原。就文化类型而言，带有浓厚的地方特色，这对研究早期蜀文化有极为重要的价值。同时，从遗址所出陶釜、陶觚等器形，以及某些器物的鸟头纹、菱形回字纹等纹饰来看，中原文化的影响是明显的。特别是中期所出的一件陶纺轮上的“舟”、“赤”文字，与常见的“巴蜀符号”不同，应属甲骨文字系统。从而说明，这一类型的文化与中原文化又存在着一定的联系。蜀地与中原地区，至迟在商周时期已有了广泛交往。
