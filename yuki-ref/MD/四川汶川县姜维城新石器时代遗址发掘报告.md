# 一、地理环境

汶川县位于四川省西北的阿坝州东南部、岷江上游河谷两岸，横断山脉东缘向四川盆地过渡地带，介于东经  $102^{\circ}51' - 103^{\circ}44'$ ，北纬  $30^{\circ}45' - 31^{\circ}43$  之间。东部隔龙门山脉的主峰九峰山与彭州市和什邡市相连，南靠崇州市、大邑县，西接宝兴县与小金县，西北至东北上溯岷江河谷、杂谷脑河分别与茂县、理县相接。县境东西宽84公里，南北长105公里，总面积4,084平方公里。东北部为龙门山脉所控，西南部受制于邛崃山系。地势由西北向东南倾斜，西部多分布海拔3.000米以上的高山，四姑娘山海拔为6.250米；东南部漩口地区的岷江出口处海拔仅780米。岷江由县北部入境，从东南部进入成都平原的都江堰，境内长达88公里，在汶川县境内的主要支流有杂谷脑河、草坡河等，分别在北部、东部和南部注入岷江。岷江多在峡谷中穿流，水势湍急，直至近代两岸还只有靠缙桥与索桥相通，河谷中少有发育较好、面积较大适合种植的平坝和缓坡台地，稍大的台地多分布在河床以上数十米到上百米处。流域的岩石多为麻岩、片岩、石灰岩等，由于山势陡峭，土壤均不能沾附，石多土少，形成“九石一土”现象[1]。南湿北旱趋势明显，昼夜温差较大，光、热、水分布不均。在2.000米以下地区，年均气温  $13.5^{\circ}\mathrm{C}$  （北部）、 $14.1^{\circ}\mathrm{C}$  （南部），无霜期  $247\sim 269$  天，雨量  $528.7\sim 1,332.2$  毫米，日照1,693.9~1,042.2小时。农作物以乔麦、粟类为主。

# 二、历史沿革

汶川是川西平原进出川西北地区的门户所在,历史悠久。古已有“禹生石钮”之说[2],以及“有王杜宇……以汶山为畜牧”的记载[3],都在汶川一带,虽非完全信史,也足见其历史源起之久远。至秦汉以降,这里成为历代中央政府管辖、镇抚川西北少数民族的戍边重镇之一。秦时在这一地区初置绵池县,隶蜀郡[4],西汉武帝时期开发“西南夷”地区,“冉鞅夷者,武帝所开,元鼎六年(前111年)以为汶山郡”[5],是中央政府真正对该地区进行管理的开始。东汉时由汶川改汶川,西晋时改为汶川山县,为汶川郡治所在,北周梁时始名汶川县,唐时“武德六年,白兰白狗遣使人贡,七年,以白狗等羌地,置维、恭二州”。维州即现在汶川县城所在的威州。宋“景佑三年,以与潍州混,改今名”[6]。元朝时保宁(今理县薛城)县并入州。明洪武三年(1385年),保宁地分为保县,属威州。明洪武二十四年(1406年),威州迁到今汶川县郭竹铺村,明宣德三年(1428年),因“常患羌人侵扰”,又从郭竹铺迁到今汶川县名“保子关”一山坡上。明宣德七年(1432年),又迁至今县城岷江河的南岸“姜维城”的山坡上,即现在的“姜维城遗址”所在地。清灭明后,州,县治仍用明时旧制,统属成都府。雍正五年(1727年)归保县,不复为州,隶属茂州(今茂县)。乾隆二十五年(1760年),清在平定大,小金川两土司之争的战役中,由于担心西蜀吐蕃势力的扩张,乃废保县,设杂谷脑直隶厅(今理县杂谷脑镇)。嘉庆八年(1803年),又改为理番直隶厅,属川西道管辖。威州属理番直辖。民国三年(1914年),废道治,以州府、厅为制,直属四川省政府。民国三年(1914年),因民族地区的复杂性,国民政府又恢复道治,理番厅改为理番县,威州仍属理番县。1935年,中国红军北上途经威州地区,国民政府将县以下设区,实行联保联坐保甲治。威州那时叫“新保镇”,属理番第三区,区公所在今威州镇。1951年2月,从改为理县的理番县划分出来,归汶川县。1952年县城由绵岘迁威州;1958年茂县、汶川县、理县合并成立“茂汶羌族自治县”;1962年复置汶川县至今。

姜维城遗址即位于汶川县县城南部的姜维山上，当地也称“古城坪”，是杂谷脑河与岷江交汇处南岸的一处缓坡台地，高出岷江河床80-100米，台地南北长约400米，东西宽约250米，面积近10万平方米。遗址地面尚存有较为完整的汉代夯土城墙和明代石墙。由于汉代修建夯土城墙取土和后期人类的频繁活动，遗址新石器时代的堆积破坏相当严重，现在保存较好的部分基本压在城墙下（图一），1996

二十世纪三十年代首次在姜维城发现了西北地区马家窑文化类型的彩陶，开始了人们对岷江上游新石器时代文化的探索[7]。此后的近八十年间，四川省文管会[8]、四川大学历史系[9]、阿坝州和汶川县的文物部门曾多次对包括姜维城遗址在内的岷江上游进行过调查和试掘，但除了采集到一些陶器和石器外，没有发现新石器时期的原生文化层堆积，从而使得对这一区域的新石器时代文化内涵和面貌的认识只能基于对零星采集材料的分析上。近年来四川盆地内的成都平原、川东峡江地区等处发现了众多的新石器时代文化并逐渐建立起了各自区域性考古学文化序列，因为岷江上游的新石器时代文化时代较早，地理位置上联系黄河流域和长江流域，而且已经发现黄河流域新石器时期文化的因素，人们自然也就更多的把探索盆地内早期文化源头的目光投向了这一区域。2000年，四川省文物考古研究所联合州、县文物部门对姜维城遗址进行了试掘，发现了比较丰富的地层堆积、遗迹和遗物[10]。2003年作为国家文物局“岷江上游新石器时代文化研究”课题的重要组成部分，省考古所再次会同阿坝州和汶川县的文物部门对遗址展开更大规模的考古发掘。整个发掘工作从10月上旬开始，至12月底结束。以遗址南部的电线杆为基点，在I、II、IV区共开  $5 \times 5$  米的探方17个（简便起见，以下探方和遗迹前略去03AWJ），实际发掘面积320余平方米（图二）。发现新石器时期灰坑30余个，房屋居住面遗迹3处以及一批陶、石、骨器等遗物。

# 三、地层堆积

此次发掘也证实了先期钻探和勘测的结果，那就是遗址的大部分新石器时代的堆积已经被后世人类的频繁活动所破坏，尤其是汉代修夯土城墙取土时基本将遗址中心地带的堆积破坏殆尽。发掘的17个探方中，位于汉代夯土城墙内外的9个探方除局部有很薄的新石器时期文化层堆积外，基本只见宋代的遗存；只有开在原夯土城墙墙基部分的8个探方有比较厚的早期文化层堆积，我们把遗址的地层统一为①-②层21个单位（⑲层分A、B）。这里就以其中的IT0105和IIT0105南壁剖面为例予以说明：（图三）

# （一）陶器

陶器以泥质灰陶、灰褐陶为主，其次是红褐陶，另有少量黑褐陶、褐陶；夹砂陶占一定比例，基本都是夹粗砂，尤其以屑夹石英石和片岩加工成的碎石粒粗砂类居多。素面为主，其中的泥质磨光陶占绝大多数。绳纹自始至终都占主要地位（图十），其次是附加堆纹、弦纹、戳印纹、复合纹（附加堆纹上饰绳纹形成箍带纹或手指压印成乳突状）、镂孔、方格纹、划纹、瓦棱纹、乳钉纹等（图十一）。器形则包括高领罐、罐、喇叭口罐、重唇小口瓶、钵、盆、壶、缸、器耳、器鎏、器盖、纺轮等，绝大多数是平底器。彩陶中泥质橙红陶的红衣黑彩占绝大多数，褐衣褐彩仅见数片；彩陶图案的题材种类比较丰富，有条形纹、弧形纹、网格纹、草卉纹、瓜棱纹等；器形有瓶、罐、壶、盆、器耳等，也都是平底器。出土的陶器除夹砂陶的烧制火候比较低，质地较差外，其它如泥质灰陶、灰褐陶、黑陶、红陶、红褐陶、橙红陶等的烧制火候都相当高，有的扣之还有铿锵之音。大多数陶器胎较薄，部分夹砂陶的胎比较厚，泥条盘筑法，都是手制，部分有慢轮修整的痕迹。这表明这一时期陶器制作、加工水平和烧造技术是相当高的。

同时从附表四中可以看出陶器组合中共有15类器物29型变化，其中具有分期意义的有12类21型。由此根据遗址的五组典型地层、遗迹单位叠压、打破关系和出土器物群组合及发展变化特征可以将遗址新石器时代遗存分为三期五段(附表五)。

各期、段的特征概括如下：

一期一段：这一阶段的陶器中，泥质陶占  $90\%$  左右，泥质灰陶约占其中的  $60\%$  ，泥质红陶近  $30\%$  。素面陶约  $50\%$  ，其中的素面磨光陶在八成以上；绳纹占到了近  $50\%$  ，其余是少量的附加堆纹、复合纹、弦纹等。夹砂陶仅有  $10\%$  多一点，基本不见有夹细砂陶，都是鳞夹用当地页岩和片岩加工成的长度在0.4-1.2厘米左右的粗大颗粒，质地比较松散。彩陶的数量很少，不足  $1\%$  。纹饰题材有弧形条带纹、网格纹、圆点纹等(附表一)。器型组合主要为AI、BI式高领罐、I式折腹罐、AI和BI式罐、I式重唇小口瓶、AaI、AbI、BaI式钵、CI、CII式盆、I式缸、AI、BaI式深腹罐，基本都是平底器，只有极少数的圈足器。彩陶有瓶、罐、盆等。其中夹粗砂缸和深腹罐中大多口沿上压饰绳纹，颈部和器身饰比较粗、宽的条带附加堆纹。陶器大部分都是手制，少数泥质陶有慢轮修整的痕迹。泥质陶的质地和烧制火候比较的高。这一时期堆积中出土了为数众多的兽骨，初步判定大者有猪、羊类的骨骼，小者有野兔类的骨头，有的还烧过。石器以磨制和打制并重，有一部分细石器，器形有石斧、锛等。

一期二段：该段的夹粗砂陶有少量的增加，约占到  $25\%$  左右，质地和火候没有太大的变化，泥质陶中的红陶的数量有所减少。纹饰中绳纹陶仍然占到绝大多数，但夹粗砂陶的罐、缸类器所饰附加堆纹逐渐的变细，并由带状和圈状向横向和斜向的间断绳纹变化。器形组合以I式高领壶、I式折腹罐、II式的Aa、Bb、Bc型钵、II式重唇小口瓶、II、III式缸、II、III式深腹罐等。这一段发现的动物骨头数量合种类与前一段差不多。石器数量有所增加。

二期三段：陶器器类和数量有了比较大的增加，泥质陶的比例略有变化，在  $84 - 90\%$  左右，但其中的红陶数量有所减少，基本在  $14 - 20\%$  之间。素面陶有仍近  $50\%$  ，其中素面磨光陶在八成左右。绳纹占  $50\%$  强(附表二)。陶器中新出现的器形有薄胎小罐、喇叭口罐等，器形组合以I式喇叭口罐、A、B型的II式罐、II式折腹罐、II式高领壶、III式高领罐、IV式重唇小口瓶、III式Ba、Bb、AaIV钵、IV缸、AIV深腹罐等。此外这一时期发现的动物骨骼相对减少，说明当时的经济形式中采集和狩猎占的比重可能逐渐在减弱。

三期四段：这一阶段泥质陶仍是主流，但夹砂陶中夹粗大页岩颗粒的粗砂陶只是零星的出现，取而代之的是夹细石英颗粒陶的数量增多。陶器的制作风格、水平和陶质也呈逐渐衰落的趋势，不能与前两期相比。泥质陶数量有继续减少，基本在  $75 - 85\%$  之间，其中的灰陶数量增加，占八成以上，红陶数量在  $10 - 15\%$  之间。素面陶  $50\%$  以上，其中素面磨光陶略高于  $70\%$  。夹砂陶的比例有所增加。陶器的烧制火候较前两期要低，质地也软，而且表面风化也比较严重。纹饰中绳纹仍是主要，其中夹砂陶器类大多是浅齿状口沿，出现一定的戳印纹(附表三)。器形中新出现了数量较多的夹粗砂小罐。器物组合有Ⅱ式喇叭口罐、Ⅲ高领壶、BaIV式钵、Ⅲ、IV式重唇小口瓶等。同时折腹罐、A、C型盆、Bc钵、缸等器形已经不见。彩陶题材比较普遍的是较为规整的平行窄线条纹，也有网格纹、弧形条带纹等。这一段房屋居住面遗迹比较集中有少量的彩陶，题材中平行条带纹较为流行。同时这一时期的房屋居住遗迹也比较丰富，而且面积比较大。说明这一时期的人类活动比较的频繁。

三期五段：夹粗砂陶中夹页岩和片岩粗大颗粒类已经不见，取而代之的是夹相对较细的石英颗粒。陶器的制作风格、水平和陶质总体呈继续退化的趋势。泥质陶数量继续有少量减少，在  $84\%$  左右。夹砂陶的比例有所增加。陶器的烧制火候较低，质地也软，而且表面风化也比较严重。纹饰中绳纹还是占主要地位，其中稍细的绳纹比较多，夹砂陶器类大多是浅齿状口沿，戳印纹的数量也有增多。器形种类继续减少，主要有Ⅲ式高领罐、Ⅱ式喇叭口罐，Ⅱ式夹砂小罐、IV式重唇小口瓶、AIV、BaIV深腹罐、AaIV、AbII式钵等。仍然有极少量的彩陶片，纹饰变化不大。

以上基本确立了各期、段的相对早晚关系，由于送检的碳十四年代测试数据结果尚未出来，还难以判定其确切的绝对年代，但遗址的总体文化特征属于西北地区马家窑文化类型范畴却是可以肯定的。因此可以通过与岷江上游毗邻地区该文化相应的有确切年代的遗址的比较来判定姜维城遗址新石器时代遗存的绝对年代。马家窑文化包括了石岭下、马家窑、马厂和半山三个类型，也是马家窑文化发展的三个阶段，其中的石岭下类型是仰韶文化向马家窑文化的过渡，马家窑类型则是马家窑文化最具特征最为繁荣的阶段。姜维城遗址出土的重唇小口瓶明显的要比师赵村四期的要稍晚，但又较五期的要原始；陶系上师赵村五期以泥质陶为主、绳纹和条带状附加堆纹较多的特点与姜维城比较相似[11]。姜维城遗址出土的Ba型带冠状和Bb型带凹槽厚唇钵也见于青海民和县石岭下类型遗存中[12]，而同时出土的

重唇小口瓶要较姜维城原始。因此可以判定姜维城遗址的年代上限应在石岭下偏晚到马家窑类型早期阶段，把文化传播上的空间距离因素考虑进去，应不晚于距今5400年左右。马家窑文化的一支或若干支在南下传入岷江上游后，应该有了自身的发展轨迹而不再受甘青地区该类文化太大的影响，因此姜维城遗址的年代下限更多的只能通过与邻近文化的对比来获得。遗址的夹砂陶系中齿状花边口、绳纹与附加堆纹、喇叭口罐与川西平原的宝墩遗址有较多的相似之处，对比其绝对年代应不晚于距今5000年。

与相邻的营盘山遗址[13]相比，二者同属马家窑文化类型是确信无疑的，从陶系、陶器组合到细石器有着大多数共同点，但同时它们之间也有一些不同的因素存在，如在姜维城遗址出土的重唇小口瓶在营盘山几乎不见，有极少数也是退化成平唇的小口瓶；营盘山遗址的细石器要较姜维城遗址要发达一些，磨制得非常精细。此外姜维城遗址早期堆积深约5米，要远较营盘山的深、厚，延续时间要长得多。因此姜维城遗址新石器遗存的上限可能要较营盘山稍早，而下限要较营盘山的晚。

# 七、结语

对马家窑文化进入四川盆地后的传播路线、影响范围，石兴邦先生曾指出“第二种可能是马家窑文化进入西南地区，它涉及的范围即后来的羌戎民族居住区，向东甚至达到了川东地区三峡一带。四川西北汶川一带发现有同仰韶文化和马家窑文化相同的彩陶片，可以作为直接或间接的证据。中原华夏居民同西南和长江原始居民发生联系，主要有两条路线：一条是沿汉江到达江汉地区，一条是从甘南沿西汉水、嘉陵江而到三峡地区。也许还有一条沿甘南到川南的路线而与当地的原始居民发生联系”[15]。目前为止，有直接考古材料证明的是岷江上游、白龙江流域（嘉陵江支流）、大渡河流域都在马家窑文化的影响范围内。马家窑文化的一支或若干支在向南进入四川盆地后基本呈环盆地边缘传播，而在其南下传播过程中形成了自身的发展轨迹，其中的一些文化因素也发生了转变，包括彩陶的逐渐衰落。其原因可能有以下三点：一、文化发展演变过程中自身的自然进化；二、对原著文化因素的吸收和融合；三、为适应新的环境所作的调整。所以从岷江上游的姜维城遗址、营盘山遗址到嘉陵江流域支流-白龙江流域的大李家坪遗址、再到大渡河流域的汉源大树遗址、狮子山遗址的新石器遗存中，外来文化占主导的同时，也体现出部分原著文化的因素。如姜维城遗址和营盘山遗址新石器时代遗存中的细石器和夹粗砂陶器的特征与川北嘉陵江流域的中子铺遗址、张家坡遗址就有许多相近的因素：细石器多系就地取材，以黑色燧石、石英石为主要原料，使用间接和直接方法打片、压片或剥片。陶片火候很低，质软，粗率，表面风化，特征原始。其中夹砂陶多为红褐陶和灰褐陶，有的加粗砂颗粒（粒粗达3厘米左右），表面风化较甚。表饰绳纹为主，个别饰划纹和指甲印纹状的连续戳印纹，口沿外饰附加堆纹，灰褐陶多附加堆纹，若干方唇上饰绳纹或齿状或绞索状装饰的陶片，以平底器居多，有圈足碗等。从以上三个遗址的碳十四年代测试看，其绝对年代并不晚于马家窑文化[16]。而且这种夹砂陶系陶器口沿多压饰绳纹而呈浅齿花边状，器身普遍饰泥条附加堆纹加绳纹（即所谓的箍带纹）的特征在岷江上游、大渡河流域、川西平原、川北边缘地带、川东峡江地区的新石器时代遗存中普遍存在，这并不是偶然的现象，应该是在马家窑文化进入盆地后才具有的，而不是其本身带来的，因为不可能这种文化只有一种因素影响如此之广而不见其他的文化因素。这些遗址的文化特征反映在马家窑文化中，其含义不言而喻。因此在四川盆地包括北部边缘地带应该有比较原始的土著文化存在，在马家窑文化进入盆地的过程中被吸收、融合，尽管它们在陶器制作烧造、生产技术水平等方面都不能马家窑文化相比。

关于岷江上游新石器时代文化是否直接进入并影响到川西平原的早期文化，如上面所述，后者一些文化因素反映在了前者的文化内涵中，如夹砂陶系陶器口沿多绳纹而呈浅齿花边状，器身普遍饰泥条附加堆纹加绳纹（即所谓的箍带纹），这些特征在盆地内有相当大的分布范围，具有相同特征的川北新石器遗存并不比马家窑文化晚；相反前者的很多因素在后者的遗存中却没有得到体现，虽然有着时空上的距离，但目前还没有发现其中的传承过程。因此更倾向于二者并不是直接的文化授受者，川西平原乃至盆地内的新石器文化有其自身的起源，而在发展过程中与周边文化的相互交流与融合则是不可避免的，这也是文化发展的普遍规律。

总之，姜维城遗址是目前为止岷江上游发现最早、堆积最厚、延续时间最长、非常具有代表性的一处重要遗址，虽然大部分堆积遭到破坏，但本年度发掘的遗存基本能反映整个遗址的文化面貌，实际也在很大程度上涵盖了整个岷江上游的新石器时代文化内涵。此次发掘揭示了它在文化内涵上与甘青地区马家窑彩陶文化的关联性，也反映了其自身发展过程中与盆地内原著文化的交流与融合，使我们在探索这一区域的早期考古学文化面貌、建立考古学文化序列的过程中迈出了极为重要的一步。相信随着进一步研究工作的开展，也会推动对岷江上游新石器时代文化同周边文化关系、南北文化交流研究工作的深入。

参加此次发掘的有四川省考古所的黄家祥(领队)、辛中华、郭富，汶川县文管所的罗进勇、张发芝。
