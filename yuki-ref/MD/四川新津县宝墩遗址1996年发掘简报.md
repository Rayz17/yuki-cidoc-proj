# 四川新津县宝墩遗址1996年发掘简报

# 中日联合考古调查队

宝墩遗址是1995年11月至12月调查时发现的，并进行了小规模试掘，对遗址的文化面貌和时代有了初步的认识。为了进一步探明该遗址的文化面貌，1996年11月12日至12月26日，由成都市文物考古工作队、四川联合大学考古教研室、日本早稻田大学和新津县文管所组成中日联合考古调查队对宝墩遗址进行了发掘。此次发掘采用“象限法”，把整个遗址分为四个区，各区统一布方。首先经过钻探，在Ⅲ、Ⅳ区选择了文化堆积比较丰富的两个地点进行发掘。为了进一步确认城的范围、城墙的修筑方法和

修筑时间，对遗址东墙蚂蝗墩段（Ⅲ区）进行了解剖。此次发掘共开5米  $\times 5$  米的探方15个，其中Ⅲ区13个（ⅢT1829～2229、T1830～2130、T2427～2430），Ⅳ区2个（IV T5401、T5402)；在蚂蝗墩开28米  $\times 2$  米探沟1条（ⅢTG1)。加上扩方，发掘面积达435平方米（图一）。出土大量的陶器和石器。经过进一步勘查，在遗址的西南部找到了城墙的西南拐角，加之对蚂蝗墩段城墙的确认，宝墩遗址的城垣范围及走向已基本明晰。整个城垣略成长方形，方向  $45^{\circ}$ ，北墙、南墙各长约600米，东墙、西墙各长约1000

# （一）房址

ⅢF2 位于ⅢTG1的西部，发现有墙基槽，开口于第4层下，打破第6层至生土。大部分叠压于探沟之外，未扩方。从已暴露的情况看，平面可能为方形或长方形，门向不清。东西宽410、南北暴露长232厘米。墙基槽宽25、深22厘米。基槽内填灰色土，土质较疏松，发现有密集的木骨洞，洞径 $6\sim 10$ 、深20厘米。部分地方由于被破坏，痕迹不清。此外，在ⅢH5内发现有大量的红烧土块，土块上多有棒状痕迹。据此，我们推测房屋的构造方式可能为“木骨泥墙”式，并经火烘烤(图六)。

# （二）灰坑

共32个，均发现于Ⅲ区。按形状可分圆形、椭圆形、长方形、长条形、不规则形等，其中以圆形、椭圆形、长方形者居多。灰坑大多较浅，出土的遗物不多。现仅就出土遗物较多并有代表性的加以叙述。

H44 位于ⅢT2130北部，部分压在T2130北隔梁内。开口于4层下，打破第6、7、9层。坑平面大致是圆角长方形，斜壁，圜底。坑口距地表深65厘米，口南北长236、东西宽135、深50-85厘米。坑内堆积为白鳝泥粘土，土质细密，颇具粘性，可塑性强。

构筑城墙的方法为“堆筑法”，即边堆土，边拍打或夯打，每次堆筑一大层。拍打又分水平、斜面拍打两种。水平拍打用于各小夯层；斜面拍打主要施于各小夯层堆筑至一定高度后形成的坡状堆积斜面，此斜面即各大层层面。各大层层面倾斜度(坡度)由中心向两边逐渐增大，即处于中心部位的Q4层坡度缓，位于外边的Q1层坡度陡。此次发掘的蚂蝗墩段城墙的夯具痕迹不如1995年发掘的真武观处明显，其夯筑的紧密程度亦不如真武观处，但它们的修筑方法相同。

# （一）陶器

陶器分夹砂陶和泥质陶两大类。夹砂陶中灰陶占绝大多数，另有少量外褐内灰陶和褐陶。泥质陶中以灰白陶和灰黄陶为主，另有少量褐陶。其中灰白陶火候较高，陶质较硬；灰黄陶陶质较软，多施有黑衣，但出土时大多脱落。陶器制法以泥条盘筑加慢轮修整为主，许多泥质陶片内壁手制痕迹明显，甚至能见泥条痕和指纹。圈足器多分体制作，然后粘接。夹砂陶器的器底多为二次粘接。部分器物为掩饰接痕，于接痕处饰绳纹，部分圈足器外底粘接处有加固戳痕。有些夹砂陶器的口沿也明显为二次粘接。夹砂陶器内壁近口沿部分多磨光，尤其是尊一类的器物特别明显。

1. 纹饰 夹砂陶器表面基本都装饰有纹饰，其中绳纹占绝大多数，另有少量划纹、戳印纹、凹弦纹、凸弦纹、附加泥条戳印纹等，而且这些纹饰多与绳纹施于同一器上。

# 四、结 语

此次发掘的第Ⅲ区以第5、6、7层出土遗物较丰富。灰坑以第6层下的H5和H16出土遗物较多，其他灰坑出土遗物较少。第8、9层出土的陶片既少且碎。第IV区发掘点以第4、5、7层出土遗物较丰富，第6层出土遗物较少。我们通过对这次发掘的各地层单位的文化遗物进行比较研究，将遗址分成早、晚两期。早期包括Ⅲ区第7层和第6层下的灰坑（以H5、H16为代表）、ⅢTG1的

考 古

第6、5、4层和IV区第7、6层；晚期包括Ⅲ区第6、5层，ⅢTG1第3层、H1以及IV区第5、4层。Ⅲ区第9、8层从陶器陶质、陶色、纹饰看，与早期有所差异，但所出的敞口圈足尊、壶、宽沿平底尊等器物与早期的基本一致，加之考虑到其出土遗物较少，面貌不甚清楚，故暂归入早期。ⅢTG1的G9由于出土遗物较少，无法归期，性质亦不明。1995年发掘简报将该遗址分成三段②，其一、二段与这次的早期相当；三段与晚期相当。该遗址早、晚两期文化面貌的主要特征是一致的，从器类看，早晚没什么大的变化，属同一考古学文化遗存。但同时也存在一定的差别，尤其是器物形制上早晚有所变化。

从陶质看，早期泥质陶约占  $60\%$  ，晚期比例有所增加，占  $70\sim 78\%$  ；相应的夹砂陶所占比例晚期较早期有所减少。泥质陶中，早期的泥质灰白陶明显多于灰黄陶，灰白陶约占  $63\%$  ，灰黄陶仅占  $33\%$  左右。晚期灰黄陶明显增多，在泥质陶中占  $41\sim 46\%$  ，灰白陶相应减少，占  $50\sim 53\%$  。从纹饰看，泥质陶中早期纹饰较晚期发达，在陶片统计中，早期纹饰占  $24\%$  ，晚期仅占  $9\sim 14\%$  。从陶器制作看，早期陶器普遍制作较精细，晚期明显变粗糙；纹饰制作早期也较晚期精美。虽然出土陶器多残破，完整器很少，但依据一些口沿看，早晚的变化仍然很明显。如口沿从早到晚有从宽变窄、沿从不卷到卷的趋势，圈足也有从矮变高的趋势。从几种典型器来看，如B、C、D型绳纹花边罐、B型敞口圈足尊、C型喇叭口高领罐，早期多为宽沿，晚期多窄沿。A型敞口圈足尊、A、B型喇叭口高领罐、宽沿平底尊等早期多为外折平沿，晚期多卷沿。C型圈足上镂孔数量早期比较少，晚期较多且方形镂孔明显减少，圆形镂孔增多。

第Ⅲ区蚂蝗墩城墙解剖处TG1，以墙内Q3、Q4和墙下第4、5层出土遗物较多，其所出陶片特征与早期比较一致。由此看

来，城墙叠压在早期地层之上，构筑城墙时亦破坏了早期地层，因而城墙的修筑年代不会早于早期。ⅢTG1墙内侧之上有晚期地层第3层和打破第3层的H1，1995年发掘的真武观段城墙墙脚上亦叠压有晚期地层，因而城墙的修筑年代不会晚于晚期，当在早期末或晚期初，使用年代在晚期。根据我们发掘钻探的情况，该遗址范围内汉代地层直接叠压在宝墩时期的文化层之上，其间没有其他时期的文化堆积，并有汉墓打破城墙，由此分析，城的废弃年代与遗址的废弃年代相一致。

通过这次发掘，对该遗址的文化面貌有了较清楚的认识。该遗址的生产工具以小型的磨制石器为主，制作较精致，有斧、锛、凿、穿孔石刀和锛等。其中以斧、锛、凿的数量最多、最具代表性，刀和铲少见。此外还有少量的矛、镞等。陶制生产工具有纺轮和网坠。生活用器主要是陶器。陶器中泥质陶的数量多于夹砂陶，盛行小平底器和圈足器。陶器唇部多作花边，水波划纹和戳印坑点纹很具特色。代表性的器物有绳纹花边罐、敞口圈足尊、盘口圈足尊、喇叭口高领罐、宽沿平底尊、宽沿盆、壶等。发现有小型房基，为方形的木骨泥墙建筑，并发现带木骨印痕的红烧土块，推测是木骨泥墙经火烘烤过。由上述情况可知，宝墩时期的人们过着定居的农业生活，兼有采集和渔猎。更为重要的是宝墩时期的人们已经筑起规模巨大的城垣，其周长达3200米。在当时，要进行如此浩大的工程并非易事，没有相当的必要是不可能修筑的。我们推测可能是由于当时竞争激烈，战争频繁而导致了这一宏大工程的产生。

关于该遗址的年代，我们曾参考三星堆一期、绵阳边堆山、汉源狮子山的碳十四测定数据，将其年代推定在距今  $4000\sim 4900$  年之间。后来在该遗址中采集了两个碳素标本：一是1995年发掘真武观段城墙内的标本，年代为距今  $4405\pm 95$  年；二是鼓墩子

北侧宝墩时期长方形竖穴土坑墓填土中的碳素标本，年代为距今  $4385 \pm 70$  。两个数据均在距今4500年左右，与原来的推测基本吻合。但考虑到两个标本并非出自原生土层，测得的结果可能早于本身的地层年代，尤其是城墙内与碳素标本共存的均为早期遗物，也就是说修筑城墙时破坏了早期堆积，其碳十四测定结果作为早期的年代当没多大问题，因此该遗址的年代上限当在距今4500年左右。

该遗址的文化面貌独特，有别于同时期的其他考古学文化。在四川地区发现的类似古文化遗存有绵阳边堆山①、三星堆一期②、汉源狮子山及都江堰市芒城遗址等。宝墩遗址是这类遗址中面积最大、最具代表性的一个，为便于将来的研究和进一步开展工作，我们建议将这类文化遗存命名为“宝墩文化”。

$③$  该墓为1996年10月调查时发现，是一东西向的长方形竖穴土坑墓，开口于近现代农耕土下，直接打破生土。墓坑东西长270、南北宽100、深70厘米。墓内上层填土厚59厘米，为灰黑土，疏松，含大量木炭和草木灰，出土一定数量的宝墩时期陶片，下层填土厚11厘米，为黄粘土，夯实。人骨架在坑底偏北，长170厘米，已腐朽，仅存痕迹。能看出为仰身直肢葬，头朝西，不见随葬品。
