# 系统增强总结 (V3.2)

本文档总结了 V3.2 版本实施的增强功能，重点关注易用性、稳健性以及与旧系统的功能对齐。

## 1. 界面本地化 (Chinese Interface)
- **状态**: 已完成
- **描述**: 整个 Streamlit 界面已完全汉化。导航、标题、按钮和状态信息均已改为中文，以提高易用性。
- **关键文件**: `gui/app.py`

## 2. Agent 资源池管理 (Agent Pool Management)
- **状态**: 已完成
- **描述**:
    -   实现了 `AgentManager` 服务来管理 Coze Bot 资源池。
    -   新增 `AgentConfig` 数据库模型以持久化 Bot 配置。
    -   后端在同类型的活跃 Agent 之间自动进行负载均衡（随机策略）。
    -   前端在“系统设置”页面提供了添加、列表和删除 Agent 的界面。
- **关键文件**: `src/services/agent_manager.py`, `src/api/agents.py`, `src/db/models.py`, `gui/app.py`

## 3. 数据库管理工具 (Database Management Tools)
- **状态**: 已完成
- **描述**:
    -   在 GUI 中新增了“数据库管理”页面。
    -   **架构查看器**: 查看所有表结构和列类型。
    -   **SQL 查询**: 直接在界面执行只读 SELECT 查询。
    -   **重置**: 增加了受保护的“重置数据库”按钮（用于开发/测试）。
- **关键文件**: `src/api/db_tools.py`, `gui/app.py`

## 4. 任务管理增强 (Task Management Enhancements)
- **状态**: 已完成
- **描述**:
    -   **批量上传**: “任务中心”现在支持一次上传多个文件。每个文件创建一个独立任务。
    -   **取消**: 增加了“取消任务”按钮以停止运行中的任务。
    -   **详细状态**: 任务现在追踪更精细的状态：`STRUCTURING`（结构化中）、`EXTRACTING`（抽取中）、`COMPLETED`（完成）、`FAILED`（失败）、`CANCELLED`（已取消）。
- **关键文件**: `src/services/orchestrator.py`, `src/api/tasks.py`, `gui/app.py`

## 5. 数据导出 (Data Export)
- **状态**: 已完成
- **描述**: 在“数据资产库”浏览器中增加了“导出为 CSV”按钮，用于下载整合后的资产数据库。
- **关键文件**: `gui/app.py`

## 运行方法 (How to Run)
1.  启动后端：`python src/main.py`
2.  启动前端：`streamlit run gui/app.py`

# English Version

# System Enhancement Summary (V3.2)

This document summarizes the enhancements implemented in version 3.2, focusing on usability, robustness, and feature parity with the legacy system.

## 1. GUI Localization (Chinese Interface)
- **Status**: Completed
- **Description**: The entire Streamlit GUI has been localized to Chinese. Navigation, headers, buttons, and status messages are now in Chinese for better accessibility.
- **Key Files**: `gui/app.py`

## 2. Agent Pool Management
- **Status**: Completed
- **Description**:
    -   Implemented `AgentManager` service to manage a pool of Coze Bots.
    -   Added `AgentConfig` database model to persist bot configurations.
    -   Backend automatically load-balances (random strategy) between active agents of the same type (STRUCTURE/EXTRACTION).
    -   Frontend provides a UI to Add, List, and Delete agents in the "System Settings" page.
- **Key Files**: `src/services/agent_manager.py`, `src/api/agents.py`, `src/db/models.py`, `gui/app.py`

## 3. Database Management Tools
- **Status**: Completed
- **Description**:
    -   Added "Database Management" (数据库管理) page in GUI.
    -   **Schema Viewer**: View all table structures and column types.
    -   **SQL Query**: Execute read-only SELECT queries directly from the UI.
    -   **Reset**: Added a protected "Reset Database" button to wipe all data (useful for dev/testing).
- **Key Files**: `src/api/db_tools.py`, `gui/app.py`

## 4. Task Management Enhancements
- **Status**: Completed
- **Description**:
    -   **Batch Upload**: "Task Center" now supports uploading multiple files at once. Each file creates a separate task.
    -   **Cancellation**: Added "Cancel Task" button to stop running tasks.
    -   **Detailed Status**: Tasks now track finer states: `STRUCTURING`, `EXTRACTING`, `COMPLETED`, `FAILED`, `CANCELLED`.
- **Key Files**: `src/services/orchestrator.py`, `src/api/tasks.py`, `gui/app.py`

## 5. Data Export
- **Status**: Completed
- **Description**: Added "Export to CSV" button in the "Master Data" browser to download the consolidated asset database.
- **Key Files**: `gui/app.py`

## How to Run
1.  Start Backend: `python src/main.py`
2.  Start GUI: `streamlit run gui/app.py`
